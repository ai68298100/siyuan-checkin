# v18.17.5 变更记录

批次：现代桌面质感重塑与 UI 原型 v3 对齐（2026-10-15），可从 v18.17.4 直接升级。

## 页面与交互

- Today 行动台：首屏落地 Hero「下一步」行动卡，突出当前唯一建议行动，支持一键记录与快速专注。
- Today Bento 网格：今日进度、连续打卡与专注卡片接入微光高光与悬停浮起动画，视觉节奏通透。
- Settings 健康总览：以 2×2 Bento 网格呈现本地数据、提醒与专注、思源笔记、外部来源 4 张健康状态卡，配备呼吸指示灯与一键去配置入口。
- 微交互手感：注入仿 iOS/macOS 弹簧物理缓动，支持悬停微浮与按压微回弹，并严格响应系统与插件级减少动效偏好。

## 视觉与排版

- 物理微材质：引入卡片顶部 1px 物理微高光（明亮模式 0.90 白色，暗黑模式 0.06 白色）与双层漫反射环境光阴影。
- 等宽数字：全局启用 `tabular-nums`，消除计数、计时器与完成率数字宽度的视觉抖动。
- 图标纯化：全量将残存的 Unicode 纯文本符号替换为规范 SVG 矢量图标（`uiIcon`），杜绝跨系统字体差异变形。
- 字阶治理：全面清理 7px~11px 极端微小字号，正文与提示信息下限收敛至 ≥12px。

## 兼容性与验收

- 主存储、事件身份、公开 API v5 和最低思源 v3.8.4 保持兼容，无数据迁移。
- 本版复跑类型检查、生产构建、主/UI/移动/生态/扩展/性能测试与发布资产门禁。
- 真实思源桌面客户端、Android/TalkBack、第三方账号、缩放与保存面板仍需现场验证；本次发布到 GitHub Releases，不推送思源集市。
