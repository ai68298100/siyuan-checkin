# 健康数据收件箱——iOS 快捷指令接入指南（T-1403，2026-09-23）

> 状态：**可用（桌面端插件逻辑已实现并有守门测试；iOS 快捷指令模板需真机验证，归 T-1388 真机窗口）**。
> 原理：手机快捷指令把健康数据以一行文本追加到收件箱文档（经思源内核公开 API），插件定期摄取并幂等记入打卡。插件侧不新增任何公开 API。

## 一、前置条件

1. 手机与运行思源内核的电脑**同一局域网**（或自行配置内网穿透）。
2. 拿到两样东西：
   - **内核地址**：电脑局域网 IP + 端口 6806（如 `http://192.168.1.10:6806`）；
   - **API token**：思源 设置 → 关于 → API token。
3. 在思源里新建一个文档（建议放在日记之外的专用笔记本，命名如「健康收件箱」），复制其文档 ID（块 ID，格式 `20260101120000-xxxxxxxx`）。
4. 插件设置页 → 外部联动 → **健康数据收件箱**：粘贴收件箱文档 ID并保存 → 把「步数」「体重」分别绑定到目标项目（至少绑定一项；步数项目单位建议「步」，体重项目单位「公斤」）→ 打开开关。

## 二、快捷指令模板（iOS）

### 步数（每日自动化）

在「快捷指令」App 中新建自动化 → **特定时间**（如每天 21:00）→ 关闭「运行前询问」→ 添加以下动作：

1. **查找健康样本**（Find Health Samples）：类型选「步数」，时间范围选「今天」；
2. **计算统计数据**（Calculate Statistics）：对上一步的结果求「和」；
3. **文本**（Text），内容填（一行，替换尖括号部分）：

```
health:steps:<今日日期，格式 YYYY-MM-DD> <统计结果>
```

> 日期可用快捷指令的「日期」动作 + 格式化 `yyyyMMdd` 后手工拼成 `YYYY-MM-DD`；也可以直接把文本写成 `health:steps:` + 日期变量 + 空格 + 数值变量。

4. **获取 URL 内容**（Get Contents of URL）：
   - URL：`<内核地址>/api/block/appendBlock`
   - 方法：POST
   - 头部（Headers）：`Authorization` = `Token <你的 API token>`（注意 Token 与值之间有一个空格）、`Content-Type` = `application/json`
   - 请求体（JSON）：

```json
{"dataType": "markdown", "data": "<上一步的文本>", "parentID": "<收件箱文档 ID>"}
```

### 体重（手动或每日自动化）

同上，把样本类型换成「体重」、统计换成「取最新样本」、文本行改为 `health:weight:<日期> <公斤数>`，其余完全一致。

## 三、摄取与幂等语义

- 插件每 **5 分钟**轮询一次收件箱文档；保存设置后立即摄取一次。单轮 SQL 按块 ID 升序最多读取 **500 行**，窗口外的行留到归档/裁剪后再处理。
- 行格式必须严格为 `health:steps:YYYY-MM-DD 数值` 或 `health:weight:YYYY-MM-DD 数值`；其他行一律忽略，不会报错。
- **幂等**：同一「项目 + 指标 + 日期」只入账一次。快捷指令同日重复运行、多开窗口都不会重复记账（重复行被自动跳过）；未来日期会被忽略。
- **首次入账后修正**：同日再次 push 不同数值不会覆盖已有记录；删除历史会留下撤销身份墓碑，同一 externalRef 不能靠重发恢复。需要更正时请在插件历史中按实际情况补录一条新的手动记录，并保留收件箱原行作审计依据。
- 行会保留在收件箱文档中，插件从不改写它；换绑项目不会迁移旧事件，仍在前 500 行窗口内的历史行可能按新项目身份再次入账。换绑前建议先停用并归档/裁剪已摄取行，再重新启用确认范围；文档变长后应定期归档，避免旧行占满读取窗口。

## 四、已知限制与摩擦（评估卡 4 的落地上限）

1. 快捷指令失败是静默的：网络不通、内核未开机、token 变更都不会有提醒——可靠性依赖电脑常开。
2. iOS「本地网络」权限首次访问会弹窗；系统大版本更新后可能需要重新授权。
3. token 属敏感凭据，填入快捷指令后**不要分享**该指令。
4. 定时自动化在设备关机或长期锁屏时会顺延，可能漏掉当日推送（漏推的日期手动补一行即可，日期写在行里，天然支持补录）。
5. Android / 华为：延后（见评估卡 7）。Health Connect + Tasker 链路门槛高，暂不提供模板。

## 五、数据边界

- 收件箱文档是普通思源文档，位于你的工作区内，内容完全由你（和你的快捷指令）写入；
- 插件只读取该文档中严格匹配格式的行，解析出的指标、日期、数值经既有 `recordEvent` 通道入库（来源标记为「接口写入」，externalRef 为 `health:<项目 ID>:<指标>:<日期>`），受统一的幂等、撤销（历史删除）与审计管理；
- 不读取任何其他健康数据，不联网。
