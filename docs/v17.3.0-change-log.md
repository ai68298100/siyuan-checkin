# 17.3.0 变更记录

## 回顾工作区重构

- 回顾页拆分为概览、记录、分析三个任务视图，首屏只展示当前任务需要的内容。
- 项目汇总每页 8 项，记录每页 30 条；趋势、热图、强度、分类、成就和提醒按需生成，避免隐藏区域提前构建大量 DOM。
- 新增最多 14 天的每日计划节奏图，可直接进入对应日期的记录；记录列表改为按日期分段的连续时间线。
- 趋势图增加可展开的精确数值表，保留折线、柱形、热图等适合对应数据的表达方式。

## 统计口径修正

- 跳过且未完成的日期不再进入完成率分母；同日真实完成仍优先计入达成。
- 周期配额单独显示所选范围内的贡献和目标周期，不再作为普通按日完成率参与排名或对比。
- 周期对比中的配额项目保留记录数量变化，不显示不可比较的百分比差值。
- 上限和戒除目标在没有违规记录时可正确表达达成；历史范围使用当时生效的单位和计数规则。

## 思源智能体与扩展总结

- 回顾助手提供“总结本期、寻找规律、规划下一阶段”三种提问方向，可复制精确日期范围后在思源智能体中继续。
- 明确区分思源能力注册与第三方总结提供者：能力注册不代表模型已连接，插件不调用未公开的聊天接口。
- 复制内容不包含原始备注和照片；插件内总结仍仅在已注册 SummaryProvider 时由用户主动触发。
- 总结缓存按完整日期范围和数据摘要匹配；切换周期、跨午夜、数据或提供者变化后，迟到结果不会覆盖当前页面。
- 智能体工具中的亮点和行动建议只比较有有效安排的按日项目，不把配额或无排期项目误判为落后。

## UI 与全端适配

- 减少重复说明、嵌套卡片和手机首屏占用，助手入口放在项目汇总之后并同时收录于报告菜单。
- 记录行、照片、长名称和长单位重新排版；主要操作保持至少 44px 触控尺寸。
- 修复窄屏配额列表横向溢出、自定义日期输入被压缩、弹层左侧裁切、滚动后跑出屏幕和平板宽度右侧越界。
- 日期弹层覆盖 320、640、719、720、844、1180px 及 844×350 短横屏，并适配独立浅色、深色主题。

## 验证与兼容

- 完整质量链、两组各 59 个回顾工作区布局、两组各 45 个全展开内容场景、双色视觉检查均通过。
- 真实生产包补充 40 个定向场景和 56 个日期断点场景，覆盖实际点击、键盘焦点、滚动返回及错误恢复。
- 主存储结构和公开 API 保持兼容，可直接从 17.2.x 升级；最低思源版本保持 3.8.4。
- 真实思源模型对话和真机系统级交互仍属于现场验证范围，不以浏览器模拟提供者替代。
