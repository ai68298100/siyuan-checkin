# 交接文档（2026-09-27，v18.8.0 发布后）

面向：在新电脑上克隆/同步本仓库后继续开发。先读根目录 `AGENTS.md`（自主开发协议），再读本文。

## 一、环境准备

1. 克隆：`git clone https://github.com/ai68298100/siyuan-checkin.git`（已有仓库则 `git pull && git fetch --tags`）。
2. 工具链：Node.js 18+、pnpm 11（`corepack enable && corepack prepare pnpm@11 --activate`）。Windows 建议 Git Bash。
3. 安装依赖：`corepack pnpm install`（仓库含 `pnpm-workspace.yaml` 构建脚本白名单，D-053，不可删除）。
4. 浏览器走查：走查脚本默认用 Playwright Chromium；缺浏览器时设 `CHECKIN_BROWSER` 指向本机 Chrome/Edge（见 README「开发与验证」）。
5. 首次验证环境：`corepack pnpm run check && corepack pnpm test && corepack pnpm run build`，三者 EXIT=0 即就绪。

## 四、开发纪律（AGENTS.md 摘要 + 本仓库惯例）

- 每轮：读 TODO/PROGRESS/BLOCKERS/DECISIONS → 选任务 → 实现 → 全链验证 → 更新台账 → 本地 commit；**不自动 push**、不编造测试结果、不跳过验收。
- 每个任务收口必过：`pnpm run check`、`pnpm test`（新守门记得注册进 package.json 的 test 串）、`pnpm run build`、`pnpm run test:ui`、`pnpm run test:quality`、`node tests/width-walkthrough.cjs`、双主题 `node tests/visual-qa.cjs`。
- 新纯函数放 `src/features/`（零依赖、无时钟、确定性）；日期运算用 `src/date-keys.ts`；schema 变更只做 additive+归一化 fail-closed；新 UI 交互同步双语 i18n 与守门。
- 架构边界由 `tests/architecture-boundaries.test.cjs` 守门：render 不越层导入、`store.events` 唯一写路径在 model.ts、外部事件唯一入口 recordExternalEvent、来源前缀须登记。
- 文档编码 UTF-8、行尾 LF（`.gitattributes` 强制）；写源码文件一律用编辑工具，不要用 shell 落盘（本机装有 Mimosa 安全钩子会拦截）。
- e2e（`pnpm run test:e2e`）会创建 `checkin-e2e.json` 隔离工作区，不碰用户笔记；e2e 工作区累积污染可能导致个别审计断言间歇超限，干净工作区复测即可。
