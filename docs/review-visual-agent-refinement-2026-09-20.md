# 回顾页：图形、智能体与UI继续精修

2026-09-20，T-1337～T-1340 / D-250。基于4ea5bcb继续开发，保持概览/记录/分析三视图、按需计算和分页；未发版、不push。

## 各区选择什么呈现形式

| 区域 | 本轮采用的形式 | 原因与边界 |
| --- | --- | --- |
| 周期概览 | 三项简洁统计带 | 条数、曾达标项目、有安排项目；项目覆盖不等于整体完成率 |
| 近期节奏 | 最多14日的小型可点击计划图 | 每日完成/有效安排，能直接进入当天记录；不是事件数量图 |
| 项目 | 分页进度条+数值+口径说明 | 20–30项仍可扫描；保留长名称、自定义单位与真实超额值 |
| 记录 | 按日期分段的连续时间线 | 查找、备注、照片和撤销需要可操作列表；不换成图表 |
| 周/日趋势 | 折线+统计值 | 延续变化方向；日活跃仍是有记录1/无记录0，不冒充完成率 |
| 月/年记录趋势 | 柱形+统计值 | 比较离散时间桶，保持真实单位；增加可展开的精确数值表 |
| 强度 | 平均或单项目曲线 | 保持近30天独立跨度，一次一张，不铺满所有项目 |
| 年度热图 | 年历色块+图例 | 适合查看长期记录分布；跳过用中性色 |
| 分类 | 按日横条，配额另列进度 | 不把天、周、ml、分钟相加后做饼图或雷达图 |
| 周期对比 | 当前/基期横条与差值 | 配额与按日比率不可混比；不可比较的项目保留记录数比较 |
| 成就、提醒、事项 | 按需展开列表 | 提供具体状态与动作，不增加装饰性图形 |
| 总结与智能体 | 任务入口、状态、结构化范围、可复制提问与结果 | 用户明确发起后生成或交给思源智能体继续 |

## 图形必须与打卡语义一致

- 节奏窗口取当前选定周期的最后最多14天，截止统计日；按日排期、创建/归档和规则修订逐日生效。周期配额单独展示，不把周目标达成涂成每天都完成。
- 未完成且跳过的日期从有效分母中去掉，标记中性；同日真实达成优先。上限/戒除目标可以在零事件时达成，不因为没事件就称为“没有表现”。
- 修复周趋势原先把跳过日算作未完成的问题。修复配额摘要原先把跳过事件当作贡献日/数值的问题，沿用Today的真实规则，不改公共数据结构。
- 项目条显示所选范围对配额目标的贡献，并注明目标周期起止；结束周期用范围内达标周期数，普通目标用有效天数。它与Today的完整自然周期进度作用域不同：例如昨日已完成周目标，切“今天”只显示今天贡献。没有有效安排用中性说明，不排成0%的落后项目。条形最大100%，旁边真实数值保留超额。
- 概览的项目覆盖包含已满足当前配额的项目；公共摘要字段结构保持兼容。UI本地总结只在同类按日项目内比较稳定性，配额不混入日完成率排名。
- 周期记录按持久localDate分段，保留时间戳排序；页内日期段的数量仅表示本页该段，翻页不暗示这是当天全部记录。

## 思源智能体的两条真实通路

1. **思源智能体读打卡数据**：宿主提供`addAgentCapability`时，插件注册只读与需确认的写入能力。助手展示实际注册状态；选择总结本期、寻找规律或下阶段计划后，复制准确起止日期及`checkin-summary-context`自定义范围调用要求，用户粘贴到思源智能体对话继续。复制动作不会发消息，不包含原始备注和照片。剪贴板失败时展开文本并选中，便于手动复制。工具的亮点与行动建议只在有效按日项目之间比较，不把配额或无排期项目误判为落后。
2. **插件内生成扩展总结**：仅在已有`registerSummaryProvider`提供者时显示生成动作和提供者名称。沿用现有提供者契约与超时；提供者输入为选定范围的项目/事件副本和汇总，其可能包含该范围原始备注。它与思源工具注册是不同状态，不把已注册工具显示成已连接模型。提问方向选择用于复制给思源的提问，不宣称所有第三方提供者支持该参数。

当前SDK证据为`node_modules/siyuan/siyuan.d.ts`中的`Plugin.addAgentCapability`；没有使用未公开聊天接口或模拟点击思源内部聊天DOM，也没有增加模型密钥配置。插件通过能力返回结构化数据，不能承诺所有宿主已配置模型或已批准能力。

总结结果按完整startDate/endDate和实际输入摘要匹配。旧缓存仍可在历史中查看，但不能冒充当前范围结果；数据变化、切换周期、跨午夜、提供者替换或失效后丢弃过期响应并释放生成状态。缓存历史串行保存，保存失败保留当前可读结果并反馈。建议仍走预览、确认、应用/撤销流程。

## UI与性能

- 保留淡紫蓝、白卡、紫罗兰主色及独立深色主题。减少记录嵌套卡与重复计数；宽端动作同行，窄端自然换行。
- 照片、长名称与长单位分别安排网格位置，防止照片把正文挤成窄列。控件保持44px；窄端节奏图在自身容器横滑，初次定位到最近日期，页面不横溢。
- 助手分清思源能力与总结提供者，将生成/失败/旧缓存反馈放在操作附近。提示与生成文本完整换行，提问文本可键盘选中。
- 共用一次周期汇总；报告关闭或没有对应历史时不扫描事件生成缓存指纹。节奏最多14日，项目每页8项、记录每页30条；深入图表仍只在所在区块展开时生成。
- 概览优先展示项目，助手入口放在项目列表之后并收录顶部报告菜单；统计口径详解进入报告，避免手机首屏被重复说明挤满。生成时间按用户语言显示本地日期和时分。历史配额采用当时的单位/计数设置，自定义范围拒绝未来开始日期。
- 展开态额外检查分类中的配额列表和自定义日期：移除窄端320px旧网格下限，日期表单在窄端改为单列，输入完整可读且可实际点击提交。日期弹层锚定整条日期工具栏，不再依赖手机滚动前缓存的header坐标或过窄按钮；从页面底部回顶展开的场景纳入生产bundle浏览器回归。
