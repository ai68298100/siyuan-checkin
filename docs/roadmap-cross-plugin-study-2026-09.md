# 思阅 / 思播与小驴打卡联动可行性研究

更新时间：2026-09-22  
状态：研究完成；仅登记后续开发计划，未改运行代码、数据结构或公开 API。

## 结论先行

| 来源 | 能否作为“累计有效时长达到阈值后自动完成打卡”的来源 | 当前证据 | 推荐边界 |
| --- | --- | --- | --- |
| 思阅（SiReader） | **可行性高，但需要小驴侧自己计时** | v2.2.8 源码有阅读统计和 `reader:open` / `reader:focus` / `reader:blur` / `reader:close` 生命周期事件；公开 `window.sireader` 只提供挂载/打开/页面脚本 API，没有统计读取方法 | 以“阅读器获得焦点且窗口可见的墙上时间”为有效时长；默认按本地日累计，达到项目阈值后写入一次幂等事件。不得读取思阅私有 `reader_stats`、`daily.json` 或直接复用其内部数据库 |
| 思播（SiMedia） | **可行性中等，需先锁定公开事件契约** | v2.0.4 发布包的 `window.siyuanMediaPlayer.controller` 有 `getCurrentMedia`、`getCurrentTime`、`getDuration`、`isPlaying` 等；播放器内部处理 `play/pause/ended/timeupdate`，但发布包没有对外稳定的累计播放时长字段/事件清单。旧更新日志（v0.6.9）声称支持第三方 API、事件监听和 window 事件，但未随当前包提供版本化契约 | 优先推动上游提供版本/能力发现及 `play/pause/ended/progress` 事件；在此之前只允许真实宿主实验性轮询 `controller.isPlaying()`，不能把内部 ArtPlayer 事件或私有存储视为稳定依赖 |

因此：**产品方向值得做，但先做“受控外部时长来源适配器”，不能直接做一个依赖插件私有数据的快捷开关。思阅可先进入 MVP；思播应以公开契约或真实宿主验证为准，默认关闭。**

## 推荐的用户语义

### 思阅

- 有效时长是阅读器获得焦点、文档可见期间的墙上时间，不等同于翻页数或思阅私有累计值。
- 失去焦点、切换到其他页签、窗口隐藏、移动端关闭时结算当前片段；回到阅读器再开始新片段。
- 默认项目范围为“全部书籍”；可选绑定某一本书或书籍身份。书籍标题/URL不进入打卡事件正文，外部引用只保留稳定、长度受限的匿名身份。

### 思播

- 有效时长是播放器处于播放状态且宿主窗口仍可观察期间的墙上时间；暂停、结束、切换媒体、窗口隐藏不计入。
- 默认不按 `currentTime` 差值直接记账，避免 seek、循环、变速和分集切换把内容位置误当成真实观看时长。若将来需要“内容秒数”口径，必须单独做版本化指标。
- 媒体身份优先使用公开的 `ref/refKey/source/sourcePath` 或稳定 URL；不得依赖 DOM 标题、私有数据库路径或历史列表内部结构。

## 自动完成打卡的最小方案（仅计划，未实现）

1. 在项目编辑器中新增 opt-in 的“外部时长来源”配置：来源（思阅/思播）、阈值、范围（全部/指定身份）、本地日口径；默认关闭。
2. 适配器只消费公开生命周期/能力接口，维护短时会话和可恢复的本地游标；不读取对方插件私有存储。
3. 达到阈值后，通过小驴 API v5 `events.record` 写入 `kind=duration` 事件；`source` 使用已登记的新前缀，`externalRef` 必须由来源身份 + 本地日 + 项目身份 + 阈值序号组成，重复事件返回 duplicate 而不是新增记录。
4. 写入失败保留待重试项并打诊断码；插件缺失、版本不兼容、事件字段不合法时降级为“仅显示已累计时长”，不静默完成打卡。
5. 事件一旦写入不因对方播放历史删除而自动删除；用户撤销沿用小驴现有事件墓碑/撤销语义。

## 必须先解决的风险

- **事件契约**：思阅事件名虽有源码证据，但未形成对外版本/能力协商；思播当前包更缺少事件清单。正式实现前要么上游声明契约，要么本项目把适配器标为实验性并配真实宿主回归。
- **多窗口与移动端**：同一窗口多个阅读器/播放器、桌面独立窗口、移动端抽屉路径都可能重复或漏结算；不能只靠一个全局计时器。
- **重载与崩溃**：阈值前的会话游标需可恢复，阈值后的 externalRef 必须稳定；重载、插件卸载、思源同步不能产生重复事件。
- **隐私**：书名、URL、媒体来源账号、字幕等不应默认写进打卡事件；设置页需明确说明仅记录时长和匿名来源身份。
- **来源注册**：在 `contracts/siyuan-checkin-contract/manifest.json` 登记新前缀前，先完成适配器准入、能力协商、卸载清理和契约测试；不能沿用 `manual` 或冒用 `tomato`。
- **真实宿主门槛**：浏览器测试不能替代思源桌面 WebView、Android、独立窗口、切页签、锁屏/后台和两插件同时重载的证据。

- **T-1386 设置与项目映射 UX**：来源、阈值、范围、隐私说明、当前累计预览、禁用/断开/重试；不把外部标题或 URL 作为必填配置。
- **T-1387 事件幂等、撤销与诊断**：新 source 前缀注册、跨窗口并发、失败重试、墓碑、卸载清理、导出诊断和回滚矩阵。
- **T-1388 真实宿主验收与小版本决策**：桌面页签/dock、独立窗口、Android、思阅/思播同时安装、插件缺失/升级/重载、暂停/seek/循环/切集、跨日和时区；证据齐全后再决定进入哪个 v18.x 小版本。

## 暂不做

- 不读取思阅 `reader_stats` / `daily.json` 或思播内部数据库来“同步总时长”。
- 不通过 DOM 选择器、ArtPlayer 私有对象、webpack 模块路径或 `/data/plugins/...` 路径建立硬依赖。
- 不把“打开过书/媒体”直接算作完成，不按阅读页数、播放进度或一次点击自动记账。
- 不在研究未完成、真实宿主证据不足时新增字段、定时器、事件监听或 source 前缀。
