- 现有预接线锚点：编辑器联动卡（bind-editor.ts:106-141 renderLinkageCard + 隐藏 linkagePlan editor.ts:210）、设置行搜索（settings-navigation.ts:40-80）、source-panel 展开态（`data-source-panel`×8）。

## 契约 1：连接总览三卡（设置页顶部任务入口，替换裸九组平铺的首屏）

| 卡 | 一句话 | 具体例子 | 进度（只读聚合，来自既有状态） |
| --- | --- | --- | --- |
| 让行为自动打卡 | 「记录不用手点：阅读、看视频、走路时自动入账」 | 打开思阅读 20 分钟 → 「阅读」项目自动 +20 分钟 | {n}/{总} 来源已配置 · {m} 个目标待修复（sourceState+问题态计数，T-1554 槽位） |
| 把结果写进笔记 | 「打卡之外，把报告、摘要、问卷答案写进你的文档」 | 完成感恩问卷 → 事实入账 + 答案写进当日日记 | {n}/{总} 输出已配置 · 最近失败数 |
| 给其他插件使用 | 「番茄钟、任务插件、AI 助手都能读写小驴数据」 | Dock Tomato 结束专注 → 绑定项目入账 | 提供方状态（API provided/Agent 态/TH waiting） |

- 数量只做导航，不用「已连接」徽标（T-1554 禁用词表）；卡片点击进入对应分区（联动与目标），九组原结构保留在其后——**不重排存储与路由**。
- 空态：全新用户三卡各显示一条 30 秒上手示例（契约 3），无进度行。

## 契约 2：项目直达来源绑定（编辑器「记录方式」段）

- 编辑器段 6（[类型驱动流程](editor-type-flow-prototype-2026-09-28.md)）扩展：选外部来源时列出**该来源对此项目的要求**（单位=分钟、类型、方向禁用等——数据来自来源登记表，T-1545 A 组「绑定·单位」列），不满足时显示缺什么而非禁用了事。
- 保存后联动卡（既有 renderLinkageCard）显示「去配置{来源}」按钮，携带项目 ID 跳设置对应面板（sourcePanelOpen 展开该卡并聚焦）；返回走 T-1603 returnTo=editor，编辑器草稿保留（DOM 表单仍在——跳转用新页签或弹层打开，避免单页表单丢失；实现细节归切片）。
- 现有 linkagePlan 隐藏 input 语义不变：保存时才生效，跳转配置不自动改项目规则。

## 契约 3：来源反查 / 新建合适项目 / 返回原路径

来源卡首屏四行（研究稿闭环 2 落地）：
1. 「产生什么记录」——按 A 组登记的记录口径（分钟片段/日汇总/步数体重/Marker 区间）；
2. 「当前写入哪些项目」——多指标逐项（健康三映射、微信读书三项目、叶归映射表），无绑定逐项显示「未设置」；
3. 「还缺什么」——T-1554 未配置场景文案+按钮；
4. 「最近一次有效记录」——活动结果槽（outcome+时间），点击→回顾记录（带来源筛选）。

「未设置 → 选择已有项目 / 创建合适项目」：创建分支预填名称建议（name-inference 既有）+ 单位校验（分钟来源只能绑分钟项目——**先校验后创建**，不建完再报错）；创建/选择完成后 **returnTo 来源卡**，绑定表单保留草稿。

## 契约 4：新用户六条示例（逐步说明，双语，含失败态）

每条=入口→前置检查→动作→看到的记录/文档→失败时显示什么：
1. 思阅 20 分钟阅读 → 分钟项目一条记录；失败=「等待一个可观察片段」（不显示已同步）。
2. 微信读书每日汇总 → 阅读项目；与思阅同时启用→非阻断冲突提示（sourceConflictReading 既有键）。
3. 健康文档步数 → 步数项目；失败=收件箱文档未配置（跳选择器）。
4. 感恩问卷打卡 → 事件+当日日记正文；失败=文档写入失败但事实已存（双结果，T-1588 切片）。
5. Dock Tomato 一次专注 → 绑定项目；失败=插件未装（9 态提示+回退内置）。
6. Task Horizon → 只看到「契约可用，对方未接入」（恒 waiting，不冒充连接）。

示例呈现于各卡空态与文档「新用户指南」；文案入 `set.state.*`/示例专用键，i18n-parity 对账。

## 契约 5：命名与可达性保留

- **组名对齐**：总览三卡名 = 联动分区三个子区名 = 来源卡分组类别名（plugin-event/official-pull/shared-doc 类别现有 i18n 键沿用），同一能力在三处同名，不造第二套叫法。
- 设置行搜索（文本过滤+Enter 聚焦）在总览卡上同样可达：搜索结果包含三卡与九组字段（T-1563 字段级导航的现有基础）；source-panel 展开态别名映射进新分区（T-1561 深链结论）。
- 快捷键/书签/渲染块入口不受影响（T-1603 兼容映射）。

## 验收门（T-1550 可用性切片对账）

1. 新用户从空库走通六条示例各一次，成功与失败路径都见到契约 4 规定的呈现；
2. 项目→来源→配置→一条真实事实→回顾详情 全链 returnTo 正确（T-1603 矩阵核对）；
3. 三卡进度数字与既有状态/审计一致（无第二套计算）；
4. 旧设置搜索/书签/展开态在总览存在时仍可达（cross-surface 守门扩展）；
5. 双语/键盘/320px 走查归 T-1608 台账。
