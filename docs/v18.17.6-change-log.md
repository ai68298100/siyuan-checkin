# v18.17.6 变更记录

批次：恢复与跨窗口可靠性、外部批量写入边界及状态可读性（2026-10-16），可从 v18.17.5 直接升级。

## 数据与外部接入

- 恢复点在遵守存储锁的路径上精确替换；旧窗口后续只提交相对持久化基线的实际改动，避免恢复前的项目、事件和修订重新流入。
- 墓碑继续保护已删除事实的外部身份，不按时间或数量自动裁剪。
- 批量写入复用 Task Horizon 严格身份校验，并按落账日的有效方向修订判定目标；调用时捕获输入快照，避免排队期间调用方改写意图。
- 批量未实际执行或存储刷新失败时拒绝 Promise，避免返回 undefined 被消费端误判；成功回执仍与输入逐项对应。
- v4 参考 bridge 增加本地日期检查：跨日待处理保留原身份并延后处理，避免写成今天。新合作仍推荐 v5 batch，完整 Task Horizon 合作验收尚待开发。

## 显示与验证工具

- 隐藏的记录回执面板不再参与布局和点击命中；完成事项芯片及提醒状态行使用明确颜色，减少透明度叠加造成的对比度问题。
- 清理重复样式，补齐首次成功按钮的语义色回退，保持现有 CSS 体积门禁。
- 新增显式运行的 Node 与真实思源主档快照基准，覆盖 1k/10k/100k 事件、附件、墓碑、双窗口并发和受控写入失败后重载恢复；基准不是存储容量承诺。
- 归档 Task Horizon 原始来件并逐项回应，修正配额累计量、截断、生命周期与消费端接入边界的文档。
