# 小驴打卡 v18.4.0 变更记录

发布日期：2026-09-24。本版交付微信读书官方接入（official-pull 渠道首租户）、每日提醒调度、回顾行动卡补齐与场景组合包，并修复一组真实交互缺陷（后台渲染死锁/面板收起/回车保存不刷新）。主存储 v3、契约 storeVersion 2、最低思源版本 3.8.4 不变，可直接从 18.3.0 升级。

## 外部来源

- **微信读书适配器（T-1402，official-pull 渠道首租户）**：经官方 Agent API Gateway（`i.weread.qq.com`，Bearer wrk- Key 用户自助申请）出站拉取，通道为思源内核公开转发接口 `/api/network/forwardProxy`。三条链路：① 每日阅读分钟（`/readdata/detail` 月度按日分桶，阈值触发每日一次幂等写入）；② 完读事件（`/shelf/sync` finishReading 预筛 + `/book/getprogress` progress=100+finishTime 核实，每本书一次；有声书专辑「系列完结」不纳入）；③ 每日笔记计数（`/user/notebooks` 活动书筛选 + `/book/bookmarklist` 划线 + `/review/list/mine` 想法点评，只结算昨日完整日）。官方 skill 包五份能力文档（SKILL/readdata/shelf/book/notes）逐条核对实现；`weread:` 前缀入 EXTERNAL_REF_PREFIX_REGISTRY；SourceChannel 枚举扩展 `official-pull`；30 分钟有界轮询+启动首拉，断网/失败静默记内存态；Key 仅存本地偏好、不入导出/文档/日志，渲染层只暴露 wereadKeySet 布尔。接入文档 docs/weread-integration.md。
- **与思阅的载体归属互斥**：微信读书时长只写用户绑定专用项目，思源内文档阅读归思阅——不同项目天然不重叠。
- **报告来源筛选**：回顾报告来源过滤与 knownSources 校验补齐 sireader/siplayer/weread（修复 sireader/siplayer 校验表遗留缺口）。

## 提醒

- **统一每日提醒（T-1443）**：当日逾期/待完成/事项汇总为一条思源原生通知（`/api/notification/pushMsg` 公开接口），事项提醒置顶；按 localDate 幂等；零事项不推送；安静时段内静默。
- **提醒调度（T-1451）**：偏好 dailyReminder {enabled, slots[]}，最多 4 个 HH:mm 时刻（严格归一去重升序）；配置后分钟级有界轮询到点触发、每槽每日一条、启动合并补发已到点未发槽位；默认空槽位完整保留「启动后一条」原行为。

## 回顾与统计

- **目标负荷解读卡（T-1450）**：interpretTargetLoad 纯函数——样本门槛（到期机会 ≥8）下的推断，积压率 ≥15% 偏紧 / ≥40% 疑似过高，只列问题项，确定性排序，观察窗首日作证据。
- **调整有效性对比（T-1448）**：报告对比节解释最近一次调整后的完成率变化方向与幅度。
- **情境×星期交叉（T-1452，第五轮生态调研采纳）**：crossTabulateContextWeekdays 纯函数——某跳过原因总命中 ≥3 且最高星期严格过半才输出模式行；报告情境节内至多 3 行。
- **失速排名（T-1436）与漏卡星期/时段分布（T-1439）**随 18.3.x 系列进入本版正式说明。

## 笔记原生

- **组合卡片（T-1453）**：checkin 渲染块支持 view=combo 编排 1~3 个既有视图——parseBlockConfigFields 抽出共用字段校验（子配置同白名单、禁嵌套、today 子段仍强制 itemIds），buildComboViewHtml 纯拼装，子视图交互经统一点击通道零改动可用。方向 9 清单（受限数据集/分组聚合/日期跳转/汇总表达式/可组合卡片）全项闭环。
- **场景组合包（T-1454，方向 11 首交付）**：TEMPLATE_PACKS 5 个场景组按模板名引用目录（纯内容资产），template-parks 纯投影（引用解析+未知名 fail-closed 降级+本地化名新旧判定），编辑器组合包芯片+预览面板，条目复用 data-template-apply 逐条填表——无批量写入、无 Store 变更。

## 修复

- **后台渲染死锁（T-1455 层 1）**：T-1445 把输入挂起放进 render() 本身造成死锁（焦点留在旧输入框时所有显式渲染被吞）。挂起收敛回 renderBackgroundUpdateFor 后台层，并在挂起时登记一次性 focusout 补渲染。
- **展开面板被后台事件收起（T-1455 层 2）**：精确录入面板展开态提升为会话字段 expandedExactEntries，全量/局部 patch/分组三条渲染通道按同一状态重建——思阅/健康收件箱事件落地不再打断用户填写。
- **回车保存后界面不刷新（T-1455 层 3）**：Enter 保存后焦点留在金额框令后台刷新被挂起吞掉；录完即收起面板+交还焦点，刷新立即发生。
- **手机端三缺陷（T-1444/T-1445/T-1447）**：回顾页二级导航 transform 滚动同步守卫改宿主显式移动标记（滚动振荡根除）；今日页输入聚焦期间后台重渲染挂起防输入法弹回（数据持久化不丢，仅推迟视觉刷新）；提醒操作按钮补 nowrap 与窄容器整行断行。
- **报告 knownSources 校验表**补齐 sireader/siplayer/weread，来源筛选不再被静默判为未知。
