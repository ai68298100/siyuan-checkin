# 小驴打卡 5.0 重构蓝图

> 状态：已实施（2026-09-10，v5.0.0）。本文件是 5.0 开发线的宪法——所有实现决策与本文冲突时，以本文为准（或先改本文）。实施差异：legacy 样式作为底层地板暂保留（见「技术决策」）。

## 一、诊断：为什么会成为"半成品"

1. **样式系统是三层补丁**：5502 行 legacy `index.scss` + 8 个 v4 覆盖文件 + 参考图对齐层，靠加载顺序互相覆盖。任何改动都在打补丁，视觉回归防不胜防。
2. **布局响应的是视口，不是容器**：插件被宿主在思源的弹窗、页签、侧边栏、手机屏四种宽度里，而所有布局判断用 `@media`（视口宽度）。侧边栏 440px 宽但窗口 1400px → 桌面布局硬塞进窄条，卡片挤碎、名称消失、导航折行。这是"打开就是乱的"的根因。
3. **功能优先，流程其次**：页面按功能命名（历史/总结/复盘），不按用户心智组织（今天做什么 / 过得怎么样 / 有什么要记住）。同一份数据三个页面各看一角，每页都单薄。
4. **头部与内容抢地盘**：今日页首屏被周条、摘要、最近记录、筛选四层占据，真正的打卡列表（最高频操作）在折叠线以下。
5. **卡片形态单一**：二值/次数/时长/数量四种类型共用一种"图标+名称+描边按钮"长条，没有为点击效率设计。

## 二、产品定位

**思源笔记里的习惯打卡工作台：记一笔要快（3 秒），看趋势要清（一屏），接生态要稳（API 永不破坏）。**

三种使用姿态，按频率排序优化：

| 姿态 | 场景 | 优化目标 |
| --- | --- | --- |
| 速记（最高频） | 手机端/侧边栏：打开→点→关 | 首屏即列表，一条一动作 |
| 回顾（每周） | 桌面回顾页：本周过得怎样 | 一屏看清，可下钻 |
| 整理（每天早晚） | 桌面今日页+新建 | 配置流程清晰 |

## 三、设计原则（所有页面共同遵守）

1. **一条就是一个动作**：打卡项目永远是单行（图标 + 名称 + 进度 + 大号主操作钮），行高 56–64px，绝不做大卡片。
2. **首屏即操作**：今日页打开直接是列表；周条/摘要/最近记录默认收起或压缩成一行，可在设置关掉。
3. **容器决定形态**：根节点为 container，按容器宽度切换四档形态——完整桌面（≥1000px，双栏+左导航）、中等（560–1000px，单列）、速记（<560px：手机+侧边栏共用）、弹窗。彻底删除视口媒体查询布局。
4. **一套样式系统**：删除 legacy 与 v4 全部样式层，新建唯一的 `ui/` 样式系统（design tokens + 组件层，目标 <160KB 产物 CSS）。类名词汇表保持兼容以保护测试与生态。
5. **彩色有意义**：淡紫蓝=可交互/品牌，绿=完成，暖橙=连续/提醒，红=危险。表面保持安静白/深灰。
6. **导航 5 项**：今日 / 回顾 / 日期事项 / 归档 / 设置。桌面左侧窄导航栏（~68px），移动端底部导航 + FAB。

## 四、信息架构

### 今日（速记优先）
- 头部一行：日期 + 进度胶囊 + ⋯（约 48px）
- 打卡行列表：按分组折叠头（细）分隔；二值=圆形打卡钮（空环→实心勾），次数/时长/数量=+步长圆钮；精确输入收进 ⋯
- 已完成：折叠为一行"✓ 已完成 N"
- 日期提醒横幅：全宽细条（最近一条 + 管理），无事项时一行静默文案
- 周条/摘要/最近记录：默认不渲染（桌面完整档可选显示，设置里存偏好）

### 回顾（历史+总结+复盘融合）
- 头部：标题 + 时间范围分段（今天/本周/本月/自定义）+ 导出
- 统计条：记录数 · 完成率 · 平均连续 · 最佳连续（一行）
- 左主栏：日历热力图（密度底色、点选展开当日明细）→ 项目汇总表（图标+名称+进度+完成率迷你条+连续徽章，点击下钻）
- 右栏：行动建议 + 智能总结入口 + 每周趋势
- 项目复盘 = 下钻视图（面包屑返回）：84 天网格、每周趋势、单项目建议

### 日期事项
- 重复引擎：一次性 / 每年（公历+**农历**）/ 每月（指定日、第 N 个星期 X、最后一天）/ 每周（指定星期）/ 每季度 / 每半年 / 间隔 N 天·月·年
- 农历：本地公历↔农历换算（压缩表算法，1900–2100，无网络）
- 模板库：生日（公历/农历）、纪念日、房贷/车贷/房租、物业水电、保险费（年/季）、信用卡还款、车辆年检、体检、订阅续费、域名续费、情人节/母亲节/父亲节等；支持存"我的模板"
- 列表行内编辑/删除；行显示重复方式、农历标记、下次日期倒计时
- 表单：选重复方式后动态出现对应字段；提醒天数预设（当天/1/3/7）+自定义

### 编辑器（新建/编辑）
- 桌面：左配置右预览。配置分三步：基础（模板胶囊→名称→类型分段→目标/单位）、外观（当前图标一格，点击弹层选择：搜索/9 组/自定义全在弹层内）、计划（分组/频率/重要性/时间段/番茄钟高级折叠）
- 右栏 sticky：实时真实卡片预览 + 保存/存为模板常驻
- 移动：单列同序，底部固定保存条；修复模板区塌缩 bug

### 设置
- 分类锚点导航 + 统一设置行（左标签右控件）：外观 / 今日视图（含首屏显示开关）/ 弹窗与页签（尺寸模式：比例默认 80%/全屏/固定宽高）/ 快捷键 / 数据与导出（含恢复偏好）/ 连接与能力 / 关于
- 删除"界面密度"（含 CSS 变量、按钮、设置卡、旧偏好静默忽略）

## 五、技术决策

- **容器查询基座**：`.lc-checkin { container: lc-checkin / inline-size }`，全部布局用 `@container`。粘性头部策略统一：速记模式一条 44px 实底 sticky 工具条，其余头部随滚动；z-index 梯子全局唯一定义。
- **样式系统（两步走）**：第一步新建 `src/ui/`（tokens + components，容器查询驱动）作为最终视觉层，级联位次在最后；legacy `index.scss` 暂作"底层地板"保留（提供未迁移组件的兜底样式），P6 视觉走查确认全量覆盖后删除。8 个旧 `*-v4.scss` 补丁层立即删除，由 `ui/` 接管。类名词汇表保持兼容以保护测试与生态。
- **数据层不动**：事件溯源模型、合并存储、tombstone、API v4 + 能力协商、番茄钟/专注/总结适配器、智能体 6 能力——全部保留（这是插件最好的部分）。日期事项存储结构扩展走迁移规范化（旧数据默认一次性/每年），照迁移回归测试惯例处理。
- **性能预算**：产物 CSS <160KB（现 285KB）；搜索输入防抖，不做全量重渲染；backdrop-filter 限导航/弹窗两处；交互响应 <16ms。发布检查加 CSS 体积守卫。
- **测试**：43 个测试文件随结构演进同步更新（断言新的行式结构/5 项导航/回顾页）；视觉 harness 保持浅+深双主题、320–1180px、四档容器形态各出截图。

## 六、明确砍掉的东西

- 界面密度（整套）
- 视口媒体查询布局（整套）
- 历史/总结/复盘三个独立页面（融合为回顾）
- 今日页首屏的大周条、大摘要瓷砖、最近记录区
- 图标选择器常驻编辑页（改为弹层）
- 日期事项"管理"孤盒（横幅 + 专页）
- 三层样式补丁架构

## 七、明确保留的好部分

- 事件溯源数据模型与离线合并语义
- API v4、能力协商、六大智能体能力
- 24 个内置模板、自定义图标（下载存本地/图标库/Iconfont 入口）
- 番茄钟/专注/总结 Provider 适配器机制
- 本地行动建议引擎（无 AI 可用）
- 测试文化（结构断言 + 视觉 harness）
