# 18.0.0 变更记录

本版本聚合 v18~v21 四个规划版本的本地交付（模板体系、笔记原生、受控智能体、生态准入）。主存储结构不变（内部 v3），公开 API 在 v5 面上新增 `diagnostics.read` 能力，可直接从 17.3.0 升级。

## 模板体系二期

- 模板目录从 45 个扩充到 60 个，覆盖健康、学习、运动、工作、生活、戒除、专注、创作八类；每个模板均有名称与备注的中英双语键。
- 新增「最近使用」置顶行（容量 6，随界面偏好持久化）与「精选推荐」行（跨八类 8 个锚点，无最近使用时展示）。
- 模板区分批显示：初始只露出前 24 个，可一键展开全部；搜索与分组筛选时自动全显。
- 非二值模板的摘要行补充排期标签；事项模板沿用既有分类页签体系。
- 新增模板目录门禁：名称/备注双语键完备、分组键完备、目录规模护栏（55~70）、精选名单可解析。

## 回顾导出增强

- 报告新增「偏差解释」区块：对比基线确定性生成提升/下降/持平/数据不足四类可读结论，可随区块开关关闭。
- 报告导出支持事件来源筛选（全部/手动/番茄/API/导入），筛选同时作用于当期与基线口径，并在报告正文声明。
- 新增「导出全部」：一键顺序导出 JSON 备份、CSV 记录与 Markdown 报告。

## 受控智能体

- 建议执行白名单扩展到排期（schedule）：结构校验、深比较、应用/撤销全链路；回顾页重点项目新增「建议改为弹性排期」入口（仅每日排期且非戒除类，改为每周 3 次弹性配额，确认后生效、可撤销）。
- 新增项目草案确认流：智能体提供方可在总结结果中回传新项目草案（最多 2 份），回顾页展示草案卡，用户「检查并保存」进入普通编辑器预填后手动落盘；草案没有任何直达持久化路径。
- 新增智能体建议审计导出：版本化诊断 JSON（信封快照 + 五类动作统计 + 归一化审计），不包含令牌与 nonce。
- 排期结构校验抽取为独立模块，建议执行与项目草案共用同一实现。

## 数据诊断与可靠性

- 新增机器可读诊断：五类原因码（保存失败/读取失败/版本冲突/导入被拒/写锁竞争），环形容量 20。
- 公开 API 新增 `diagnostics.read` 能力与 `getDiagnostics()`（防御性副本）；`describe()` 新增 `deprecated` 弃用预告数组（当前为空）。
- 设置页新增「数据诊断」行（计数 + 最新本地化标签 + 导出）与「数据诊断与恢复指南」折叠块（恢复点、JSON 备份、损坏隔离、多窗口、番茄收件箱、诊断导出六条自助路径）。
- 发布摘要同步脚本化（`sync:digest`），取代手工流程。

## 界面语言

- 设置页新增「界面语言」：中文 / English / 跟随思源；默认中文，老用户行为不变。
- 英文界面完成全矩阵走查审计（42 页面 + 32 交互 + 8 对比度 + 10 混合 + 16 长内容场景），中英布局均无溢出。

## 渲染块二期

- 新增 `groups` 多分组并集作用域（≤16 个，去重）与 `view:"groups"` 分组聚合视图（完成率排序、未分组显式标注）。
- 新增白名单表达式 `minRate`（1~100）：只看完成率不低于阈值的条目；全部被滤掉时给出可读空态。
- 跳转增强：汇总行点击跳转项目洞察；有已解析锚点的行点击直接打开锚点所在文档，失败回落项目洞察。
- 渲染性能门禁扩展为 1k/10k/100k 三档（实测 19/28/232ms 量级）。

## 生态准入

- 发布消费方契约自测包 `contracts/siyuan-checkin-contract`：78 项合规断言 + 五项准入清单（身份、幂等、卸载清理、权限声明、失败隔离），manifest 与仓库契约清单字节一致。
- API 参考文档（`docs/api-v5.md`）新增错误模型三原则、批量写原因枚举表与会话诊断码表；`describe()` 弃用预告语义成文。

## 维护与工程

- CSS 卫生门禁：类引用审计（583 token 零死类）+ 重复规则护栏 + 预算重收紧（620KB 警告 / 640KB 硬阻断，替代 D-246 报告口径）。
- 修复 8 个模板缺失的英文名称映射、「戒除」分组英文键与 20 个备注双语键；清理绑定层硬编码中文计数。
- 走查脚本支持英文界面与模板区运行时断言；宽度走查中英双语全矩阵通过。
