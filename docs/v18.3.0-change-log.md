# 小驴打卡 v18.3.0 变更记录

发布日期：2026-09-24。本版把生态调研第三轮采纳项与产品战略落地路线（R-A0～A12 泳道，D-264/D-265）的本地可交付部分一次收口：戒断里程碑、今日行动台、提醒注意力、命名保存视图、范围导出、隐私披露与生态契约全面增强。主存储 v3、契约 storeVersion 2、最低思源版本 3.8.4 不变，可直接从 18.2.1 升级。

## 习惯内核

- **戒断里程碑（T-1415，源：T-1400 第三轮采纳）**：at-most 戒除类项目新增「戒断里程碑」只读投影——当前戒断天数对照 1/3/7/14/30/60/90/180/365 阶梯输出最近达成级与下一级。今日卡片、summary 渲染块与公开 API `getStreaks` 三处同口径。
- **节奏投影（T-1426）**：新增 `pace-projection.ts` 纯模块，普通 backlog 逾期率（SKIP 排除、证据日期回放）、quota 进度、at-most 恢复状态三套口径独立且可解释。
- **情境化记录（T-1433）**：跳过/打卡备注的自由文本按中英关键词归一化为有限词表（阻力/时间不足/环境变化/身体状态/情绪波动/其他）；报告新增「跳过原因分布」节并带样本不足守卫。不新增事件字段、不影响完成判定与连击。

## 今日页与提醒

- **今日行动台摘要条（T-1420）**：今日页顶部只读呈现完成进度、跳过数、推荐下一步与专注可用性；记录、撤销与失败回滚路径不变。
- **安静时段（T-1421）**：可配置跨午夜窗口（缺省 22:00–07:00、默认关），窗口内优先提醒降级为页内安静呈现；断开/延迟语义显式化。
- **延后 2 小时（T-1421）**：提醒中心新增防抖动作，同一提醒实例在窗口内只呈现为已延期，到期自动恢复。

## 回顾与导出

- **命名保存视图（T-1432）**：把「最近 N 天 + 来源」存为命名视图一键应用（上限 10），只存查询偏好不复制事件；失效条件显式回显。
- **范围导出（T-1436）**：CSV 导出支持相对天数范围（7/30/90/365，钳制 730）；JSON 恒为全量备份语义。
- **报告范围声明（T-1425）**：报告头显式回显统计范围（相对天数/全部、过滤器、缺失条件、截断）。
- **失速项目排名（T-1436）**：报告新增「失速项目」节——最近 30 天漏卡次数排名，附完成率与最近漏卡日证据。

## 生态与契约

- **渲染块一键插入（T-1416）**：命令面板提供汇总/月历/热力图/分组概览 4 个预设，插入即可正确渲染；参数缺失继续 fail-closed。
- **导入预览（T-1427）**：Loop CSV 与 Obsidian Habits 21 导入前统一披露重名合并与语义损耗（六类词表），不再事后才发现。
- **Task Horizon 消费侧契约（T-1428）**：消费者参考实现补齐 calendar.read 发现、单飞合流、事件失效缓存、超时/Abort 守卫与 v4 显式降级。
- **契约套件同步（T-1434）**：externalRefPrefixes 扩至 6 前缀（补思阅/思播/健康），来源生命周期矩阵测试覆盖跨日/重复/异常 fail-closed。
