# 新建打卡页 UI 原型与重构计划（2026-09-28，研究稿，先不开发）

> 源码复核后的能力基线与顺序见 [统一实施计划](consolidated-experience-plan-2026-09-28.md)。当前基础类型只有二值、次数、时长；配额是排期，戒除/上限是每日项目的方向。30 天预演、规则变更对照、模板、保存并继续等已实现，下面要重排其入口和解释。

## 当前页面承担的事情

新建/编辑页目前同时承载：模板浏览、名称和图标、打卡类型、目标/单位/步长/快捷增量、问卷绑定、实时预览、未来 30 天排期、分组/优先级/时段、自动归档、连断容忍、限额方向、专注提供方、笔记锚点、Task Horizon 显示和删除/归档。当前页面把模板区和基础字段放在左侧，把预览和“高级”放在右侧；但高级区里混合了影响记录事实的选项、显示偏好和外部写入入口。

用户创建一个打卡项目实际只需要依次回答：

1. **我要记录什么？** 二值、次数或时长；配额排期与戒除/上限方向在后续步骤决定。
2. **做到多少算达标？** 目标、单位、每次记录步长和快捷增量。
3. **什么时候需要做？** 每日、工作日、指定星期、间隔或周期配额。
4. **怎样产生记录？** 手动、内置专注、Dock Tomato/番茄、问卷；第三方来源绑定继续在联动设置中完成。
5. **是否需要写回笔记？** 问卷目标、笔记锚点属于可选输出，应在明确用途后配置。

## 类型、排期、方向与附加能力的产品分层

| 规则维度/能力 | 新建时必须决定 | 适合的后续配置 | 页面提示 |
| --- | --- | --- | --- |
| 二值完成 | 做/不做，是否为戒除方向 | 排期、提醒、可选备注 | 目标固定为 1，不显示数量步长 |
| 数量 | 目标、单位、每次记录步长 | 快捷增量、排期 | 不把目标值当作实际记录值 |
| 时长 | 目标分钟/小时、记录方式 | 内置专注、Dock Tomato、手动数值 | 专注记录和手动补记都保留 |
| 周期配额 | 周期、次数/总量、计数口径 | 周期窗口预演 | 不伪造固定到某一天的任务 |
| 戒除/at-most | 上限目标、适用排期 | 破戒记录、宽限与复盘 | “记录一次破戒”与“完成目标”语义分开 |
| 问卷绑定 | 选择一个问卷模板或不绑定 | 文档目标在文档设置/问卷设置维护 | 绑定后打卡动作先填问卷，事件仍先落盘 |
| 笔记锚点 | 是否绑定已有块 | 回写属性/可选追加备注 | 只更新插件拥有内容，不等于来源读取 |
| 外部来源 | 不在此页配置凭据和文档 | 从联动设置按项目回链 | 编辑器只显示已绑定来源和去配置入口 |

编辑已有项目时，顶部应显示“正在修改已有项目”和影响范围；修改类型、单位、目标或排期先展示现有规则与新规则对照，确认后保存。删除、归档和恢复固定在危险操作区，不能与保存按钮混在一起。

### 交互原则

- **渐进披露**：新建首屏只显示模板、名称、类型、目标/单位、排期；类型相关字段立即出现，其他设置按“记录方式”“输出与组织”折叠。
- **类型 × 排期 × 方向驱动**：二值不显示无意义的目标输入；时长优先解释专注动作；配额显示周期窗口；每日戒除显示上限语义；字段变化同时更新预览和保存校验。
- **一条事实预览**：预览必须同时说明“今日卡片长什么样、按钮会做什么、目标/单位/排期是什么”；问卷、锚点和外部来源只显示其影响，不把未完成配置伪装成已启用。
- **模板是起点**：模板应用后进入同一表单，用户能看到被填入的字段；推荐、最近使用、组合包不与手工编辑形成两套保存路径。
- **第三方关系回链**：编辑器显示来源徽标、目标项目/来源状态和“在联动设置中配置”，不把所有第三方凭据、文档查询和宿主探测复制进新建页。
- **保存边界清楚**：新建项目一次提交；保存并继续清空名称/表单但保留模板选择上下文；失败保留草稿；编辑项目的影响对照取消时零写入。

## 分阶段改造步骤

1. 盘点字段与保存契约：为 `render/editor.ts` 的每个控件登记所属步骤、适用类型、默认值、校验、存储字段和依赖；确认类型、排期、联动、问卷、锚点和 Task Horizon 没有重复业务判断。
2. 建立三维规则驱动的表单模型：基础类型、排期和每日戒除方向共同决定字段、目标/单位默认值、记录动作及帮助文案；保留现有 `KIND_OPTIONS`、排期内核、问卷/锚点数据契约。
3. 重排模板与基础信息：把模板/空白选择收束为起点区，模板应用后回填同一表单；名称、图标、类型和目标组成第一步，推荐与组合包使用同一事件委托。
4. 拆出排期和记录方式：排期作为独立步骤，复用未来 30 天预演和规则变更对照；记录方式只处理手动/专注/问卷，外部来源展示回链状态。
5. 收拢高级设置：分成“输出”（问卷、锚点）与“组织”（分组、优先级、时段、自动归档、连断容忍、日历可见），按类型隐藏不适用项；危险动作单独放在页尾。
6. 重做预览与操作栏：预览同时展示记录动作、实际输入口径、排期摘要和缺失条件；桌面侧栏、移动底部固定操作栏共用同一状态，不制造第二套计算。
7. 兼容旧项目与保存状态：旧字段原样读取，类型切换显示明确的字段清除/保留提示；保存失败保留草稿，编辑影响对照和取消零写入；模板、问卷、锚点 ID 不因重排丢失。
8. 分阶段验收：字段/类型/排期守门 → 模板/问卷/锚点/联动回链接线 → 双语、键盘、IME、触屏和 320px～宽屏视觉 → 新建/编辑/保存并继续/失败恢复/危险操作真实内核回归。

## 不改变的边界

本原型不新增打卡类型，不改变 Store v3、事件身份、排期公式、问卷事实先落盘、文档写入旁路、锚点所有权或第三方来源契约。外部来源仍在联动设置中配置；编辑器只负责清楚呈现当前关系和跳转入口。
