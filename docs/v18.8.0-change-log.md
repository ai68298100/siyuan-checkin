# 小驴打卡 v18.8.0 变更记录

主存储 v3、公开 API v5、最低思源 3.8.4 不变；所有数据结构变更均为可选字段（旧数据零迁移，可直接从 18.6.0/18.7.0 升级）。

## 新建体验（第十一轮批次一）

- **联动预接线模板**（T-1486）：套用「步数/体重/阅读/问卷日记」模板时，编辑器给出联动绑定建议卡；确认后随项目保存生效（「保存后生效」计划可撤销，不静默启用）。健康收件箱从「步数/体重 → 单项目」升级为按项目映射：同一指标可挂载多个项目（例如按日与按周步数目标），每项目独立幂等身份；旧的单项绑定自动迁移并保留镜像字段，降级可读。
- **名称智能默认**（T-1487）：新建时按名称联想内置模板（中英文均可命中），未命中则按关键词推断类型/单位/目标/时段/排期（如「每天读书30分钟」「每周一三五跑步」）；建议行非阻断，应用前不改任何字段。
- **空状态一键装填**（T-1488）：库中无项目时，组合包预览提供「一键应用全部新增（N）」，逐条过模型归一化；「保存并继续」保持表单上下文连续创建；空状态模板区默认展开。
- **互补习惯动态推荐**（T-1489）：推荐位按已有项目动态生成（组互补配对、时段补位、类型多样性），排除已有项目（中英文名均可比对）；空库回退静态精选，全部命中时如实隐藏。

## 事项页强化（第十一轮批次二）

- **纪念日里程碑**（T-1491）：纪念日/生日自动派生「满 100/1000/10000 天、满 N 个月、满 N 周年（生日 N 岁）」投影；事项列表行与今日横幅展示，里程碑当天强调呈现。
- **时间表达升级**（T-1492）：纪念日/生日行显示自然历跨度「X 年 X 个月 X 天」；季度/半年/年度/间隔类长周期事项显示本周期进度条（明确为周期口径，不冒充完成率）。
- **那年今天**（T-1493）：今日页低干扰回顾卡聚合往年同日的打卡与事项锚点；每条可只读跳转当年日记（按宿主 dailynote 属性定位，找不到提示、绝不创建文档）。无历史不渲染。
- **单次改期与错过处理**（T-1494）：循环事项支持单次实例改期（实例覆盖，additive 字段）；上一周期未标记时行内中性提示并提供「补标记」（沿用按日期完成通道），不使用欠账样式。

## 问卷日记与入口

- **提示词轮换**（T-1484）：问卷模板每题可选配「提示词池」，按 ISO 周 hash 确定性轮换展示（同周同题、跨周轮换）；内置感恩三问/五分钟日记部分题目自带候选池；自建模板文本以「> 候选」行配置；轮换只影响呈现，事件与幂等标记不变。
- **页签默认打开方式**（T-1502）：设置 → 外观与交互新增「默认打开方式」（快捷弹窗/页签）；打卡命令、热键与顶栏按钮按偏好路由，页签可固定在布局并随重启恢复（仅桌面）。

## 设置、绑定与 UI

- 文档绑定闭环（T-1477）：保存前核验目标存在性与类型，总览显示名称/路径，请求失败保留配置与重试。
- 设置搜索定位到具体设置项（T-1478），支持结果跳转、清空恢复。
- 绑定目标卡片化（T-1485）：七类绑定目标入口统一为独立卡片（说明 → 搜索/选择 → 保存），窄屏纵排与 44px 触控。
- 问卷可视化编辑补题目复制、双向移动与键盘操作（T-1479）；设置页 UI/加载/失败态一致性复核（T-1480）；设置搜索与大记录量渲染性能优化（T-1481）。
- 笔记联动与来源管理：来源卡片统一状态与立即刷新（T-1386）；宽屏回顾布局编排（T-1483）；热图变体与周条对齐修复（T-1482、周热图日历周对齐修复）。
- **快捷指令配方**（T-1501）：健康收件箱文档整理为可照做的 iOS 步数/体重配方，补充到家、睡前、手动补录和分支场景、幂等验收与失败排查；明确当前只接受 `steps` / `weight`，不把任意健康指标名伪装成已支持能力。真实 iPhone/内核链路仍标为 `host-pending`。
- **笔记推导打卡**（T-1500）：固定只读 SQL 模板支持显式绑定的文档/笔记本范围与 frontmatter/tag 标记，使用 `notequery:<itemId>:<blockId>:<localDate>` 稳定身份；同日手动记录优先、重复和墓碑沿用既有幂等通道，失败回落为空结果。接入说明见 [note-query-integration.md](note-query-integration.md)。
