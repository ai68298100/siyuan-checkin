# 小驴打卡 0.9.2 → 1.0.0 路线

1.0.0 的目标是把当前可靠的打卡记录能力，提升为可长期使用的个人计划与复盘工作台。每个项目先独立完成逻辑、界面和回归验证，再合并到发布候选。

## 项目 A：模板与计划系统

- 用户模板完整管理：创建、应用、编辑、覆盖保护、删除和排序。
- 计划字段：目标、单位、频率、间隔、配额、分组、重要性和时间段。
- 内置模板与用户模板统一搜索、筛选和迁移。
- 重复提交、并发写入、旧数据和非法数据的恢复策略。
- 桌面侧栏、弹窗、页签和手机端保持同一数据语义。

## 项目 B：日期事项与提醒

- 生日、纪念日和固定缴费事项独立管理。
- 支持一次性、每年和自定义提前提醒天数。
- 当天事项进入今日页，提前提醒进入独立提醒区域。
- 完成、跳过、延期和历史记录语义明确。
- 提醒数据迁移、时区和跨日边界回归。

## 项目 C：思源智能体融合

- 复用思源已配置的智能体和模型，不重复维护 API。
- 提供只读总结、项目列表、单项洞察和明确确认后的记录能力。
- AI 不可用时保留完整离线功能和本地行动建议。
- 增加权限提示、失败回退、超时和能力版本兼容。
- 为智能体调用提供稳定示例和第三方扩展接口。

## 项目 D：跨窗口与移动端质量

- 侧栏、弹窗、页签和手机端的响应式布局统一。
- 真实浏览器视觉验证和 SiYuan-compatible mount 接入。
- 多窗口并发写入、数据变更通知和失败回滚。
- 安装包、版本、图标、README、Release 资产一致性。
- 性能、可访问性、键盘和触控回归。

## 发布门槛

- 四个项目均有可审查提交和测试结果。
- `pnpm test`、`pnpm run test:mobile:visual`、`pnpm run check:release` 和生产构建全部通过。
- 真实浏览器验证的阻塞必须有明确记录，不能以结构测试冒充截图验证。
- README、变更记录、迁移说明和回滚说明同步更新。
- 1.0.0 发布候选至少经过一次完整安装和升级路径检查。
