# 18.2.1 变更记录

外部来源体验收口：修复思播采样累计与健康收件箱身份两处缺陷，设置页五个外部来源入口聚合为折叠面板并内联今日累计预览，回顾报告来源筛选扩展到思阅/思播。主存储 v3、契约 storeVersion 2、最低思源版本 3.8.4 不变；公开 API v5 能力面不变（20 项）。

## 修复

- **思播采样累计**：此前按单段采样向下取整，15 秒采样周期永远累计不到 1 分钟——现按原始毫秒跨段累计、按分钟晋升（`floor(dayMs/60000)`），时长项目能正常达标结算；补真实内核 E2E 用例。
- **健康收件箱身份**：幂等身份从 `health:<指标>:<日期>` 升级为 `health:<项目>:<指标>:<日期>`，消除多个健康项目绑定同一指标时的写入互相覆盖；启动时先补一次收件箱 ingest（此前要等首个轮询周期）；E2E 升级为按项目身份矩阵。

## 增强

- **设置页外部来源聚合（T-1386）**：日记/摘要驻留/思阅/思播/健康五组入口收进单个折叠面板，摘要行显示已启用数量（i18n 1597 对键保持对等）。
- **来源今日分钟预览（T-1386 首切片）**：思阅/思播启用时在设置行内实时显示「今日已累计 N 分钟」。
- **回顾报告来源筛选扩展**：报告与偏差对比的来源筛选新增「思阅阅读」「思播观看」，白名单同步扩展（`bind-page-navigation` 与类型口径一致），筛选同时作用于当前与基线口径。

## 工程与质量

- 真实内核 E2E 新增思阅生命周期用例（事件→片段→结算→幂等→防伪，含生命周期事件前缀映射修复）。
- 新增 `tests/upstream-proposals.test.cjs` 守门（入 test:ui 与 test:ecosystem）：三份上游公开 API 提案草案（思阅生命周期/结算、思播播放事件/有效时长、Task Horizon 日历投影消费层）+ draft 夹具 + 文档↔夹具↔代码三方同步（前缀注册表、calendar.read since 5、刷新事件、投影六态、隐藏过滤）；强制 D-255 双轨纪律与隐私红线成文，外部 issue/PR 零提交。
