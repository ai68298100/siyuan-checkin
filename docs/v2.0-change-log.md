# 2.0 开发变更记录

## 已完成

- 统一今日、历史、总结、复盘、日期事项、模板管理和编辑器的视觉表面。
- 建立主题角色、密度、焦点、动效、减少动效、高对比度和强制颜色模式支持。
- 完善桌面宽屏、窄容器、移动触控和横屏低高度布局。
- 增加加载、空态、错误、同步提示和打印展示规则。
- 跨插件 API 升级为 v4 元数据协议，提供 `name`、`protocol`、`version`、`capabilities` 和 `getCapabilityInfo()`。
- API 描述快照增加存储版本与事件名称，提供 `hasCapability()` 做调用前检查；能力清单只声明实际开放的方法。
- 事件名称纳入统一契约并在运行时校验，防止生态订阅名称与公开协议漂移。
- 保持无 AI、无外部插件时的离线核心流程和既有数据语义。
- 界面密度偏好已接入今日页操作并持久化到视图设置，侧栏、页签、弹窗共享同一状态。
- 密度循环逻辑抽为可测试的偏好工具，统一标签和切换顺序，避免不同入口出现不一致文案。
- 设置中心已提供主题、减少动效和当前配置摘要，外观偏好与视图偏好统一持久化。
- 所有页面根容器统一注入密度、主题和动效状态，避免不同入口出现外观偏好不一致。
- 增加跨页面外观状态结构回归，防止新增页面遗漏个性化属性。
- 减少动效规则扩展到所有页面根容器，设置页之外的历史、总结、事项和编辑器也保持一致。
- 浅色/深色外观偏好增加局部颜色角色覆盖，确保主题选择不仅影响控件原生配色，也影响页面表面和文字层级。
- 两种主题同步覆盖强调色、成功/警告/危险状态和阴影强度，保持反馈层级一致。
- 设置中的密度选项、主题选择和复选框补齐键盘焦点反馈。
- 设置摘要区域增加实时状态语义，切换偏好后辅助技术可获得即时反馈。
- 设置中心支持恢复全部显示偏好，不影响任何打卡数据和项目配置。
- 恢复全部显示偏好增加明确确认步骤，避免移动端误触。
- 密度单选组支持左右方向键循环切换，并立即同步持久化状态。
- README 已补充显示设置、主题、动效和偏好重置的用户说明。
- 偏好文档回归同时检查桌面和移动端设置入口，以及主题和动效控件标记。

## 延后到 2.0 统一实测

- 思源桌面端、移动端和浏览器容器截图验收。
- 跨版本升级、回滚、多窗口并发和真实生态插件兼容验证。
- 根据实际使用反馈调整布局、交互和性能参数。

## 当前开发状态

当前发版版本为 `2.0.0`。`package.json`、`plugin.json`、构建产物和安装包必须保持同一版本；真实环境实测按约定延期到发布后统一进行。

1. 继续完善设置、主题、密度和移动端入口的一致性。
2. 完善生态 API 的能力发现、事件契约和第三方接入示例。
3. 继续压缩重复样式和页面级分支，保持数据语义不变。
4. 在 2.0 功能冻结后统一处理真实环境、升级回滚和兼容性实测。
