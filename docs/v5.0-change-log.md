# 5.0 变更记录

## 概览

5.0 是一次结构性重构：样式系统、导航、页面信息架构全部按《v5 重构蓝图》（`docs/v5-redesign-plan.md`）重建。数据模型、存储语义、跨插件 API（v4）与智能体能力保持不变，升级无需迁移操作；旧显示偏好中的密度设置会被静默忽略。

## 破坏性变化

- **导航收敛为五项**：今日 / 回顾 / 日期事项 / 归档 / 设置。原【历史】【总结】【复盘】三个页面融合为【回顾】。
- **界面密度移除**：设置项、快捷按钮与 CSS 变量全部删除。
- **样式系统重写**：`src/ui/`（tokens + components，容器查询驱动）取代 legacy + 8 个 v4 补丁层的叠加架构（legacy 保留为底层地板，逐步退役）。

## 新增

- **容器查询四档形态**：完整桌面（≥1000px，左导航 + 双栏）、中等、速记（<720px，手机/侧边栏共用，一条一动作）、弹窗。布局随容器宽度而非窗口宽度切换，修复侧边栏与窄弹窗中的碎裂布局。
- **回顾页**：日历热力图（密度底色 + 记录徽章）、按日明细、范围统计条、项目汇总表（可下钻到单项目复盘）、近期事项 60 天时间线、智能总结。
- **日期事项引擎**：一次性 / 每年（公历 + 农历，含闰月；月内第 N 个星期 X）/ 每月（固定日、第 N 个星期 X、月末）/ 每周 / 每季度 / 每半年 / 自定义间隔（天、月、年）。农历为本地换算（1900–2100，经春节、中秋、闰六月锚点与 500 例回环验证）。
- **日期事项模板**：21 个常用模板（生日公历/农历、纪念日、房贷、车贷、房租、物业、保险年/季缴、信用卡、年检、体检、订阅、域名、工资、情人节、母亲节、父亲节、七夕、中秋、春节）。
- **日期事项行内编辑**：每行可直接编辑 / 启停 / 删除，显示重复描述与下次日期倒计时。
- **编辑器向导**：图标选择器收起为单格弹层（搜索 / 9 组 / 自定义全部在弹层内）；桌面端右栏常驻实时卡片预览与保存按钮。
- **弹窗尺寸偏好**：按屏幕比例（默认 80%，50–100% 可调）/ 全屏 / 固定大小三档，设置页调整。
- **今日页显示偏好**：七日概览默认关闭，可在设置开启。
- **系统级快捷键说明与 AHK 伴生脚本**：`docs/system-shortcut.md`。

## 改进

- 今日页头部压缩为一行（标题 + 日期 + 进度胶囊 + 新建），首屏直接是打卡列表；已完成项折叠为一行。
- 打卡行为单行结构：图标进度环 + 名称 + 元信息 + 大号操作钮；左侧色条、整卡染色、大卡片全部移除。
- 日期提醒降级为全宽细横幅（最近事项胶囊 + 管理入口）。
- 桌面端新增带标签的左侧导航栏，当前页实心圆片高亮；移动端底部导航五项 + 悬浮新建。
- 页面头部不再粘性悬浮，消除滚动时的标题重叠。
- 深色主题在所有页面按 `data-appearance` 正确生效（"跟随思源"解析思源主题模式）。

## 验证

- `pnpm test`、`test:ui`、`test:mobile`、`test:ecosystem`、`check:release` 全部通过。
- 视觉 harness（`tests/visual-qa.cjs`）浅色 + 深色双主题、320–1180px、四档容器形态全部通过，无页面错误。
- 产物 CSS 285KB → 约 246KB（预算 <160KB 在 legacy 地板退役后达成）。
