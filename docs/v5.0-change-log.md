# 5.0.x 变更记录

## 5.0.1（2026-09-11）

### 独立主题（脱离思源主题）

- 固定明亮 / 暗黑两套自带色板，照参考设计定死：淡紫蓝画布、纯白卡、紫罗兰主色、暖橙连续强调、20px 大圆角、柔和紫影；暗黑为深空底 + 亮薰衣草。思源主题不再影响插件配色。
- 插件作用域内将 `--b3-*` 重定义为固定色别名：legacy 底层样式自动继承新设计，且不污染宿主思源。
- 设置仍提供 跟随思源 / 明亮 / 暗黑 三选；"跟随思源"只跟随思源的明暗模式。
- **实时跟随**：思源切换明暗主题后约 50ms 内，所有打开的打卡页面同步切换色板。

### 布局与体验

- 宿主宽度自适应修复：全屏 / 80% 弹窗 / 窄窗口 / 侧边栏四种宽度下布局正确（修复 flex margin-auto 收缩、编辑器被 legacy 多列 grid 挤成竖条、今日货架半空、名称被挤截断、筛选胶囊拉伸等）。
- 侧边栏底部导航与悬浮新建按钮锚定在面板内部，不再横跨整个思源窗口。
- 手机速记形态：单列清单（修复多列溢出）、行式卡片两行以内、42px 大打卡钮、次要按钮与普通标签退出首屏。
- 回顾"自定义日期"改为浮层；当日明细行窄列换行；范围切换文字不再竖排。
- 行内次要按钮（复盘 / 编辑）改为悬停浮现，名称优先显示；已完成卡边框实线化。

## 5.0.0（2026-09-10）
