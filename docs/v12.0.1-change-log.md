# 12.0.1 变更记录

12.0.1 是 12.0.0 的跨端界面与刷新可靠性维护版本，不改变本地数据格式。

## 侧边栏与跨端布局

- 窄 dock 底部导航固定为五个可收缩的等分轨道，图标和标签在各自轨道中居中。
- 长导航标签使用省略显示，卡片正文、标签和主操作按钮允许安全收缩，避免窄侧栏横向溢出。
- 宽 dock 导航按钮均匀分配可用宽度，同时保留可用的最小点击宽度。
- 延续单一滚动所有权、安全区和 320px 极窄布局保护，不复制参考插件的品牌视觉或多重滚动结构。

## 打卡刷新可靠性

- 局部刷新携带实际事件日期；历史日期事件不会错误改写今天的卡片。
- dock、页签和快速窗口先完成统一预检，再执行局部 DOM 更新，避免多表面部分更新。
- 完成/撤销、完成区归属、准确记录、拖拽和批量节点发生变化时回退完整投影，避免失效按钮或卡片残留在错误分区。
- 删除事件的分析更新时间采用事件实际日期，保持历史统计口径一致。

## 验证

- 类型检查、生产构建、主测试、UI、移动端、生态、性能和发布资源门禁通过。
- 浏览器宽度走查覆盖 360px 至 2000px，未发现横向溢出。
- 真实思源桌面、移动、dock、安全区、软键盘及番茄钟双窗口仍需要现场复核；自动化验证不替代真实宿主验收。
