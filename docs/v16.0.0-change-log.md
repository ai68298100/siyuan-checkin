# 16.0.0 变更记录

16.0.0 是复盘基线比较版本：为相同跨度的当前与前置范围提供可追溯的差值模型，并继续收紧 Task Horizon 生态契约与自动化验证边界。

## 复盘范围比较

- 新增纯函数 `buildReviewComparison(current, baseline)`，输出范围总事件、完成项目、计划项目及其 delta。
- 输出逐项目 `current`、`baseline`、`delta`，按项目并集比较，当前或基线缺失项目自动补零。
- 新增 `getPreviousReviewRange()`，可从当前本地日期范围推导同跨度的前置范围；非法日期和逆序范围安全返回 `undefined`。
- 比较结果与输入对象解耦，不修改 store 或调用方数据，便于 UI、导出和后续分析复用。

## 生态与质量

- 延续 Task Horizon bridge 的协议探测、重试、并发单飞、停止竞态和 300 项压力/replay 矩阵覆盖。
- 新增范围比较专用测试并接入统一 `test:quality` 门禁。
- 自动化质量链覆盖类型、构建、主功能、UI、移动端、生态、扩展、性能和发布资源检查。

## 验收边界

自动化质量链通过不等于真实思源宿主验收。真实桌面、页签、dock、移动软键盘、多窗口及 Task Horizon 双方联调仍需在目标客户端完成。
