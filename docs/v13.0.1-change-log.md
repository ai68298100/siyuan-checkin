# 13.0.1 变更记录

13.0.1 是 v13.0.0 的紧急修复版本，修复编辑器新建条目保存被写后校验误判失败并回滚的缺陷，同步浏览器质量走查的宿主保真与期望值。不改变打卡、统计与提醒的用户可见口径。

## 修复

- 编辑器新建条目保存失败回滚：v13.0.0 的写后回读校验以 JSON 指纹比较期望快照与回读快照，normalizeStore 会把缺省的 archived 物化为 false，而编辑器构造的新条目省略该字段，两侧指纹永不等价，导致保存被误判为并发覆盖、重试后抛错并回滚。现编辑器构造条目物化 archived 缺省值，克隆快照作为防御边界同步物化，与规范化字段集合严格一致。
- 该缺陷由 CI browser-audit 的视觉走查（双击提交步骤）拦截，真实思源环境中同样会导致新建条目无法保存，v13.0.0 用户应尽快升级。

## 质量走查宿主保真

- 浏览器 QA 宿主的存储模拟改为按存储名分槽，主打卡 store 与偏好、备份、审计等存储互不覆盖，与真实思源 loadData/saveData 契约一致；写入内容不可克隆时明确 reject，不再静默挂起。
- "阅读"模板的目标值步长期望同步 T-1091 的步长分离设计（目标输入统一两位小数，快捷动作默认值不变）。
- 双击提交步骤等待卡片渲染完成后点击，消除"活跃 store 乐观可见早于表面重渲染"的竞态误报。

## 验证边界

- 完整质量链（类型、构建、主功能、UI、移动端、生态、扩展性能门禁、发布资源）与浏览器视觉走查全部通过。
- 真实思源多窗口并发、dock、安全区与软键盘行为仍需现场复核；自动化结果不替代宿主验收。
