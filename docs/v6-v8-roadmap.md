# 小驴打卡 6.0 / 7.0 / 8.0 开发方案

> 状态：✅ 全部已发布（2026-09-10 一日内完成 6.0.0 / 7.0.0 / 8.0.0 三个版本）。制定日期：2026-09-11。基线：v5.0.1（容器查询布局、五项导航、回顾融合页、农历事项引擎、编辑器向导、独立双主题）。
> 执行约定：每个版本按阶段推进，每阶段出口 = 全部测试链绿 + 双主题 harness 绿 + 该阶段验收点；版本完成后打 tag 发 Release。

---

## 总路线图（一句话版）

| 版本 | 主题 | 一句话 |
| --- | --- | --- |
| **6.0** | 效率与生态 | 让每日使用更快（拖拽排序、批量操作、内置专注计时），把番茄钟等外部插件联动真正落地 |
| **7.0** | 洞察与记录 | 让积累的数据更有价值（趋势图表、图文打卡日志、成就徽章、数据导入、智能体 v2） |
| **8.0** | 打磨与平台 | 细节走查、主题色板系统、万级数据性能、国际化、集市上架 |

优先顺序依据：打卡工具的留存核心是"每天用得爽"（6.0）→"坚持有反馈"（7.0）→"长期可靠可推广"（8.0）。外部依赖少的自包含功能排前，涉及生态联动的排中，纯打磨排后。

## 6.0 效率与生态 ✅（v6.0.0 已发布）

### P0 今日清单拖拽排序
- 内容：行左侧悬浮排序把手（桌面 hover 显现、移动长按把手）；指针拖拽实时换位；落点持久化 `sortOrder`（组内连续重编号）；排序方式为"自定义顺序"时生效。
- 步骤：① 把手 UI + 指针拖拽状态机（pointerdown/move/up + 占位高亮）② 落点计算与组内重排 ③ 持久化（复用 mutation 队列）④ 键盘可达（Alt+↑↓ 移动）⑤ 测试：重排后顺序持久、撤销不影响。
- 出口：桌面鼠标 + 手机触摸都能拖动，刷新后顺序保持。

### P1 批量操作
- 内容：今日页长按/右键进入多选模式 → 全选本组 / 批量完成 / 批量归档 / 批量改分组；历史明细批量撤销。
- 步骤：① 多选状态与选择条 UI ② 批量动作走既有 mutation 队列 ③ 移动端长按进入 ④ 测试。
- 出口：10+ 项的操作 3 次点击内完成。

### P2 内置专注计时（番茄钟联动基座）
- 内容：详情行"专注"按钮 → 弹出倒计时面板（默认 25 分钟，可调）；结束自动按"专注分钟"记录一次；数据 `source: "manual-focus"`；已有 `registerFocusAdapter` 保持不变——外部番茄钟插件可覆盖内置面板。
- 步骤：① 计时面板 UI（剩余环 + 暂停/放弃）② 完成时自动 recordEvent + 备注"专注 25 分钟" ③ 设置里可改默认时长 ④ 文档声明适配器优先级（外部 > 内置）⑤ 测试：计时完成落账、中途放弃不落账。
- 出口：不装任何插件也能"选项目 → 专注 → 自动记录"。

### P3 日期事项 → 打卡项联动
- 内容：日期事项行新增"生成打卡项"：以事项名建一个一次性打卡项（当日出现在今日页），完成后自动把事项标记为已处理。
- 步骤：① 动作与弹窗（复用编辑器预填）② 完成联动（事件落账时勾选事项 occurrence）③ 测试。
- 出口：生日/体检日当天在今日页直接可见可打卡。

### P4 生态文档与示例
- 内容：`docs/ecosystem-integration.md` 补全为对接手册；`examples/` 增加最小示例插件（10 分钟接入演示：读项目 + 写一条记录 + 订阅事件）。
- 出口：按文档操作的新插件可完成一次 recordEvent 并被去重。

### P5 发版 6.0.0
- 全量测试 + 双主题 harness + 宽度走查 + 变更记录 + Release。

## 7.0 洞察与记录 ✅（v7.0.0 已发布）

### P0 趋势图表（轻量 SVG，零依赖）
- 内容：回顾页新增"趋势"区：近 12 周完成率折线、近 6 月记录数柱状、分组占比条。复用现有聚合函数，不引第三方图表库。
- 步骤：① SVG 图表基础组件（折线/柱状/横条）② 聚合查询（按周/月桶）③ 回顾页右栏接入 ④ 空数据态 ⑤ 测试（聚合正确性）。
- 出口：一周使用后能看到趋势变化。

### P1 图文打卡日志
- 内容：记录时可附 1 张图片（≤500KB，存插件数据）+ 短文本；回顾页"日志"时间线按天展示图文卡。
- 步骤：① CheckinEvent 扩展 `attachments`（迁移规范化）② 记录弹层加图片选择 ③ 日志时间线视图（回顾页新 tab）④ 存储预算提示 ⑤ 测试（迁移与去重）。
- 出口：坚持打卡的同时能留下"图文日记"。

### P2 成就徽章
- 内容：首卡、连续 7/21/100 天、单日全清、百日全勤、早起鸟（晨间卡 ≥20 次）、夜猫收敛等 12 枚；回顾页成就墙 + 达成时顶部庆祝条。
- 步骤：① 徽章定义与判定引擎（纯函数、可测试）② 达成检测与持久化 ③ 成就墙 UI ④ 庆祝动效（尊重 reducedMotion）⑤ 测试。
- 出口：徽章判定全部可从事件数据推导、可重放。

### P3 数据导入向导
- 内容：设置 → 数据 → 导入：CSV/JSON 映射到项目 + 历史事件（列映射预览、冲突策略、导入报告）。
- 步骤：① 解析与列映射 UI ② 校验与预览（将导入 N 项目 M 事件）③ 导入（走 mutation 队列，分批）④ 报告与回滚说明 ⑤ 测试。
- 出口：从其他打卡工具导出的 CSV 可在 5 分钟内迁入。

### P4 智能体能力 v2
- 内容：新增 4 项——`checkin-list-upcoming`（近期事项）、`checkin-create-item`（代建打卡项，需用户确认）、`checkin-create-occasion`（代建日期事项）、`checkin-weekly-report`（生成周报文本）；既有 6 项保持兼容。
- 步骤：① 能力描述与协商扩展 ② 只读两项实现 ③ 写入两项（复用确认与并发锁）④ 提示词示例文档 ⑤ 测试。
- 出口：思源智能体可回答"下周有什么要提醒的"并可代建事项（带确认）。

## 与其他插件的合作方式（长期承诺）

1. **API 稳定**：`window.siyuanCheckin` 协议 `siyuan-checkin`、API 版本 4 起只增不破；破坏性变更升大版本并保留旧能力两个大版本。
2. **能力协商**：第三方必须先 `hasCapability()` / `getCapabilityInfo()` 再调用；不支持时隐藏入口而非报错。
3. **去重契约**：外部写入必须带稳定 `externalRef`；同引用重放安全。
4. **适配器**：专注（focus）与总结（summary）两类适配器，外部注册优先于内置；适配器异常不得阻塞手动打卡。
5. **不读他人存储**：一切协作走公开 API。

## 与思源智能体的结合（长期方向）

- 6.0：保持 6 项能力稳定。
- 7.0：能力 v2（+4 项，见上），补齐"查询→建议→代操作（确认）"闭环。
- 8.0：智能体提示词模板内置（周报/复盘/规划三种一句话场景）。
