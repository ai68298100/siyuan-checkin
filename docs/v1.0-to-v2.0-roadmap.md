# 小驴打卡 1.0.0 → 2.0.0 长期路线

1.0.0 发布后继续保持“主线整合 + 隔离大项目”的开发方式。每个阶段先完成一个可独立验收的大项目，再合并和发布小版本。

## 1.1：稳定性与可迁移

- 完整升级迁移向导、备份与回滚。
- 多窗口并发写入冲突提示和恢复。
- 思源桌面端、移动端和浏览器容器兼容矩阵。
- 发布资产、安装和卸载路径自动检查。

## 1.2：提醒与计划增强

- 生日、纪念日、缴费和固定事项的提醒中心。
- 提前提醒、重复规则、跳过、延期和完成历史。
- 月历、今日页和外部任务入口的统一事项语义。

## 1.3：分析工作台

- 日 / 周 / 月 / 自定义范围仪表盘。
- 分组、优先级、时间段和目标类型分析。
- 趋势、热力图、完成率分布、连续记录和异常波动。
- 可导出的复盘报告和本地建议。

## 1.4：AI 协作

- 思源智能体上下文、权限和确认流程稳定化。
- 可插拔总结、计划建议、异常解释和自然语言记录。
- 无 AI 降级路径、离线缓存、超时和错误恢复。

## 1.5：生态与自动化

- 番茄钟、任务管理器、日历和快捷入口适配器目录。
- 外部事件去重、来源追踪、双向同步和冲突策略。
- 第三方插件 SDK、示例和兼容版本声明。

## 1.6：个性化体验

- 主题变量、布局密度、图标包和快捷操作自定义。
- 桌面侧栏、弹窗、页签和手机端的个性化入口。
- 可访问性、键盘、触控和低性能设备优化。

## 1.7：现代 UI 重构

- 建立完整视觉 token、排版、间距、表面、状态和动效规范。
- 重构今日、历史、总结、复盘、日期事项、新建和设置页面。
- 宽屏采用信息分区和双栏编排，窄窗口与手机端保持内容可读、操作可达。
- 增强层级、重点和反馈质感，不再局限于简单留白和同质化卡片。
- 统一侧栏、弹窗、页签与移动端容器体验。
- 详细实施范围见 `docs/ui-redesign-roadmap.md`。

## 2.0：平台化工作台

- 统一事件、计划、提醒、分析和集成协议。
- 面向第三方插件的稳定扩展 API 和能力发现机制。
- 可组合的今日、日历、复盘和 AI 工作区。
- 完整的备份、迁移、权限、审计和回滚能力。
- 2.0 发布候选必须经过跨版本升级、真实桌面 / 移动端验证和生态适配验收。

## 发布原则

- 每个阶段只在验收、测试、构建和文档齐全后发布。
- 主线负责冲突处理、统一数据语义、测试和打包。
- 独立任务负责边界清晰的大项目，完成后一次性反馈。
- 发现主流程回归时暂停新功能，优先修复并补充回归测试。
