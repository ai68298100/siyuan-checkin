# 全插件 UI 细节审计与设计落地

范围：T-1317–T-1322。继续已批准的浅紫画布、白色表面、紫色重点和独立深色主题；这轮目标是信息更清楚、动作更确定，不是简单缩小所有东西。

## 参考方式与取舍

参考来源为官方公开产品页面：

- [Habitify](https://www.habitify.me/)：官网产品图采用桌面左导航、中间紧凑列表、右侧项目统计；手机每行以图标/名称/进度和单个主动作组织。借鉴主次关系和按需详情。
- [Streaks](https://streaksapp.com/)：官网手机图使用大圆图标、进度环和实心完成状态，且明确最多24项任务。借鉴状态辨识，不照搬大圆卡铺满30项。
- [Loop Habit Tracker](https://loophabits.org/)：官网首屏产品图同屏11项习惯、最近5日横向排列，数值型直接显示量与单位。借鉴稳定行高与少重复说明，手机不强塞5日表格。
- [everyday](https://everyday.app/)：官网演示以习惯为行、日期为列，用连续色带呈现历史，右侧集中统计连续/最长/总次数。适合回顾热图，不挤占今日行动首屏。

这些是实际打开官方网页、查看产品展示图后的参考，不是安装或登录后的完整产品体验；本地审计截图位于`.artifacts/reference-audit/`，未将其商标或资产用于插件。本插件具有备注、事项、番茄联动和思源多宿主约束，不机械照搬截图。尤其不采用大面积单习惯圆盘：用户有20–30项，这种形式会显著增加滚动。连续记录是鼓励，不把中断表现为错误或丢失历史。

## 全局设计准则

| 细节 | 规则与本轮处理 |
| --- | --- |
| 信息优先级 | 今日先行动，回顾先结果与日期，设置先类别；重复数字放到展开区域 |
| 表面 | 画布浅紫/深色，内容以单层表面为主；事项不再紫卡套白卡 |
| 形状 | 导航保留胶囊；搜索、筛选、批量工具、表单与记录按钮使用较克制的圆角矩形 |
| 字体 | 沿用统一系统无衬线栈；主字段约13–14px，设置标题16px，说明约12px；不把所有小标签强行放大 |
| 数字 | 今日进度使用等宽数字，单位与剩余量降低权重；统计不重复堆叠 |
| 图标 | 更多入口线条与大小增强，折叠使用统一方向图标；照片使用同体系矢量图标，不依赖平台emoji |
| 触控 | 分组、筛选、批量、模板、事项筛选/新建、设置开关等关键控件44px；图形可小但命中范围不可过小 |
| 焦点 | 插件原生按钮、输入、选择、文本框、summary统一清晰focus-visible；附件label保留focus-within |
| 状态 | selected同时有底色/边界和aria；disabled保留明确禁用语义；完成/停用不将整块内容过度淡化 |
| 动效 | 卡片悬停不再位移，避免点击目标移动；保留既有减少动态选项，不新增循环动画 |
| 容量 | 窄端紧凑横卡、宽屏多项2–3列；完整名称换行，不靠裁字或降低触控面积容纳30项 |

## 逐页问题与落地

### 今日

1. “不分组”在设置中存在，但渲染分支漏掉，实际上仍按项目group拆组。修为一个“待完成”区，排序保持；筛选中补回同一选项。
2. 只有32px高的分组按钮，看起来整行可点但实际触控偏小；改44px并保持首卡高度预算，增加展开方向图标。
3. 展开筛选后选择框30px、仅未完成按钮36px；按真正可见控件验收，统一44px。
4. 多选原来在主动作旁新增选择框，时长卡从110升154px且仍能误打卡。现在只保留选择入口；名字/图标变非编辑非打卡内容，选中卡有底色与边界，批量按钮44px。
5. 多选快捷键：Alt+数字不触发记录；j/k定位选择按钮；e不进入编辑；连续天数变为非交互标识，右键/长按不弹单项编辑菜单，避免模式冲突。
6. 搜索与筛选从“每个都是胶囊”调整为工具条圆角矩形；底栏当前页改浅色选中底，避免同时出现多个强色悬浮感按钮。
7. 已完成项目不再整卡降透明度并划线，名称仍可阅读；原撤销行为保留。
8. 窄端日期事项把标题/管理与具体事项分行，事项名称占完整宽度，避免长名称被挤进圆形小胶囊逐词折行。

### 回顾

1. 原首屏三指标、总结文字、对比三指标重复表达同一组数据，手机月历出现太晚。
2. 对比改原生details，默认只显示标题与基线日期；展开仍有三指标、增减和比较图，未删除数据。
3. 总结中的记录数/完成数等重复文字移入行动建议；截止日、重点标题与完成率保持可见。
4. “较上期”子导航直接展开并定位顶部对比，避免用户点后不知道去了哪里；其他区块导航维持。
5. 保留图表与数字各自的职责：不是通过一律隐藏图表换取密度。

### 新建与编辑

1. 宽屏原高级配置被压进窄右栏，左边留空；改基础字段+预览上排，高级配置下排双栏组织。
2. 字段标签、说明、输入形成清楚层级；文本输入44px，原18px复选框不受影响。
3. 模板summary曾被旧样式设为display:none，页面只剩空胶囊；恢复所有端可见、44px、键盘展开和实际模板选择。
4. 短横屏旧form-scroll max-height:58vh让模板内容缩到后续字段下面；取消这条限制，子块不压缩，保留正常滚动和保存栏可达。
5. 模板与预览保持单层；不是用多个同色大框区分不同任务。

### 复盘与归档

1. 手机复盘顶栏漏了路由分支而显示“今天”；改为“习惯复盘”，页内继续显示当前项目名称。
2. 复盘指标窄端单行组织，减少重复纵向空间；建议主文字提升，长名称与证据保持换行。
3. 归档手机已有宿主返回，移除重复页内返回栏；保留真实恢复/删除及批量入口。

### 设置

1. 去密集表格行线，用标题、空隙、控件列而非多重边框表达分区。
2. 标题16px、主文字14px、说明12px；分类选中采用轻色矩形，避免整页像一串胶囊。
3. 开关实际44px触控区，轨道维持38×22px；清晰键盘焦点、Space切换和aria语义不变。
4. 保留收件箱分批、长状态换行、危险数据操作既有确认，不为视觉隐藏必要诊断。

### 日期事项

1. 白底列表与轻分隔替代多层紫卡；顶部数量和标签分层展示。
2. 停用项不再整行半透明/划线：名称与动作仍清楚，用明确停用标签和虚线表达状态。
3. 删除使用危险色并与常用动作留间隔，但确认流程不变。
4. 修复窄端筛选summary隐藏；实际筛选→显示停用项→清除全部可操作。
5. 新建按钮显式44px宽高及flex尺寸，避免旧40px轨道压缩；小屏动作放在整行，长名不挤出页面。

### 精确记录与专注

1. 附件以统一相机图标呈现；file input有明确辅助名称，键盘焦点可见。
2. 专注时长预设提供“15分钟”等辅助名称，aria-pressed随选择同步；不再只依靠颜色区分。
3. 暂停/继续/完成/放弃及“本次记录”补双语；不改变计时或写入协议。
4. 长专注名保留全文辅助/悬停名称，窄面板不无限撑高；短横屏进入正常内容流。

### 强调色与暗色可读性

实际生产bundle检查四种强调色×浅深两主题的快捷打卡、记录和保存按钮。发现暗色蓝/绿/橙仍继承浅色按钮底色，却使用暗色文字，文字对比度只有3.53/3.71/3.84。局部修正三组暗色`accent-fill`，使用各自已有的明亮强调色，保留暗色文字；紫色及四组浅色不变。新增八组令牌对比度守门，实际按钮结果记录于最终验收日志，不把这项检查宣称为整个产品的无障碍认证。

修后实测（每格均覆盖快捷打卡、记录、保存；日志`.artifacts/palette-primary-contrast-final.log`）：

| 强调色 | 浅色文字对比度 | 暗色文字对比度 |
| --- | --- | --- |
| 紫 | 4.70:1 | 6.67:1 |
| 蓝 | 5.20:1 | 7.31:1 |
| 绿 | 4.95:1 | 8.11:1 |
| 橙 | 4.78:1 | 8.58:1 |
