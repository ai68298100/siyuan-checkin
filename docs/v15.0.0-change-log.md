# 15.0.0 变更记录

15.0.0 是跨端交互与批量事务版本：Today 卡片菜单覆盖鼠标、触屏和键盘；完成、归档、删除收敛为批量事务；归档页补齐摘要与批量管理；删除和自动归档进一步加强多窗口一致性及十万级数据性能。

## Today 交互

- 卡片支持桌面右键、触屏和触控笔长按打开编辑、归档、删除菜单；移动超过阈值会取消长按，菜单自动限制在视口内。
- 上下文菜单采用标准 menu/menuitem 语义，支持方向键、Home、End、Tab 和 Escape；关闭后恢复原卡片主操作焦点。
- 菜单和批量工具栏执行期间整组禁用并暴露 `aria-busy`，同步异常和异步失败都能释放守门并保留可见反馈。
- 全选仅作用于当前搜索和筛选结果；重渲染会剔除不可见旧选择。勾选、计数与按钮状态采用局部更新，避免焦点和滚动跳动。

## 批量事务与并发安全

- 批量完成、归档、删除各自只进入一次 mutation 队列并持久化一次；失败回滚完整快照，取消或失败时保留选择以便重试。
- 新增批量事件追加核心，复用事件 ID、externalRef 和墓碑幂等守门；成功后仍逐条发送兼容事件，只合并分析刷新信号。
- 单项、Today 批量和归档批量删除在用户确认后、实际写入前重新核对项目数和记录数；跨窗口影响变化时安全中止。
- 单项删除统一进入 storage mutation，Today 上下文删除成功后立即移除卡片，不留下幽灵状态。

## 归档与自动归档

- 归档页新增累计达成天数、最近记录日期/时间，并使用一次性按项目事件投影避免重复扫描。
- 支持筛选结果全选、批量恢复和批量删除；窄容器下操作区自动回流，恢复/删除动作具备行级互斥与稳定焦点回退。
- 多个项目在批量完成后同时达到自动归档阈值时，共享一次后续事务和持久化；每个真实转换仍依次发送 `item-updated` 与 `item-archived`。
- 单项目保留带名称和天数的提示，多项目使用聚合反馈，避免连续通知互相覆盖。

## 生态与公共 API

- 新增 `getEventRangeSummary`：按半开本地日期区间输出每日数量、数值和单位聚合，默认限制 366 天、5,000 条事件及 366 个日期点。
- 摘要只使用事件 `localDate`，不从 UTC 时间戳推导日历归属；结果不暴露 store、备注、附件或原始事件对象。
- 新增“任务打卡”配额模板，并更新 Task Horizon 合作契约；自动归档增加专用 `checkin:item-archived` 通知。

## 性能与质量

- 建立回顾页 1k/10k/100k 事件范围查询、汇总、分析快照与导出序列化基线。
- 增加 100k 历史追加 1,000 条事件、100 项/100k 事件批量删除，以及 50 项/100k 事件自动归档资格投影门禁。
- 完整质量链覆盖类型、构建、主功能、UI、legacy 样式、移动端、生态契约、扩展性能和发布资源；98 个测试文件纳入执行脚本。
- 真实思源桌面、页签、dock、移动端软键盘与多窗口焦点仍需要目标客户端现场复核，自动化结果不替代该边界。
