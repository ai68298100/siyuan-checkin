# v18.17.0 变更记录

批次：双机合并后的事项工作台、微信读书推荐与跨表面可靠性收口（2026-10-08）。

## 微信读书推荐

- 新增确定性的阅读时长推荐引擎与候选事实映射。
- 设置页新增推荐草案预览；推荐与启用分离，只有用户点击应用才写入配置。
- 多候选或证据不足时明确要求用户选择，不自动猜测目标项目。

## 事项工作台

- 新建事项前提示重复或相似名称，编辑已有事项不误触发重复检查。
- 表单草稿在远端刷新后恢复，并在事项已被其他窗口更新时提示冲突。
- 增加规则预览、排序、统计筛选、单次改期与冲突/撤销、逐次完成和提醒状态。
- 事项与打卡项目支持关联展示及跨页面编辑，编辑项目后保留关联身份。

## 可靠性与多表面

- 多 root 页面状态、焦点、滚动和 quick dialog 生命周期隔离。
- 记录失败保留可重试草稿和回执；CSV、Loop、Obsidian 导入持久化失败统一回滚内存。
- 提醒动作进入有序 mutation 队列，卸载期间不再发起晚到写入；删除墓碑阻止跨窗口旧快照复活。
- 键盘日期导航、IME 搜索、移动端表单定位和关联项目入口补齐无障碍与触控反馈。

## 兼容性与数据

- 主存储、事件身份、公开 API v5 和最低思源版本保持兼容，无需迁移。
- 版本四元组（`package.json`、`plugin.json`、`src/version.ts`、构建产物）统一为 18.17.0。
