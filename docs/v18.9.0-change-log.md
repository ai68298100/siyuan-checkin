# 小驴打卡 v18.9.0 变更记录

主存储 v3、公开 API v5、最低思源 3.8.4 不变；所有数据结构变更均为可选字段（旧数据零迁移，可直接从 18.8.0 升级）。本版本主题：**可信记录与复盘可解释**（D-291 十五项 + 收尾任务）。

## 批次 A：可靠事实与可处理问题（P0）

- **外部失败待处理箱**（T-1509，D-293）：外部来源写入因存储故障失败时进入有界待处理箱（容量 40、保留 14 天，常量显式）；入箱按来源+项目+外部身份合并、满员显式拒绝；启动恢复每条自动尝试一次并出会话摘要；设置页逐条重试/丢弃（带确认），重试决策全量重查（目标/映射/启用/墓碑/单位/日期），拒绝绝不转投。只有存储失败入箱，配置拒绝不入箱——自动重试被拒配置等于绕过用户撤销。
- **单条记录事实详情**（T-1510）：回顾页历史行新增「详情」切换，六行固定序只读投影（记录日期/时刻/实际数值单位/计量方式/生效修订/归属项目）；计量方式仅按登记前缀与来源确证，无登记前缀如实未知，绝不以当前配置反推历史；展开零写入。
- **批量补记实际数量与提交预览**（T-1511）：批量补记改两步流——预览逐项分类（已存在→排期不适用→限额/戒除→绑定问卷→类型），数值项逐项填实际数量（空/零/负/非法/超限不提交、绝不默认目标值），提交在变更内重建快照重校验、一批一次持久化失败整批回滚、成功后逐条可撤销。
- **来源渠道细筛与计量方式筛选**（T-1512）：记录筛选来源下拉扩展 13 项（来源枚举 + api 细分渠道：健康/笔记推导/任务回写/其他），新增计量方式维度（会话片段/日汇总/其他），各选项带命中数；「api」保持伞选项语义；组合筛选/清空/翻页先过滤后分页，查询零写入。

## 批次 B：规划透明与复盘可解释（P1）

- **未来 30 天排期预演**（T-1513）：编辑器从当前草稿逐日投影应做/非应做与原因，与排期内核同口径；配额项目按周期窗口展示剩余额度不编造固定日；非法草稿 fail-closed。
- **规则修改前后影响对照**（T-1514）：既有项目保存前对照规则字段差异与未来 30 天新增/不再应做天数（旧侧=当前生效修订，新侧=草稿），确认才生效，历史快照不变；单位差异原样呈现不自动换算。
- **全项目未来一周负荷预览**（T-1515）：今日页折叠区按日投影全部项目应做分布；配额项目单列不摊派；归档/排期非法项目如实排除；点击项目名直达编辑器，零事件写入。
- **统计分母与状态贡献明细**（T-1516）：概览「如何计算」展示指标口径定义与逐日条构成（完成/未完成/跳过/非应做），与统计引擎同序同谓词、配额同款短路；逐日条可跳转记录并保留筛选。
- **选定项目横向趋势比较**（T-1517）：分析工作区选 2~4 个项目，按单位分组比较逐日序列（折线图+同源表格），配额项目单列不参与完成率比较；满员禁用未选项、稀疏数据如实标注。
- **周复盘向导与可恢复草稿**（T-1518）：周范围概览三步向导（本地事实核对→阻力→下周一项调整），草稿按周键隔离保存（有界 8、文本 500、重载恢复），确定性导出 Markdown，事实与用户解释分节标注。

## 批次 C：配置复用与安全迁移（P1）

- **个人模板脱敏分享**（T-1519）：勾选个人模板导出白名单 JSON（name/icon/kind/target/unit/schedule/group/priority/timeSlot 等），备注、内部 ID、时间戳与任意未知字段天然不出包；shareVersion=1 版本声明；20 个上限与空选择显式拦截；确定性序列化。
- **模板包导入逐项决策**（T-1520）：契约拒绝（版本/大小/数量）、字段级校验逐条丢弃计数；新模板默认导入、重名默认跳过（最安全），可选替换现有或另存为；一次保存失败整批回滚，重复导入幂等。
- **设置保存前变更清单与分节恢复**（T-1521）：设置页展示待保存修改清单（字段旧值→草稿值，敏感字段前后值一律遮罩），支持按字段或整节撤回（撤回只删草稿，不触碰事件与文档内容）；明示「仍是草稿」。
- **数据迁移重名冲突主动选择**（T-1522）：Loop/Obsidian 迁移遇同名活跃项目时逐项选择合并/跳过/另存为；单位或类型不兼容默认跳过并明示原因，绝不静默换算单位；确认后一次持久化失败整批回滚。

## 批次 D：离线验证联动配置（P2）

- **外部来源粘贴样例试算台**（T-1523）：健康收件箱/笔记推导/叶归设置卡内嵌「用样例检查」——粘贴样例逐行离线试算映射结果（命中/未命中/非法 + 原因 + 摘要），复用生产解析函数；零 SQL、零网络、零宿主调用、零事件写入、零映射修改，输入有界仅会话内存。
