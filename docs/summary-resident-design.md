# 每日摘要写驻留文档——设计稿（T-1353/T-1354 前置，2026-09-21）

> 状态：**设计稿，未实现**。实现前置条件：用户完成隐私决策（development-roadmap-v18-v22.md §十遗留项 1）。
> 本稿是 T-1370 同步评审之外另一个需要用户拍板的待定项的完整设计，决策通过后可直接进入实现排期，预计 1 个批次。

## 一、目标

把「今日/本周期摘要」以纯文本形式写入用户指定的一个思源文档（驻留文档），使外部工具（其他思源插件、自动化脚本、移动端快捷指令经内核 API）能在**不加载插件前端**的情况下读到打卡概览。

## 二、数据边界（隐私核心，全部为硬约束）

1. **单一目标文档**：用户在设置页显式绑定一个文档块 ID（复用 `validateAnchorBlockId` 校验，同日记集成 T-1352）。
2. **内容字段白名单**：仅日期 + 汇总数字——`日期、完成/计划项目数、总记录数、各来源计数`。**不包含**：项目名以外的自定义文本、备注、照片引用、事件明细、externalRef。
3. **只追加**：每日一行（`- 2026-09-21 · 5/7 · 记录 9 次`），经 `/api/block/appendBlock` 追加为子块；不修改/删除既有内容。
4. **默认关闭**：`enabled` 与合法 `docId` 双条件缺一不可（同 D-241 日记集成纪律）。
5. **外部读取零新增面**：外部工具经内核 `/api/block/getBlock`（公开接口）读该文档即可；**不新增**公开 API 能力、不注册新的诊断/事件。

## 三、实现轮廓（决策通过后）

| 件 | 内容 | 复用 |
| --- | --- | --- |
| 偏好 | `summaryResident: {enabled, docId}`（view-preferences，模式同 diaryReport） | T-1352 |
| 写入 | 每日首次打卡后旁路追加当日行；`withBoundedRetry` + 审计 `channel: "summary-resident"` | D-241/D-247 纪律、note-anchor 通道 |
| 触发 | 事件驱动（打卡后）而非定时器——无常驻任务，卸载即净 | 既有事件总线 |
| 读取 | 外部工具自读文档；插件不提供 push | 零新增面 |
| 设置 | 数据安全区一行：开关 + 文档 ID + 「立即写入今日摘要」 | 日记集成三件套同构 |

## 四、风险与对策

| 风险 | 对策 |
| --- | --- |
| 长期追加使文档膨胀 | 每行 ~40 字节，年增约 15KB；文档属用户空间，由用户自行归档 |
| 多窗口重复追加 | 追加行带唯一 `date+window` 幂等标记前一日检查：同日已有本插件标记行则跳过 |
| 与日记集成（T-1352）混淆 | 设置文案显式区分：日记集成=周期报告手动写入；驻留摘要=每日自动一行 |

## 五、待用户决策清单

1. 是否启用该能力（不启用则本设计稿归档，零成本）；
2. 若启用：触发方式是否需要「每日自动」之外的选项（当前设计仅事件驱动）；
3. 内容白名单是否需要扩充（当前拒绝项目名以外的任何自定义文本）。
