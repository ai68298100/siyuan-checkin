## 二、评估卡

### 卡 1｜微信读书·完读事件 + 划线/笔记计数 —— 做（条件批次）

- **用户收益**：读书打卡免手动；完读日期是事件型数据，字段级证据充分，口径无歧义。
- **适配代价**：中。新增 outbound-pull 适配器（用户填 API Key → 插件定时/手动拉取 → 结算 → `weread:` 前缀写入）；需处理网络失败静默降级（本地优先不受影响）。
- **验证方法**：Key 申请流程实测 + 拉取数据字段核对 + 双窗口/重载幂等回放 + 断网降级。
- **防双重累计**：与思阅按「**载体归属**」互斥——同一本书只登记一个来源（导入微信读书私架的书归微信读书，思源内打开的本地文档归思阅，公众号/网文天然归微信读书）；不做时间窗互斥。
- **触发条件**：①用户实际需求出现；②Agent API Key 流程实测通过；③官方 ToS/限流文档跟踪无恶化（当前 "Rate limits: Not documented"，`skill_version` 会演进）。
- **登记**：T-1402。

### 卡 2｜微信读书·阅读时长 —— 延后

`/readdata/detail` 有 `readTimes`（时间戳→秒数），但**仅当月按日**、无历史逐日序列——跨月补记不可行，只能做「当日在线拉取」。等卡 1 落地且官方 API 稳定后，以「当月按日 + 当日拉取」形态重评。原预期「无官方时长数据→不做」**不成立**，记录修正。

### 卡 3｜Keep —— 不做（全部指标）

无自助导出（隐私政策页为 JS-SPA 无法核验可携带条款原文）、开放平台为占位页（API 仅面向约 20 家硬件厂商）、唯一官方途径是客服/邮件人工申请 xlsx（每次更新数据重走全流程）；第三方工具全部依赖手机号+密码模拟登录私有接口，违反「不逆向私有格式」硬约束。相对内置手动记录的增量价值仅剩跑步距离精确化，操作成本压倒收益。**保留项**：若未来建成通用 CSV/xlsx 导入框架，Keep 客服 xlsx 可作为顺带兼容格式（延后，不专门投入）。触发重评信号：Keep 向个人开发者开放 API 或上线自助导出。

### 卡 4｜手机健康中心·iOS 步数 + 体重 —— 做（文档级交付，C 类零代码）

- **通路**：iOS 定时自动化（免确认全自动）→ Find Health Samples（步数样本求和即日总量；体重为低频样本）→ 拼 JSON → Get Contents of URL POST 到思源内核 + token。全程无 App、无审核。
- **交付形态**：不是插件内集成，而是**官方快捷指令模板 + 接入文档**——公开 API `recordEvent` 已天然支持（source=api + externalRef 幂等），插件侧零代码；配套做同日重复 push 的幂等说明（upsert 语义：同 externalRef 重放返回已有事件）。
- **摩擦点（写入文档）**：手机须与内核同网或内网穿透；失败静默无重试；iOS「本地网络」权限首访弹窗、系统更新可能重置；token 填入快捷指令后勿分享。
- **验证方法**：用户真机 iOS 快捷指令模板实测（步数/体重各一条 + 同日重放）。

### 卡 5｜手机健康中心·睡眠时长 —— 延后

iOS 需对区间样本求和且 in-bed/asleep 重叠需过滤（推断级证据）；Android 依赖厂商写入 sleep session，链路最脆。等步数/体重模板在真机验证后按需跟进。

### 卡 6｜手机健康中心·锻炼时长 —— 不做

iOS「锻炼分钟」属活动环摘要而非样本，Shortcuts 无确认的 workouts 查询动作（官方未逐项列明覆盖范围）；依赖 Apple Watch 佩戴。数据源不稳，不做。

### 卡 7｜Android / 华为健康 —— 延后

Android：Health Connect 是唯一长期通路（Google Fit API 2026 年底停服），但 Tasker+第三方插件+多层授权三件套门槛高，且聚合 API 不含手动录入步数；华为：个人无 API、不支持 Health Connect，Health Kit 需企业资质——基本不可行。等 iOS 模板验证后按用户需求重评 Android。

## 三、框架学习（记录，不立即改码）

1. **渠道分类学扩展**：微信读书暴露了第五种接入形态——**official-pull（出站拉取第三方官方 API）**。与 C 类 push（外部主动推给我们）方向相反，是插件出站 HTTP（需 opt-in + 网络失败降级，符合本地优先）。`SourceChannel` 枚举在首个此类适配器（T-1402）落地时扩展 `"official-pull"`，随实现一并补框架文档、描述符校验与测试。
2. **幂等 upsert 语义已有**：公开 API `recordEvent` 对同 `source + externalRef` 重放返回已有事件——健康快捷指令同日多次 push 天然幂等，无需插件改动。
