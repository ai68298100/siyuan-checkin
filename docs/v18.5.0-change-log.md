# 小驴打卡 v18.5.0 变更记录

发布日期：2026-09-25。本版完成设置页与外部联动重构、叶归 LifeLog 接入、外部来源边界守门和移动端已完成项折叠修复。主存储 v3、契约 storeVersion 2、最低思源版本 3.8.4 不变，可直接从 18.4.0 升级。

## 设置页与外部联动

- 设置页分为“思源文档写入”和“第三方来源联动”两组，日记、摘要、思阅、健康、思播、微信读书、叶归分别使用独立来源卡片。
- 每个来源卡片说明绑定目标、保存与启用顺序、数据流、隐私边界、停用保留、重绑历史、查询上限和宿主可用状态。
- 健康联动要求至少一个指标映射，校验日期、指标单位、查询上限、墓碑和目标项目。
- 思阅与思播的时长结算要求目标项目单位为“分钟”；思播设置页显示 controller 宿主状态，停用或重绑会丢弃未结算片段。
- 微信读书 Key 仅保存于本地偏好，时长、完读和笔记计数使用独立目标与有界拉取；叶归从绑定笔记本读取当日 Marker 段落，按相邻时间差结算并以块 ID 幂等。

## 手机端与交互

- “已完成打卡项”支持展开、折叠和再次展开；点击时同步 `aria-expanded`、`hidden` 列表和箭头状态，并持久化偏好。
- 移动视觉矩阵覆盖 320/360/390/430px，设置页分组与长内容保持可触控且无横向溢出。

## 质量与发布工程

- 完整质量链覆盖类型检查、生产构建、175 个测试文件、移动结构、生态契约、性能基准、发布清单和回滚演练。
- 真实思源 3.8.5 隔离内核 E2E 覆盖 21 个场景；思阅、思播 fixture 使用分钟时长项目，避免单位错误绕过 fail-closed 守门。
- `package.zip` 保留真实构建时间以满足宿主同步的新鲜度要求，`sync:digest` 固定在最终测试后、发布资产检查前执行。
