# 4.0 UI 变更记录

## 发布

- **v4.0.0（2026-09-10）**：4.0 响应式工作台 UI 随本版本发布；新 logo 与 preview 图同步更新。发布决策由仓库所有者做出，mock 视觉 harness（浅色 + 深色）与全部自动化测试通过；真实思源客户端的反馈在发布后继续收集修复。

## 已完成

- 修复深色主题跟随：`data-appearance` 现在输出解析后的 `light`/`dark`（"跟随思源"读取 `window.siyuan.config.appearance.mode`，回退系统 `prefers-color-scheme`），且八个页面根节点（今日、历史、总结、复盘、归档、日期事项、设置、编辑器）全部携带该属性。此前只有今日页输出且写的是原始偏好值 `system`，深色覆盖从未生效。
- 视觉 QA harness 支持 `CHECKIN_QA_THEME=dark`：深色思源 token 下跑同一套页面与断言，深色截图输出至 `.artifacts/visual-qa-dark/`。浅色与深色均通过，深色下卡片、摘要瓷砖、实心按钮与底部导航对比度已人工核验。
- 依据用户参考图（001–003 及零散参考）完成视觉对齐层：画布带 7% 淡紫调、Today 卡片去掉左侧色条改用干净白卡（16px 圆角）、色彩集中到图标块/实心胶囊操作按钮/渐变摘要瓷砖（紫 + 暖橙对）、周条"今日"徽章改为实心主色块、移动端导航选中态改为实心圆片。
- 视觉 QA harness（`tests/visual-qa.cjs`）纳入仓库：编辑器类型选择改用 force 点击、图标分组断言修正为 9、mobile matrix 增加真实视口截图与底部导航可见性检查（fullPage 截图会把 fixed 元素渲染到文档底部造成误判）。
- Today 页面增加持久化搜索、分组、排序和“仅未完成”筛选，并提供完成数、待处理数和完成率摘要。
- Today 桌面端使用两列/三列工作台布局，移动端固定单列、八入口底部导航和安全区间距。
- History 页面采用桌面日历与记录双栏，移动端记录值与操作区分行排列。
- Summary 页面统一范围切换、自定义日期、统计概览和项目汇总层级。
- Settings 页面将密度、主题、默认视图、动效和恢复操作整理为控制面板。
- Occasions 页面采用桌面表单/列表双栏，移动端单栏并保持事项操作可达。
- Insights 页面统一统计卡、84 天状态网格、行动建议和周趋势；无项目空态也使用同一表面样式。
- Archived 页面增加名称、分组和单位搜索、结果计数、暂停时间与明确恢复反馈；移动端保持紧凑恢复列表、触控尺寸和底部安全区。
- 七个 `*-v4.scss` 文件在 legacy `index.scss` 之后加载，避免旧规则覆盖新表面。
- 发布检查验证七个表面进入生产 CSS，源/构建 JSON 不带 BOM，插件元数据使用正常 UTF-8 中文。

## 行为边界

- 不改变打卡项目、事件、删除标记、日期事项和跨插件 API 的数据语义。
- 不要求 AI、网络或外部插件；本地记录、统计、导出和行动建议继续独立可用。
- 不提前修改版本号；当前包版本仍为 `3.0.0`，4.0 UI 作为开发线继续验证。
