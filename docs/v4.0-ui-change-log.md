# 4.0 UI 变更记录

## 已完成

- Today 页面增加持久化搜索、分组、排序和“仅未完成”筛选，并提供完成数、待处理数和完成率摘要。
- Today 桌面端使用两列/三列工作台布局，移动端固定单列、八入口底部导航和安全区间距。
- History 页面采用桌面日历与记录双栏，移动端记录值与操作区分行排列。
- Summary 页面统一范围切换、自定义日期、统计概览和项目汇总层级。
- Settings 页面将密度、主题、默认视图、动效和恢复操作整理为控制面板。
- Occasions 页面采用桌面表单/列表双栏，移动端单栏并保持事项操作可达。
- Insights 页面统一统计卡、84 天状态网格、行动建议和周趋势；无项目空态也使用同一表面样式。
- Archived 页面使用低噪声恢复列表，移动端保留触控尺寸和底部安全区。
- 七个 `*-v4.scss` 文件在 legacy `index.scss` 之后加载，避免旧规则覆盖新表面。
- 发布检查验证七个表面进入生产 CSS，源/构建 JSON 不带 BOM，插件元数据使用正常 UTF-8 中文。

## 行为边界

- 不改变打卡项目、事件、删除标记、日期事项和跨插件 API 的数据语义。
- 不要求 AI、网络或外部插件；本地记录、统计、导出和行动建议继续独立可用。
- 不提前修改版本号；当前包版本仍为 `3.0.0`，4.0 UI 作为开发线继续验证。
