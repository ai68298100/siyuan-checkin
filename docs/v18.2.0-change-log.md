# 18.2.0 变更记录

本次小版本交付生态调研循环（T-1400/D-256）第一轮的全部采纳项，并新增思播观看联动（实验）与极简「今日视图」渲染块。主存储 v3、契约 storeVersion 2、最低思源版本 3.8.4 不变；公开 API v5 能力面不变（20 项）。

## 新增功能

- **极简「今日视图」渲染块（T-1412，源：obsidian-easy-tracker）**：`{"view":"today","itemIds":[...]}`——每项目一行的今日状态/连续天数/最近漏卡日概览 + 一键打卡按钮（完成后祝贺态）；itemIds 必填（缺失 fail-closed），写回走既有 `recordEvent` 通道（修订指纹/审计/撤销不变），`data-record-pending` 节流防连点。
- **思播观看联动（T-1385，实验，opt-in 默认关）**：有界轮询思播 `controller.isPlaying()`（15 秒周期），累计「在播墙上时间」——不使用 currentTime 差值（seek/变速/循环不可信）；相邻采样间隔超 3 倍周期判为断档丢弃；跨午夜按 localDate 预切分；当日累计达阈值后每日一次幂等写入（`siplayer:<itemId>:<localDate>`）。
- **完成庆祝动效（T-1411，D-263 克制原则首批）**：完成打卡时反馈条 ✓ 徽标轻弹一次（360ms 纯 transform，零布局跳动）；插件 reducedMotion 偏好与系统 `prefers-reduced-motion` 双闸禁用。

## 增强

- **容错连续（maxGap，T-1409）**：项目级「漏打容错（天）」（1~30）——排期日漏打不超过 N 天不断签、缺口不计入连续值；真实完成重置缺口；SKIP 中性不消耗容错；at-most 与 quota 不叠加。当前连续与历史最长同口径，洞察/渲染块/API getStreaks/今日徽章自动同源。
- **热力图色阶自适应（T-1410）**：年度热力图四级阈值按「有记录日」条数分布的百分位（25/50/75）自适应，低频用户同样呈现完整层次；阈值随 `YearHeatmap.thresholds` 暴露。

## 公开 API 与身份

- externalRef 前缀注册表新增 `siplayer:<itemId>:<localDate>`；公开 API 输入不可伪造内部保留来源 `sireader`/`siplayer`（强制回落 api）。
- 历史与洞察来源标签新增「思播观看」；摘要驻留来源计数覆盖 siplayer。

## 工程与质量

- 真实内核 E2E 覆盖 today 渲染块用例（渲染→点击→真实落盘→祝贺态→缺参 fail-closed）；`CHECKIN_E2E_KERNEL` 候选路径新增本机安装位，免环境变量运行。
- 守门：tests/siplayer-adapter.test.cjs（采样状态机/断档丢弃/跨日切分/身份/偏好/结算组合/全套触点/防伪/注册表/i18n）入 test:ui；i18n 1593 对键对等。

## 明确不变

- 主存储 v3、公开 API v5 契约 storeVersion 2、minAppVersion 3.8.4；无迁移脚本，从 18.1.x 可直接升级。
- 思播联动为实验路径（上游无版本化契约，D-255/D-263 边界内），真实宿主验收归 T-1388。
