# 小飞驴打卡 v14.0.0

这是生命周期管理与体验优化版本：新增打卡项删除、自动归档、卡片右键菜单与批量删除；事项模板 31→66 并新增推荐分组；回顾页趋势图扩为四维度。

## 更新内容

- **打卡项删除**：编辑器与归档页均可删除；两步确认、删除前自动恢复点、事件墓碑防复活。
- **自动归档**：项目可配置"完成 N 天后自动归档"，打卡后自动检查触发。
- **卡片右键菜单**：右键弹出编辑/归档/删除菜单，零常驻空间。
- **批量删除**：批量模式新增删除按钮。
- **事项模板 31→66**：新增推荐分组（精选 11 个默认首档）+ 35 个新模板。
- **Today 常用模板 21→36**。
- **回顾页**：趋势图四维度、二级导航钉住、日志双列、头部工具同行。
- **修复**：「展开其余 N 天」失效、dock 设置页文字竖排、弹窗四角透白、事项操作按钮不可见。

## 安装

下载本 Release 的 `package.zip`，在思源中通过"设置 → 集市 → 下载安装包"安装。升级前建议在插件设置页导出 JSON 备份。
