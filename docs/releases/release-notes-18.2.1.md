# 小驴打卡 v18.2.1

外部来源体验收口：修复思播采样累计与健康收件箱身份两处缺陷，设置页外部来源入口聚合为折叠面板，回顾报告来源筛选覆盖思阅/思播。

## 更新内容

- **修复·思播观看联动**：此前按单段采样取整，15 秒采样无法累计到 1 分钟、难以达标；现按原始毫秒累计、按分钟晋升，时长项目可正常完成打卡。
- **修复·健康收件箱**：幂等身份补入项目维度，多个健康项目绑定同一指标不再互相覆盖；插件启动时立即同步一次收件箱，不再等待轮询周期。
- **设置页**：日记/摘要驻留/思阅/思播/健康五组外部来源入口收进折叠面板，摘要行显示已启用数；思阅/思播启用时行内显示今日累计分钟。
- **回顾**：报告来源筛选新增「思阅阅读」「思播观看」，筛选同时作用于报告与偏差基线。

## 升级与验证边界

最低思源版本仍为 3.8.4，可直接从 18.2.0 升级；主存储 v3、契约 storeVersion 2 不变，无迁移脚本。所有外部来源联动默认关闭；思播联动为实验路径（上游无版本化契约），真实宿主验收继续开放。
