# 小驴打卡 v18.1.0

本次小版本把外部数据来源正式接入打卡体系：思阅阅读联动与健康数据收件箱（均 opt-in 默认关）让阅读与步数/体重自动变成打卡；Task Horizon 日历可见性与每日摘要驻留加强笔记与外部工具协作；容错连续与热力图色阶自适应改善统计体验。

## 更新内容

- 来源统筹框架：统一「登记→接入→结算→身份→治理」管道，新增来源零改动结算与身份层。
- 思阅阅读联动：有效阅读分钟达阈值后为绑定项目每日一次幂等打卡，可撤销，重载不重复记账。
- 健康数据收件箱：iOS 快捷指令写入步数/体重到收件箱文档，插件自动摄取入库（附模板与接入指南）。
- Task Horizon 日历可见性：项目级日历显示开关 + 有界只读投影（公开 API 新增 `calendar.read`）。
- 每日摘要驻留：每日汇总一行追加到绑定文档，外部工具不经插件直接读取。
- 容错连续：项目级漏打容错天数，缺口在范围内不断签；跳过日语义不受影响。
- 热力图色阶按个人记录分布自适应分级。
- 锚点跳转跟随块移动，不可达时明确提示。

## 升级与验证边界

最低思源版本仍为 3.8.4，可直接从 18.0.x 升级；主存储 v3、契约 storeVersion 2 不变，无迁移脚本。所有外部来源联动默认关闭，启用需在设置中显式开启；真实宿主（桌面/Android/多窗口/双插件）验收继续开放，见发布验收边界。
