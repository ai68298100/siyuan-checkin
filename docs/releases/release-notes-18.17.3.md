# 小驴打卡 v18.17.3

全插件体验复核与真实思源内核验收版本，集中收口入口、反馈、跨窗口状态和生态联动稳定性，可从 v18.17.2 直接升级。

## 更新内容

新增：

- 独立思源内核 E2E 覆盖 23 个可写场景和 1 个只读场景，包含 API v5、持久化、只读拒写、双窗口同步、移动 bundle、问卷日记、外部来源、渲染块、导出和插件生命周期。
- 事项统计筛选入口、归档来源上下文恢复和 Today 首次使用三步引导。

优化：

- Today、Review、Insights、More、Editor 和事项页的异步动作按 owning root 反馈，跨窗口不串页。
- 未来七天负荷、提醒文流、短屏滚动、焦点与保存入口继续按桌面和移动场景收口。

修复：

- 事项统计伪入口、归档 stale 返回、锚点文档重复创建、事项迟到反馈和失败后 busy 残留。
- E2E 靶场 API token 配置、思源自动目录白名单、默认笔记本识别和只读内核等待兼容性。

## 兼容性与验收范围

- 主存储、事件身份、公开 API v5 和最低思源版本 v3.8.4 保持兼容，无数据迁移。
- 真实内核：思源 v3.8.7-alpha.6；可写 23/23、只读 1/1 通过。只读实例使用独立端口，写入拒绝已验证。
- 本地质量链覆盖类型、主/UI/移动/生态/扩展/性能测试、生产构建、视觉与宽度走查、发布资产和回滚演练。
- 真实思源桌面客户端、Android/TalkBack、第三方账号、缩放与保存面板仍需现场验证；本次发布到 GitHub Releases，不推送思源集市。
