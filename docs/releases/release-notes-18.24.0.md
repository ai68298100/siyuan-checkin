「健康收件箱一键创建绑定、精力心流区间对账与进度环硬件加速」小版本发布：设置页健康收件箱支持一键快速创建步数与体重打卡项并自动完成映射绑定，实现四大第三方外部联动全量具备零摩擦极简闭环；彻底排查并根治 Review 回顾页精力心流与跳过阻力看板多维筛选下全历史越界统计缺陷，严格对齐当前复盘时间范围契约；Today 仪表盘环形进度条挂载独立合成层与平滑贝塞尔微动效加速；主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 外部联动：健康收件箱一键创建与双向映射绑定（T-1912，D-564）
- **四大外部联动开箱即用闭环**：继思阅、思播、微信读书之后，在设置页健康收件箱行增设“快速创建并绑定”按钮，点击自动检测或生成“健康步数”（6000步）与“健康体重”（70千克）两个数量型标准项目，并自动挂载 `steps` 与 `weight` 映射关系并持久化偏好，消除新用户手动逐项配置摩擦。

### 2. 统计与排雷：精力心流与跳过阻力范围越界修复（T-1913，D-565）
- **时间范围契约严格守卫**：修复了在回顾分析工作区（analysis）选择特定项目或分组下钻时直接从全历史事件汇总导致区间越界的隐患；重构为严格在当前复盘区间（`summary.startDate` ~ `summary.endDate`）内进行有界统计，确保精力平均分与阻力分布完全忠实于当前复盘周期。

### 3. 视觉与性能：Today 环形进度条硬件加速（T-1914，D-566）
- **GPU 独立合成层**：为 `.lc-checkin__overview-ring` 注入 `transform: translateZ(0)` 与 `will-change: transform`，使进度百分比更新与打卡跳动动画在低端移动设备与高刷桌面均丝滑顺畅。
