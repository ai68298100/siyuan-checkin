# 小驴打卡 v18.8.0

新建体验与事项页强化：模板联动预接线、名称智能默认、事项里程碑与那年今天回顾。主存储 v3、公开 API v5、最低思源 3.8.4 不变，可直接从 18.6.0/18.7.0 升级。

## 更新内容

- **联动预接线模板**：套用「步数/体重/阅读/问卷日记」模板时给出绑定建议，确认后随保存生效；健康收件箱升级为按项目映射（同指标多项目、旧绑定自动迁移）。
- **名称智能默认**：新建打卡按名称联想内置模板或推断类型/单位/目标/时段/排期；建议非阻断，应用前不改任何字段。
- **新建流效率**：空状态一键应用场景组合包；「保存并继续」连续创建；推荐位按已有项目动态生成互补建议。
- **事项里程碑**：纪念日/生日自动派生「满 N 天/满 N 个月/满 N 周年/满 N 岁」；列表行与今日横幅展示，当天强调。
- **事项时间表达**：显示「X 年 X 个月 X 天」自然历跨度；季度/半年/年度/间隔类事项显示本周期进度条。
- **那年今天**：今日页聚合往年同日的打卡与事项锚点，可只读跳转当年日记（未找到提示、不创建文档）。
- **单次改期与错过补标记**：循环事项可单次改期（不影响整个周期）；上一周期未标记时中性提示并可补标记。
- **提示词轮换**：问卷题目可配提示词池，按 ISO 周确定性轮换；内置部分题目自带候选池，自建模板同支持。
- **页签默认打开方式**：可把打卡命令/热键的落点设为桌面页签（可固定、随布局恢复）。
- **设置与绑定**：文档绑定保存前核验、设置搜索定位到具体项、绑定目标卡片化、问卷编辑补复制/双向移动/键盘操作、宽屏回顾布局与热图变体优化。
- **快捷指令配方**：健康收件箱补充 iOS 官方配方，覆盖步数、体重、自定义触发场景、幂等验收和失败排查；当前解析器只接受 `steps` / `weight`，任意新健康指标仍明确降级为不支持。
- **笔记推导打卡（T-1500）**：新增 opt-in 笔记查询接入指南，登记 `notequery:<itemId>:<blockId>:<localDate>` 身份前缀；固定只读 SQL 仅支持文档/笔记本范围与 frontmatter/tag 模板，保留幂等、手动互斥和失败降级边界。
