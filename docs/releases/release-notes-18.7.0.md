# 小驴打卡 v18.7.0

笔记联动总览上线，修复手机端已完成区域折叠和回顾页边界下拉。主存储 v3、公开 API v5、最低思源 3.8.4 不变，可直接从 18.6.0 升级。

## 更新内容

- **笔记联动总览**：在设置 → 外部联动集中查看七类绑定，显示目标、启用和健康状态；批量检测目标是否存在，支持打开目标和跳到配置。检测结果保留在当前会话，不增加后台轮询。
- **问卷日记定位**：路径查找未命中时，使用思源日记属性查找已有文档，减少重复创建日记的风险。
- **手机端完成区折叠**：修复移动网格样式覆盖隐藏状态的问题，点击折叠后列表实际隐藏，再次展开恢复显示。
- **回顾页边界下拉**：限制移动回顾、弹窗和文档层的边界滚动传播，避免顶部下拉拖动外层页面。
- **文档**：重构 README 的功能、安装、数据、联动和开发说明；更新仓库简介及主题标签。

## 验证与边界

本轮代码已通过完整质量链（183 个守门文件）、移动完成区和回顾页定向真实内核自动化、双主题视觉 QA 与宽度走查。发布脚本重新执行构建和完整测试链。真实 Android/iOS WebView 的触摸弹性、软键盘、安全区及第三方账号仍需目标设备反馈；自动化证据不替代真机验收。
