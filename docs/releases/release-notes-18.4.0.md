# 小驴打卡 v18.4.0

微信读书官方接入、每日提醒调度与回顾行动卡全面落地。主存储 v3、最低思源版本 3.8.4 不变，可直接从 18.3.0 升级。

## 更新内容

- **微信读书联动**（opt-in 默认关）：经微信读书官方 Agent API 自动记录三类打卡——每日阅读分钟达阈值记一次、书架每读完一本记一次、每日笔记条数（划线+想法）写入绑定项目。官方 skill 契约逐条核对；`weread:` 前缀幂等+墓碑；断网静默降级；Key 仅存本地偏好、不入导出，接入步骤见 [微信读书接入指南](../weread-integration.md)。
- **每日提醒**：统一推送当日逾期/待完成/事项为一条思源原生通知（事项提醒置顶）；可配置最多 4 个提醒时刻（每时刻每日一条，启动时合并补发）；安静时段与零事项不打扰；不配置时刻保持「启动后一条」的原行为。
- **回顾行动卡**：新增「目标负荷解读」（回答「目标是否过高」，样本门槛下的推断，建议为可选表述）与「调整有效性对比」；失速排名、漏卡星期/时段分布、跳过原因分布齐备——每个图表给可行动结论。
- **情境×星期交叉**：跳过原因分布新增「常发生在星期几」行（严格过半集中才成模式，样本不足不打扰）。
- **渲染块组合卡片**：一个 checkin 块可编排 1~3 个既有视图（如汇总+月历），子配置白名单校验、禁嵌套；子视图交互（日期跳转等）原样可用。
- **场景组合包**：新建页新增 5 个生活场景模板组（晨间例程/学习成长/运动健身/睡前放松/创作入门），点击预览内容与「已存在」标记，逐条填表确认（无批量写入）。
- **设置页外部来源分组**：日记/摘要驻留/思阅/思播/健康/微信读书按来源子标题分节，一眼分辨行归属。
- **交互修复**：后台事件（思阅/健康收件箱等）落地不再收起用户展开中的「填写」面板；数字录入按回车保存后界面立即刷新（此前看起来没变，可能误以为失败）；回顾页滚动振荡、输入法弹回、提醒按钮文字竖排三项手机端缺陷修复。
- **质量基建**：日期运算收敛至 date-keys 单一实现；架构守门扩至 105 模块（weread 进入时钟纪律与来源登记双清单）；e2e 隔离真实内核回归 20/20；宽度走查 49 表面+32 交互场景全绿。

## 升级与验证边界

最低思源版本 3.8.4，可直接从 18.3.0 升级；主存储 v3、契约 storeVersion 2 不变，无迁移脚本。所有外部来源联动默认关闭；微信读书 Key 由用户自助申请。微信读书真机首拉、每日提醒真机弹窗形态、Android 触摸为现场验收项；思阅/思播上游 API 提案（成稿已备）待授权后另行提交。
