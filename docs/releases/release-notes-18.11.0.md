# 小驴打卡 v18.11.0

「可信数据」批次（审计驱动的 11 项正确性/契约收口）：跨时区统计按记录日结算、设置即时保存失败自动回滚、多窗口写入按桶合并、CSV 自导出自回导无损往返、迁出完成日按当日生效规则判定、公开 API 读侧来源过滤对齐、微信读书三指标独立出结果；另有动态内容安全转义、i18n 占位符修复与文档口径收口。主存储结构与公开写入边界不变，最低思源 3.8.4 不变，可直接从 18.10.0 升级。

## 更新内容

### 可信结算与跨时区

- **记录日唯一口径**：每日进度、回顾月/年趋势的完成判定一律按持久 `localDate` 键直接比较（此前负时区设备会把日期隐式解析为前一日）；配额贡献日与自动补全推导同口径。
- **三来源分页扫描**：健康文档、笔记推导、叶归 LifeLog 超出首窗口（500/查询上限/200 块）的记录不再漏读——单轮有界多页推进游标续读，短页收尾；跨页同文档相邻段落完整保留（叶归时长归属不受分页影响）。
- **迁出完成语义**：Loop Checkmarks 与 Obsidian H21 的「完成日」改按当日生效规则由主模型判定——跳过日、部分达标日、戒除破戒日不再被误标为完成；配额项目损耗显性计数；Loop 导入拒绝 `2026-02-30` 这类非真实日历日期。

### 持久化可靠性

- **设置即时保存失败回滚**：外观/语言/提醒/来源开关等即时偏好保存失败时自动回滚内存值、重绘并提示——界面值与存储值不再静默分叉；周复盘草稿保存/清除失败给出可见状态且输入保留可重试。
- **跨窗口合并**：提醒动作、事项完成日期、外部失败箱按身份并集合并，两个思源窗口同时操作不再互相覆盖；合并遵循「不复活删除」边界。
- **Agent 创建入队**：公开 Agent 接口创建项目/事项改经统一变更队列（享受既有跨窗口合并与写后校验），保存失败回滚内存并向调用方报错，不再假成功。

### 导出与契约

- **CSV 往返无损**：导入识别本插件导出表头全集（旧中英文别名兼容）——自导出文件可原样回导；日期真实日历校验（`2026-02-30` 拒绝）；引号/换行字段按 RFC 4180 跨行解析；文本列公式中和（`=SUM(...)` 等不再被电子表格执行）；单文件 20000 行上限。
- **JSON 备份口径明示**：备份/恢复覆盖主档（打卡项目、事件、墓碑）；个人模板、问卷、图标库、事项、提醒动作、偏好等独立配置不在其中——文档与界面文案同步，不再称「全量」。
- **公开 API 读侧来源过滤**：`getEventsInRange` 的 `source` 过滤对齐全部八种持久化来源（思阅/思播/微信读书/叶归事件可被过滤读取）；写侧防伪造边界不变（批量写入仍仅接受 `source: "api"`）。

### 来源拉取完整性

- **微信读书三指标独立出结果**：阅读时长、完读、笔记三条链路各自结算——笔记本分页触顶或网关失败时笔记计数**不写入**（每日身份不再被部分数据锁定），整日保留下轮重算；官方升级提示出现即阻断本轮全部链路；完读未核实的书计入待重试而非假成功。

### 安全与文案

- **动态内容转义边界**：今日日志附件缩略图地址经协议白名单门（`javascript:` 等永不进入属性）；上下文菜单与多处 aria 标签的用户内容统一转义。
- **i18n 修复**：占位符全量替换（同一参数出现多次不再残留字面 `{unit}`）；审计定位的十余处硬编码中文可见文案全部键化（双语）。
- **多表面标识**：提醒中心标题、事项预设列表等 DOM id 按渲染唯一化，多窗口同屏读屏关联不再串台。

### 文档与口径

- README 增补小驴系列插件（小驴雷切/小驴打卡/小驴人脉/小驴拾遗）与交流群信息；全功能/UI/交互审计登记并按数据风险分层收敛（本版本即首批落地）。

## 边界与说明

- 主存储结构、公开 API 写入面、`externalRef` 幂等注册表不变；升级无需迁移。
- 真机侧的跨窗口并发、超长来源回填与微信读书真实分页触顶场景建议按 [集成冒烟清单](integration-smoke-checklist.md) 抽查。
