# 小驴打卡 v18.13.0

「代码质量与用户反馈」批次（7 项质量/体验收口）：设置页目标卡全宽单列修复（逐字竖排/挤压消除）、统一文档选择器覆盖全部绑定入口（问卷 doc 模式与叶归笔记本变体新增）、设置页字体层级三档令牌归一、CSV 截断警告与 SurfaceContext 读侧扩参。主存储与公开 API 不变，最低思源 3.8.4 不变，可直接从 18.12.0 升级。

## 更新内容

### 设置页目标卡修复

- **全宽单列卡面**：目标卡在 ≥720px 容器不再被「标签|控件」两列行栅格压入 240px 窄列——摘要逐字竖排与字段挤压彻底消除（此前用户截图中的「乱码」实为 CJK 字符在极窄列宽内逐字竖排的伪乱码）。
- **类名退役**：五张目标卡不再复用 `settings-row` 行类，卡自有类规则在所有容器宽度天然单列；CSS 死类清理（净省 580B）。

### 统一文档选择器扩展

- **问卷卡 doc 模式**：doc 模式下新增搜索选择（与日记/摘要/健康同等搜索面），选中回填并走 save-journal-target 校验。
- **叶归笔记本**：从「加载按钮 + 下拉 select」改为单搜索框 + 候选行列表——首次聚焦自动拉取笔记本列表（会话缓存），搜索框客户端过滤；已存笔记本不在列表时保留自动停用+提示行为。

### 设置页字体层级归一

- 三档类型令牌（标题 720 / 次级强调 650 / 帮助 11px）统一设置面 12 处散布字重（620/640/660/700 四种归一）与帮助字号（10/10.5/11→11px）。
- 探针三档计算样式留档：420/760/1180 全宽一致，跨档跳变确认不存在。
- 分组折叠头字重 640→650（strong 档归一）。

### CSV 截断警告

- 导入超 20000 行上限的文件时，确认弹窗前显示双语截断警告（"文件超过 20000 行上限，超出部分未包含在上方计数中"），不再静默丢弃。

### SurfaceContext 与多表面

- SurfaceContext 读侧扩参到契约 1 全形状（日期/范围/工作区/查询/筛选，默认值不进上下文）。
- 提醒中心标题与事项预设 datalist id 按渲染次序唯一化（多窗口同屏读屏不串台）。
- 目标摘要附 title 全值（悬停可读完整名称/路径/ID）。

## 边界与说明

- 主存储结构、公开 API 写入面、`externalRef` 幂等注册表不变；升级无需迁移。
- 统一选择器的真实搜索与多窗口并发建议按 [集成冒烟清单](integration-smoke-checklist.md) 抽查。
