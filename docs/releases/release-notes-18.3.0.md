# 小驴打卡 v18.3.0

戒断里程碑、今日行动台、命名保存视图与范围导出、隐私披露与生态契约全面增强。主存储 v3、最低思源版本 3.8.4 不变，可直接从 18.2.1 升级。

## 更新内容

- **戒断里程碑**：戒除类项目显示「戒断第 N 天」，对照 1/3/7/14/30/60/90/180/365 阶梯给出最近达成级与下一关；今日卡片、summary 渲染块与 API `getStreaks` 同口径。
- **今日行动台摘要条**：今日页顶部呈现完成进度、跳过数、推荐下一步与专注可用性；记录路径不变。
- **提醒注意力**：安静时段窗口（跨午夜支持）内提醒降级为页内安静呈现；提醒中心新增「延后2小时」防抖。
- **命名保存视图**：把「最近 N 天 + 来源」存为命名视图一键应用；视图只存查询偏好，不复制事件。
- **范围导出**：CSV 导出支持最近 7/30/90/365 天窗口（JSON 恒为全量备份）。
- **隐私披露**：导出前审计备注/图片数量；来源断开明示事件与身份保留；诊断导出前预览包内构成；删除/批量删除确认含影响清单。零遥测不变。
- **渲染块一键插入**：命令面板 4 个预设（汇总/月历/热力图/分组概览），插入即可渲染。
- **导入预览**：Loop CSV 与 Obsidian 导入前披露重名合并与语义损耗。
- **报告增强**：统计范围显式声明、「跳过原因分布」节（样本不足守卫）、「失速项目」节（30 天漏卡排名）。
- **质量基建**：日期运算单一实现、架构边界自动守门（104 模块）、UI 状态台账、Task Horizon 消费侧契约（单飞/超时/Abort/降级）、来源生命周期矩阵。
