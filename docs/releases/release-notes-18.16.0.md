# 小驴打卡 v18.16.0

「事项页体验修复 + 设置页持续改进」批次：事项页表单抽屉滚动修复、统一文档选择器扩展至问卷/叶归、CSV 导入错误行明细、设置页字体层级令牌化。主存储与公开 API 不变，最低思源 3.8.4 不变，可直接从 18.15.0 升级。

## 更新内容

### 事项页表单滚动修复

- 表单抽屉滚动改为仅移动端定位 + instant 行为，消除点击「+」后 smooth 滚动引发的纵向位移感知。
- `BindOccasionsHost` 增 `isMobileFrontend?: boolean`。

### 统一文档选择器扩展

- 问卷卡 doc 模式接入统一搜索+候选行列表（与日记/摘要/健康同等搜索面）。
- 叶归笔记本卡从「加载按钮 + 下拉 select」改为单搜索框 + 候选行列表——首次聚焦自动拉取笔记本列表（会话缓存），搜索框客户端过滤；已存笔记本不在列表时保留自动停用+提示行为。
- 五张目标卡退役 `lc-checkin__settings-row` 复用类——卡自有类规则在所有容器宽度天然单列（≥720px 摘要逐字竖排/挤压消除）。
- 候选列表 id 按渲染次序唯一化（多窗口同屏安全）。

### 设置页字体层级

- 三档类型令牌（标题 720 / 次级强调 650 / 帮助 11px）统一设置面 12 处散布字重与帮助字号；分组折叠头 640→650 归一。

### CSV 导入

- 逐行错误明细：`errors: [{line, reason}]`，行号+原因（名称缺失/日期无效/数值无效）。
- 确认弹窗前显示截断警告与错误行摘要。

### 安全与多表面

- SurfaceContext 读侧扩参到契约 1 全形状；提醒中心/事项预设 DOM id 唯一化（多 root 读屏不串台）。
- `as any` 全量清理（`reminder-projection` 最后两处）。

## 边界与说明

- 主存储结构、公开 API 写入面、`externalRef` 幂等注册表不变；升级无需迁移。
- 统一选择器的真实搜索与多窗口并发建议按 [集成冒烟清单](integration-smoke-checklist.md) 抽查。
