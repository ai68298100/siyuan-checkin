# 小驴打卡 v18.23.0

「月份快速穿梭、微信读书一键绑定与物理按压防抖」小版本发布：回顾页历史记录月份导航新增一键回到本月今日（Today Anchor）快捷按钮，长周期复盘翻越历史后秒级穿梭回当天；设置页微信读书联动新增一键创建并绑定三维度打卡项（阅读时长/完本书籍/划线笔记）；卡片主打卡按钮增加 250ms 物理连击防抖，彻底杜绝手抖快速双击导致的重复提交；主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 历史复盘：月份导航一键飞回本月今日（T-1909，D-561）
- **Today Anchor 快捷锚点**：在回顾页记录工作区（records）月份导航栏中，当浏览非当月历史时，自动动态显示 `[今天]` 快捷按钮，点击一键平滑飞回当前月份和今日选中项，当前月时自动收起不占空间。

### 2. 生态联动：微信读书三维度一键创建绑定（T-1910，D-562）
- **多维度一键开箱即用**：在设置页微信读书联动行增设“快速创建并绑定”按钮，点击自动检测或生成对应的分钟项（阅读时长 45分钟）、二值项（完本书籍 1本）与计数项（划线笔记 10条）并自动完成绑定，配置体验零摩擦。

### 3. 交互稳固：卡片打卡物理防抖与连击防护（T-1911，D-563）
- **250ms 连击防抖门**：在 `runExclusiveAction` 核心动作调度中增加时间戳防抖记忆，操作完成后的 250ms 内忽略对同一项目的重复高频猛击，彻底杜绝触屏微抖或鼠标双击造成的重复提交。
