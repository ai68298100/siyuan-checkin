# 小驴打卡 v18.21.0

「生态联邦事件信封、CSS 结构化瘦身与极速打卡心流」小版本发布：升级跨插件联邦事件派发为 Epoch 6 统一信封格式（`ECOSYSTEM_EVENTS`），支持雷切工作台等兄弟插件即时响应无缝刷新；全面深度收敛 SCSS 冗余规则，重复规则体积削减近 40%，为 680 KiB 维护硬上限释放出 1.2 KiB 以上的安全缓冲空间；排雷 LifeLog 多行备注换行破坏日记单块结构缺陷，项目名称冒号冲突安全转义；Today 页面搜索框挂载中文输入法组字态安全保护与 Enter/Escape 极速打卡闭环；行动轨迹抽屉支持空态透明引导。主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 跨插件联邦：Epoch 6 统一事件信封广播（T-1904，D-557）
- **全生态事件信封广播**：在 `emitIntegrationEvent` 中，将事件对象包装为 Epoch 6 统一信封格式（含 `v: 1`、`source: "siyuan-checkin"`、`eventId`、`at`、`idempotencyKey`、`payload`），打卡与撤销发生时实时通过 DOM CustomEvent 广播给小驴雷切、快门等兄弟插件，实现多组件秒级协同响应。
- **向后兼容性**：保留原有事件字段直接展开，既有监听方零成本平滑兼容。

### 2. 数据与排雷：LifeLog 换行清洗与冒号冲突排查（T-1901，D-554）
- **多行换行压平为单行空格**：在 `formatLifelogEntry` 中对备注文本的多行换行符（`[\r\n]+`）进行统一清洗替换，防止思源追加日记块时被撕裂成多段碎片块，严格捍卫行首时间戳与段落原子性。
- **项目名冒号安全转义**：将项目名称内部的冒号替换为中划线 `-`，消除叶归与 Marker 解析器提前截断项目名的边界冲突。

### 3. UI 与基建：CSS 结构化深度瘦身与预算防御（T-1902 / T-1905，D-555，推进 T-1813）
- **容器查询与公共声明深度合并**：合并 `@container lc-dialog` 与 `lc-tab` 的 5 处镜像媒体/容器查询块，安全清理 10 余处跨段完全重复的单行规则声明。
- **大幅降低重复规则体积**：重复规则体积从 2001 bytes 降至 1242 bytes（降幅约 38%），CSS 编译体积从 696,188 bytes 稳定压缩至 695,147 bytes，为 680 KiB 维护硬上限腾出 1,173 字节安全缓冲空间，0 死类。

### 4. 交互与体验：极速打卡心流与轨迹零记录引导（T-1903 / T-1906，D-556 / D-558）
- **搜索输入框键盘流**：Today 搜索框挂载 `keydown` 监听，输入法组字态（`isComposing || keyCode === 229`）严格拦截；回车键在有 NLP 推荐时一键打卡、唯一匹配时自动转移焦点至主打卡按钮；Escape 键一键清空搜索。
- **行动轨迹抽屉零记录引导**：无打卡记录时依然呈现轻量折叠抽屉，提示“今日暂无行动记录”并保留“打开今日日记文档”直达入口，功能透明可发现。
