# 小驴打卡 v18.26.0

「习惯成熟度算法除零排雷与全生态五大集成大圆满」小版本发布：排查并修复 `computeHabitSaturation` 习惯稳固度饱和曲线在非有限数值与基准天数 46 天时的除零与边界计算缺陷；设置页“连接与能力”笔记推导（Note Query）补齐“快速创建并绑定”按钮，至此思阅、思播、微信读书、健康收件箱、笔记推导五大外部集成 100% 达成 0 阻力一键创建绑定大圆满；排雷跨午夜（Midnight Boundary）生命周期，跨日自动清理残留回执、旧日段落映射与在飞临时变量，彻底杜绝跨天内存残留与误撤销隔夜日记风险。主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 算法与健壮性：习惯饱和成长曲线除零排雷（T-1918，D-569）
- **除零与非有限数值双重守卫**：在 `computeHabitSaturation` 中严格进行 `Number.isFinite` 校验与非负截断；针对基准天数为 46 天的极端边界引入 `rootSpan = Math.max(1, validTarget - 46)` 除零防御，确保成熟度与饱和得分在任何输入下均稳定输出有界数值。

### 2. 外部联动：五大集成一键创建开箱即用大圆满（T-1915，D-567）
- **全集成 0 阻力创建闭环达成**：在设置页“笔记推导”行增设“快速创建并绑定”按钮，自动生成标准二值“笔记打卡”（✍ 1次）项目并自动赋值给 `noteQuery.itemId`；配合此前完成的思阅、思播、微信读书与健康收件箱，五大外部联动全部具备开箱即用的一键绑定能力。

### 3. 稳定性与排雷：跨午夜刷新与旧日映射内存治理（T-1916，D-568）
- **跨日边界彻底清理**：在 `refreshDateBoundary` 中重构跨午夜清理逻辑，跨日时自动执行 `recentLifelogBlocks.clear()`、清空残留 `recentRecord` 回执、重置 `pendingLocalItem*` 变量，消除常驻后台多日运行下的内存累积与误撤销昨日日记段落的边界隐患。
