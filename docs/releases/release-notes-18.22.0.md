# 小驴打卡 v18.22.0

「全生态联动模板组、思播 v1 播放事件驱动与设置页一键创建」小版本发布：新增 7 款开箱即用的生态联动打卡模板（思阅精读、思播精听、闪卡复习、考证刷题、拾遗精读、人脉关怀、管家事务）与【小驴生态联动】专属场景组合包；深入贯彻思播 Issue #180 上游 Integration API v1 契约规范，全面监听 `siplayer:play/pause/ended` 实现暂停/结束时毫秒级即时结算；设置页新增“快速创建并绑定”按钮，0 摩擦一键生成对应分钟打卡项并启用绑定。主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 全生态开箱即用模板与组合包（T-1907，D-559）
- **7 款专属联动打卡模板**：在 `CHECKIN_TEMPLATES` 中新增：
  - 📚 **思阅精读**（45分钟，高优先级，自动累计有效精读时间）；
  - 🎧 **思播精听**（30分钟，中优先级，自动累计音视频精听时间）；
  - 🎴 **闪卡复习**（30张，高优先级，对接小驴闪卡 cards: 复习完成）；
  - 📝 **考证刷题**（20题，高优先级，对接小驴考试 exam: 练习完成）；
  - 📰 **拾遗精读**（2篇，中优先级，对接小驴拾遗 glean: 剪藏文章已读）；
  - 🤝 **人脉关怀**（1人，低优先级，对接小驴人脉 contacts: 跟进互动）；
  - 📋 **管家事务**（1次，低优先级，对接小驴管家 home: 事务办理）。
- **【小驴生态联动】专属场景组合包**：在新建面板可一键预览并应用该组合包，中英文双语 100% 覆盖。

### 2. 思播官方 Integration API v1 事件驱动即时结算（T-1907，D-559）
- **全面监听官方播放生命周期**：深入结合 Issue #180 契约，监听 `siplayer:play`、`siplayer:pause`、`siplayer:ended`，当用户暂停或媒体播完时立即触发有效时间结算，彻底消除 15 秒轮询延迟。

### 3. 设置页一键快速创建并绑定打卡项（T-1908，D-560）
- **0 摩擦极简闭环**：在思阅与思播目标项目设置行增设“快速创建并绑定”按钮，点击自动检测或生成对应的分钟打卡项并完成绑定启用，用户再也无需来回跨页面手动配置。
