# 小驴打卡 v17.3.0

本版本重新整理回顾页的信息架构、统计表达和智能体协作方式，不改变主存储结构，可直接从 17.2.x 升级。

## 主要更新

- **三个回顾视图**：概览聚焦近期节奏和项目状态，记录支持日期/周期、项目、来源与关键词组合查询，分析集中趋势、热图、强度、分类和成就。
- **更准确的图表口径**：跳过日不进入完成率分母；按日目标、周期配额、上限目标分别表达；配额不再显示不可比较的完成率差值。
- **更易读的记录与图表**：新增最多 14 天的可点击计划节奏、按日期分段的记录时间线，以及图表精确数值表。
- **思源智能体回顾助手**：可选择总结、规律或计划方向，复制带准确日期范围的提问到思源智能体；不自动发送消息，也不在复制内容中包含备注和照片。
- **可选的插件内总结**：已接入 SummaryProvider 时可主动生成扩展总结；缓存按日期与数据版本匹配，过期请求、提供者错误和保存失败均有明确状态。
- **全端 UI 修订**：减少嵌套卡与重复说明，优化长名称、照片、长单位和主要操作；修复窄屏、平板和短横屏下的配额列表及日期弹层。

## 能力边界

- 思源的 `addAgentCapability` 用于注册插件工具，不等同于插件可直接打开智能体对话或调用模型。
- 即使没有智能体或第三方总结服务，所有本地打卡、记录、筛选、统计、导出和恢复功能仍可使用。
- 第三方 SummaryProvider 的数据权限由对应扩展决定；使用前请确认其隐私和网络策略。

## 兼容与升级

- 最低思源版本保持 3.8.4。
- 主存储结构和公开 API 保持兼容。
- 升级前仍建议在设置页导出 JSON 备份。
