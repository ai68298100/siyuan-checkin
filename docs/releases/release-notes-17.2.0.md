# 小驴打卡 v17.2.0

联动与生态版本：底栏番茄钟深度联动修复、公开 API 升级到 v5、新增 Obsidian 双向迁移通道与渲染块文档/笔记本维度。存储结构不变（仍为 v3），可直接升级。

## ⚠️ 升级前必读

本版本起最低思源版本为 **3.8.4**。使用更旧版本思源的用户请**先升级思源**再升级本插件——版本不满足时思源会禁用插件（数据不受影响,升级思源后即恢复）。

## 你会感觉到什么

- **底栏番茄钟联动全面修复**：点击「开始专注」后不再被误判失败而自动暂停；插件停止/卸载/重载不再误伤番茄钟正在进行的计时；专注完成自动打卡——写入失败会进入待回写清单自动重试,补打卡不会重复记账。
- **待回写番茄完成一目了然**：设置页新增「待回写的番茄完成」清单,可立即重试、丢弃；完成日已标记跳过的条目可一键「撤销跳过并计入」。
- **戒除类目标更安全**：戒除类（要少做/不做）目标不再提供专注计时入口,避免把专注误记成破戒。
- **公开 API 升级到 v5**：第三方插件可以获得按日期区间的事件读取、幂等批量写入、统一项目投影与连续/最长连续指标；v4 调用方完全不受影响。
- **从 Obsidian 迁入**：支持导入 Habit Tracker 21 的习惯文件（勾选日 → 打卡记录,重复导入自动去重）。
- **迁出到 Obsidian 同样支持**：每个活跃项目导出为一个 Habit Tracker 21 习惯 `.md` 文件（含全部勾选日,重复与无记录项目自动处理）。
- **渲染块支持文档/笔记本维度**：```checkin``` 配置新增 `docId`/`notebook`,只聚合锚定到该范围的项目;相邻两个渲染块互不干扰;同时修复了相邻代码块预览互相覆盖的问题。
- **质量与性能基线**：范围事件读与批量写在 10 万级事件下有性能门禁;最长连续全历史扫描有灾难退化捕获;真实思源内核端到端扩至 15 项(新增渲染块、批量写、跳过日解析旅程)。

## 稳定性与兼容

- 底栏番茄钟侧需要其上游发布带 focus 接口的版本并开启第三方联动开关后,联动才会生效;未安装或未开启时本插件一切功能照常。
- 渲染块预览按源块归属管理,相邻渲染块不再互相覆盖;锚点解析失败时显示加载失败占位而非空白。
- CSS 体积分级预算放宽为 480KB 告警 / 520KB 硬阻断（318KB 历史软线保留）。

## 验证

- 新增 4 个测试文件;测试清单 133 个文件、0 退役;完整质量链全链通过。
- 真实思源 3.8.4 内核端到端：桌面打卡/双窗口/禁用启用/移动端/只读实例合计 9 项全部通过。
- 浏览器级验收：多宽度走查 12/12 无溢出;双主题视觉检查 277 项全部符合预期。

## 安装

下载本 Release 的 `package.zip`，在思源中通过“设置 → 集市 → 下载安装包”安装。升级前建议照例导出 JSON 备份；回滚不会删除插件数据，见 `docs/release-rollback.md`。
