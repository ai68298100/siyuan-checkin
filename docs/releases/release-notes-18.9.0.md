# 小驴打卡 v18.9.0

可信记录与复盘可解释：外部写入失败可处理、每条记录事实可核对、规则变化所见即所得、配置与迁移全程可控；另新增 5 个循证打卡模板与日历消费端参考层。主存储 v3、公开 API v5、最低思源 3.8.4 不变，可直接从 18.8.0 升级。

## 更新内容

### 可靠事实与可处理问题

- **外部失败待处理箱**：外部来源（健康收件箱/笔记推导/微信读书等）写入因存储故障失败时进入有界待处理箱（容量 40、保留 14 天），启动自动恢复一次并在设置页逐条重试/丢弃；撤销过的记录不会被错误复活。
- **单条记录事实详情**：回顾页历史行新增「详情」，展示记录日期、时刻、实际数值/单位、计量方式与生效修订，全部只读投影、绝不以当前配置反推历史。
- **批量补记填实际值**：批量补记改为两步流——先预览逐项分类（已存在/排期不适用/限额/绑定问卷等），数值项逐项填写实际数量（空/非法不提交、绝不默认目标值），提交前重校验、失败整批回滚、成功后逐条可撤销。
- **来源渠道细筛**：记录筛选新增 api 细分渠道（健康/笔记推导/任务回写/其他）与计量方式（会话片段/日汇总/其他），各选项带命中数，组合筛选零写入。

### 规划透明与复盘可解释

- **未来 30 天排期预演**：编辑器实时预演当前草稿的逐日应做/非应做安排与原因；配额项目按周期窗口展示剩余额度，不编造固定执行日。
- **规则修改影响对照**：修改既有项目时保存前对照新旧规则（字段差异 + 未来 30 天新增/不再应做天数），确认才生效，历史快照不变。
- **未来一周负荷预览**：今日页一键查看全部项目未来 7 天的应做分布，配额项目单列不摊派，点击项目名直达编辑。
- **统计分母明细**：概览「如何计算」展示完成率分母逐日构成（完成/未完成/跳过/非应做），与统计引擎同口径可核对。
- **横向趋势比较**：分析工作区可选 2~4 个项目按单位分组比较趋势，配额项目单独呈现，不跨单位换算、不排名施压。
- **周复盘向导**：周范围概览新增三步复盘（本地事实核对 → 阻力 → 下周一项调整），草稿按周保存、重载可恢复，可导出 Markdown。

### 配置复用与安全迁移

- **模板脱敏分享**：勾选个人模板导出白名单 JSON（备注、内部 ID、问卷、锚点等敏感字段天然不出包），同输入同字节、版本声明防漂移。
- **模板导入逐项决策**：导入分享包时逐条预览——新模板直接导入，重名可选跳过/替换/另存为；一次保存、失败整批回滚。
- **设置变更清单**：设置页保存前展示待保存修改清单（敏感字段遮罩），支持按字段或整节撤回，不把草稿当已生效。
- **迁移重名冲突三选**：Loop/Obsidian 迁移遇同名项目时逐项选择合并/跳过/另存为；单位或类型不兼容时默认跳过，绝不静默换算。

### 联动与模板

- **外部来源样例试算台**：健康收件箱/笔记推导/叶归设置卡新增「用样例检查」——粘贴样例数据离线试算映射结果（逐行判定+原因），零 SQL、零网络、零事件写入，未连接宿主也能验证配置。
- **循证模板批次**：新增读一页书、按时服药、定时起身、联系亲友、分散复习 5 个模板，选型源自习惯方法论书评与循证生活指南，基线刻意偏小（低压力口径）。
- **概览调整**：移除回顾概览统计区的 30 天迷你趋势线（口径混排且无视觉归属），趋势呈现由分析工作区唯一承载。
- **移动端下拉修正**：移动布局下「报告设置/更多工具」下拉展开时若底部被固定底栏遮挡，自动滚动页面让出空间，最底部菜单项不再点不到。

### 生态

- **契约包日历消费端参考层**：`siyuan-checkin-contract` 包新增 `calendar-consumer.mjs`（能力协商/区间规划/单飞加载/防御性归一化/刷新四类/自检），供日历类消费方（如 Task Horizon「打卡」图层）直接取用；v1 机器契约未变。
