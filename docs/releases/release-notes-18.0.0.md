# 小驴打卡 v18.0.0

本版本聚合模板体系、回顾导出、受控智能体与生态准入四个方向的交付：模板扩充到 60 个并新增最近使用与精选推荐；报告支持目标偏差解释、来源筛选与一键导出全部；智能体草案与排期建议在确认后执行；新增数据诊断与英文界面。主存储结构不变，可直接从 17.3.0 升级。

## 主要更新

- **模板体系**：内置模板扩充到 60 个（八类，中英双语），新建页新增「最近使用」与「精选推荐」，模板区分批展示不再一次平铺全部。
- **回顾导出增强**：报告自动生成目标偏差解释（提升/下降/持平/数据不足），可按事件来源筛选并显式声明口径，新增「导出全部」（JSON + CSV + 报告）。
- **受控智能体**：排期调整与目标类建议经确认后执行、可撤销；智能体可起草新项目（进入普通编辑器检查后由你保存，不直接写入）；建议审计轨迹可导出诊断 JSON。
- **日记集成（默认关）**：把本周/本月报告手动写入你绑定的思源文档；只追加，不改动既有内容。
- **数据诊断**：保存失败、版本冲突、导入被拒等输出结构化原因码，设置页可查最新状态并导出诊断 JSON；恢复指南内置。
- **英文界面**：设置可选中文 / English / 跟随思源；英文界面完成与中文同标准的全端走查。
- **渲染块升级**：```checkin``` 块支持多分组聚合视图、完成率阈值过滤与项目/锚点跳转。
- **生态自测包**：第三方插件可用 `siyuan-checkin-contract` 包在开发期自测 API 兼容性（78 项断言 + 准入清单）。

## 能力边界

- 智能体相关功能需要思源支持 `addAgentCapability` 且已配置模型；未配置时打卡、统计、导出与恢复完整可用。
- 草案与建议都不会绕过你的确认：确认前只读，确认后可撤销；历史事件永远不在修改范围内。
- 日记写入默认关闭；启用需绑定目标文档，只向该文档追加内容。
- 公开 API 在 v5 面上新增 `diagnostics.read` 能力（`capabilitiesSince` 标注），v4/v5 消费方无需改动。

## 兼容与升级

- 最低思源版本保持 3.8.4。
- 主存储结构（内部 v3）与公开 API 契约版本（storeVersion 2）保持不变。
- 新增界面偏好（语言、报告来源、最近模板、日记绑定）均为可选项，旧数据升级后行为不变。
- 升级前仍建议在设置页导出 JSON 备份。
