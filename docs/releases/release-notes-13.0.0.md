# 小驴打卡 v13.0.0

这是数据内核与多窗口可靠性版本：并发写入有了写前收敛与写后校验，已删除记录不再被旧数据复活，十万级历史的各类查询与统计全面索引化；同时包含手机端折叠修复与"每次打卡"增量自定义。

## 更新内容

- 多窗口并发安全：写前三方对账在排他锁内确定性合并，写后回读校验并在并发覆盖时最多一次自动修复，冲突事件全部保留。
- 删除一致性：事件删除墓碑并发闭环，旧窗口重放不再让已删记录复活；墓碑查询双键索引化，大数据量下不减速。
- 统计口径修复：历史自定义汇总区间使用所选起止日的精确边界；回顾页跨午夜共享单一截止日，不再出现"两个今天"。
- 记录体验：手机端已完成项即时折叠/展开；非二元任务支持配置"每次打卡"增量，旧数据自动兼容。
- 十万级性能：事件、墓碑与日期修订全面索引化，追加、备注编辑、配额、规则、汇总、成就与完美日计算降至毫秒级，全部携带自动化门禁。

## 安装

下载本 Release 的 `package.zip`，在思源中通过"设置 → 集市 → 下载安装包"安装。升级前建议在插件设置页导出 JSON 备份。

自动化测试覆盖类型、构建、主功能、UI、移动端、生态、性能和发布资源（92 项测试资产、零退役）。真实思源多窗口并发、dock、安全区与底栏番茄钟双插件联动仍建议现场复核；自动化结果不替代宿主验收。
