# 小驴打卡 v18.17.6

本版完善恢复、跨窗口与外部批量写入的可靠性，并修正回执折叠和状态对比度，可从 v18.17.5 直接升级。

## 更新内容

新增：

- 主档快照基准工具与真实思源存储实验，提供大样本、双窗口及受控失败重载证据。
- Task Horizon 原始来件的逐项处理清单与合作回复材料。

优化：

- 完成事项芯片和提醒状态行改用明确颜色，补齐首次成功按钮颜色回退并清理重复样式。
- 批量调用在排队前保存输入快照，按落账日的规则修订判定方向。

修复：

- 恢复后旧窗口可能重新合入恢复前未变化实体的问题，保留并发产生的真实新增事实。
- 隐藏回执面板仍可能占位或遮挡点击的问题。
- Task Horizon 批量身份校验不一致，以及批量未执行时返回 undefined 的问题。
- v4 参考 bridge 跨日重试可能把历史事实写到今天的问题；原身份继续保留待处理。

## 兼容性与验收范围

- 主存储和公开 API v5 兼容，无数据迁移，最低思源版本仍为 v3.8.4。
- 发布前执行完整质量链、Chrome 明暗主题视觉走查、发布资产核对及回滚演练，详细证据见 PROGRESS。
- Task Horizon 新合作的生命周期通知、日历语义补充和专用写入限制尚未完整验收；本版不声明合作契约就绪。下一批先完成日历提供端，再进入普通任务回写联调。
- 独立思源 3.8.7 只验证指定存储场景；受控 saveData 失败不代表内核自然磁盘或断电故障。Android/TalkBack、第三方账号、缩放、保存面板与双插件现场仍需验证。
- 本次发布到 GitHub Releases。
