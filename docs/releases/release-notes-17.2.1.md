# 小驴打卡 v17.2.1

本版本是 v17.2.0 的 UI 与记录流程修订版，不改变主存储结构，可直接升级。

## 主要更新

- 今日卡片根据当天排期数量和容器宽度自适应；支持 20–30 项使用场景，长名称、长单位和长备注自然换行。
- 时长项目和非二值番茄来源项目提供“专注 + 记录”双入口，手动记录不要求先启动计时。
- 回顾页重新校准趋势、热图、日志、历史操作、项目汇总、建议和报告的字号、间距、换行与对齐。
- 自定义图片图标在今日、回顾、模板和归档中正确显示；目标与单位输入框保持对齐。
- 修复番茄钟收件箱小时换算、月度/每周事项星期保存和第 N 个星期序数选择。

## 兼容与升级

- 最低思源版本保持 3.8.4。
- 公开 API 保持 v5，v4 能力继续兼容。
- 升级前仍建议导出 JSON 备份。
