# 小驴打卡 v18.2.0

本次小版本交付生态调研循环第一轮的全部采纳项：极简「今日视图」渲染块、思播观看联动（实验）与完成庆祝动效，外加容错连续与热力图色阶自适应两大统计增强。

## 更新内容

- 极简「今日视图」渲染块：`{"view":"today","itemIds":[...]}` 嵌入任意笔记——今日状态、连续天数、最近漏卡日概览 + 一键打卡按钮，完成后显示祝贺态。
- 思播观看联动（实验，默认关）：有效观看分钟达阈值后每日一次幂等打卡；只累计在播墙上时间，seek/变速不影响数据；可随时删除撤销。
- 容错连续（maxGap）：项目级设置漏打容错天数，缺口在范围内不断签且不计入连续；跳过日语义不受影响。
- 热力图色阶自适应：按个人记录分布自动分级，低频用户也有完整四档层次。
- 完成庆祝动效：反馈徽标轻弹一次；系统或插件内开启「减弱动效」时不播放。

## 升级与验证边界

最低思源版本仍为 3.8.4，可直接从 18.1.x 升级；主存储 v3、契约 storeVersion 2 不变，无迁移脚本。所有外部来源联动默认关闭；思播联动为实验路径（上游无版本化契约），真实宿主验收继续开放。
