# 小驴打卡 v18.10.0

统一页面体验改造收官（D-307 六阶段 49 项任务）+ 洞察/复盘三处增强：全插件页面壳与导航统一、洞察页钻取与范围选择、周复盘一键复制 AI 提示词、LifeLog 时间轴；无障碍与触控目标系统化走查修复。主存储与公开 API 不变，最低思源 3.8.4 不变，可直接从 18.9.0 升级。

## 更新内容

### 页面壳与导航统一（D-307 收官）

- **统一页面壳**：全部详情页（编辑器/归档/事项/设置/洞察）头部由单一构造点生成——标题、上下文行、返回路径、动作槽口径一致；编辑器新增**单级返回栈**（从洞察「编辑规则」进入后返回洞察而非固定回今日），通用返回分派统一走表面上下文。
- **洞察页可行动化**：完成率/连击之外新增「查看记录」（直达该项目的记录区，返回洞察保持会话）与「编辑规则」动作；分母说明按项目类型附**计算口径行**（配额窗口累计 / 戒除上限守住读数 / 排期机会日分母），配额窗口注、守住破戒词表、样本不足提示各归其位。
- **洞察范围与项目选择**：评估窗口新增 28 / 84 / 365 / 自定义起止（未来日拒绝、起止联动钳制）；项目选择器支持搜索（中文输入法组合态安全）并显示已归档项目（可回看只读洞察，附「在归档中查看」直达归档页——恢复动作仍留在归档页的重进排期预览确认内）。
- **今日行动台收束**：合并与概览重复的进度展示为单条「下一步」行动条，信息层次更清晰。
- **快速弹窗会话**：重开时回到上次页签；编辑页关闭先确认（问卷草稿不静默丢失）。
- **专注计时跨页**：非今日页显示专注小条（项目/剩余/回到专注）；重载后的中断会话明确告知「未入账」，不冒充恢复。
- **渲染块降级一致**：多块并存互不干扰、配置未变跳过重绘、局部失败错误面板隔离。
- **回顾页 LifeLog 时间轴**：叶归事件纵向串联（类型着色+时长徽标），纯渲染零写入，无记录时显式说明。

### 洞察与复盘增强

- **AI 复盘复制提示词**：周复盘向导新增「复制 AI 提示词」——本地统计事实+你的阻力/调整草稿组装为自足文本，粘贴到任意外部 AI 即可分析；零网络、零模型依赖、不写事件，文案内含隐私边界声明。
- **洞察钻取**：84 日格与每周趋势行可点击/键盘直达对应日期的记录页（含完整状态读数的无障碍名称）。
- **教练建议行动**：每条建议附「查看证据」「调整排期」入口，从结论直达事实与修改。

### 无障碍与响应式

- **页面级无障碍走查**：亮/暗/空态三遍 × 七表面全绿（可访问名称、键盘可达性、对比度、24px 下限零违规）；窄容器下 8 处折叠头/入口对齐 44px 触控准则（归档详情、事项抽屉、设置分组头、今日负荷等此前最低仅 16px）。
- **键盘与读屏基线**：j/k 卡片导航、上下文菜单 Escape 收口并归还焦点、导航 aria-current 一致性等行为纳入常驻守门。
- **宿主壳审计**：四种宿主组合（dock/页签/弹窗 × 桌面/移动）无横向溢出、固定底栏遮挡零命中并纳入守门；安全区 20 条规则全量枚举存档。

### 质量与性能

- **隔离内核回归**：问卷双结果编排（事实先落、文档旁路失败不回滚、重试只补文档不重复记账）与重载状态矩阵（持久偏好恢复/会话态回默认）新增行为级守门。
- **渲染性能测量**：今日 500 项目、回顾 10 万事件、多窗口渲染等九场景全部 1~14ms（60fps 预算内），零热点；渲染层新增 250ms 灾难守门。
- **验收台账**：六阶段对账、无障碍/键盘/性能基线、宿主现场清单（H1~H8）四份台账就绪（docs/d307-final-ledger-2026-09-29.md 索引）。
