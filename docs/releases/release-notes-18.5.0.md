# 小驴打卡 v18.5.0

设置页与外部联动重新分组，移动端已完成打卡项折叠修复，外部来源配置与数据边界进一步明确。主存储 v3、最低思源版本 3.8.4 不变，可直接从 18.4.0 升级。

## 更新内容

- **设置页分组**：思源文档写入（日记、摘要）与第三方来源联动（思阅、健康、思播、微信读书、叶归）分开显示，每个来源独立卡片。
- **配置流程优化**：统一显示绑定目标、保存/启用步骤、本地配置状态、数据流、隐私边界、停用保留、重绑历史和查询上限。
- **外部联动守门**：时长来源要求分钟项目；健康来源校验指标单位与日期；思播显示宿主 controller 状态；微信读书 Key 保持本地；叶归按绑定笔记本的当日 Marker 块读取并幂等结算。
- **手机端折叠**：已完成打卡项支持展开、折叠、恢复，ARIA 状态、列表隐藏状态与偏好同步。
- **质量基建**：完整测试、移动视觉矩阵、真实性能、生态契约、发布清单和回滚演练均纳入候选验收；修复构建时间戳导致的摘要同步竞态。

## 升级与验证边界

所有外部来源默认关闭，微信读书 Key 由用户自助申请。真实 Android/WebView 触摸命中、微信读书实际 Key、叶归实际笔记本和第三方宿主联动仍需在对应环境现场确认。
