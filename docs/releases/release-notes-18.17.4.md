# 小驴打卡 v18.17.4

全插件 UI 与性能细节复核版本，聚焦长列表滚动、图片布局稳定性和首屏加载体验，可从 v18.17.3 直接升级。

## 更新内容

新增：

- Today 长列表按卡片延迟绘制，降低大量项目同时渲染时的压力。

优化：

- 头像、日志附件和历史缩略图补充固定宽高与异步解码，减少加载时布局抖动。
- 自定义图标和附件图片继续使用懒加载，保持安全 URL 校验和现有交互。

修复：

- 修复短横屏场景下延迟绘制卡片可能影响靠近滚动边缘按钮命中的问题。

## 兼容性与验收范围

- 主存储、事件身份、公开 API v5 和最低思源版本 v3.8.4 保持兼容，无数据迁移。
- 本地质量链覆盖类型、主/UI/移动/生态/扩展/性能测试、生产构建、视觉与宽度走查、发布资产和回滚演练。
- 真实思源桌面客户端、Android/TalkBack、第三方账号、缩放与保存面板仍需现场验证；本次发布到 GitHub Releases，不推送思源集市。
