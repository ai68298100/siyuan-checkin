# 小驴打卡 v18.17.2

全插件 UI 复核后的提醒布局、入口一致性和短屏体验修复，可从 v18.17.1 直接升级。

## 更新内容

- Today 的“未来七天负荷”调整到主任务区域下方，减少宽屏空洞并保持打卡操作集中。
- 提醒通知在可见 Dock、Tab、Dialog 中以内联文流显示，避免覆盖 Today、编辑器预览和事项内容。
- 短屏提醒收敛到 64px，编辑器、事项长文本、More 入口和移动底栏经过补充走查。
- 同步更新 README、版本变更记录、宽度矩阵和移动质量守门，发布资产由同一提交构建。

## 兼容性与验收范围

- 主存储、事件身份、公开 API v5 和最低思源版本 v3.8.4 保持兼容，无数据迁移。
- 本地验收覆盖类型、主/UI/移动/生态测试、生产构建、Chromium 明暗主题、Dock 明暗主题宽度矩阵、发布资产完整性和回滚演练。
- CSS 产物为 657,073 bytes；D-463 将维护态硬阻断线调整为 660 KiB，620 KB 软提醒、死类检查和重复规则检查保持不变。
- 真实思源、Android/TalkBack、第三方账号、缩放与保存面板仍需现场验证；本次发布到 GitHub Releases，不推送思源集市。
