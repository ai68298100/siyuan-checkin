# 小飞驴打卡 v15.0.0

这是跨端交互与批量性能版本：Today 卡片菜单支持鼠标、触屏和键盘；批量完成、归档、删除收敛为单事务；归档页增加摘要与批量管理；删除并发复核和自动归档批处理进一步提升多窗口可靠性。

## 更新内容

- **跨端卡片菜单**：桌面右键、触屏/触控笔长按均可编辑、归档和删除，支持完整键盘导航与焦点恢复。
- **批量完成/归档/删除**：每次操作只持久化一次，失败整批回滚；筛选后的全选不会影响不可见项目。
- **归档页增强**：显示累计达成天数和最近记录，支持筛选集全选、批量恢复、批量删除及窄屏布局。
- **删除并发安全**：确认后若其他窗口改变项目或记录数量，本次删除安全中止并要求重新确认。
- **自动归档批处理**：多个项目同时达标时共享一次事务，通知聚合但仍发送逐项目兼容事件。
- **生态摘要 API**：新增有界的本地日期区间聚合接口和“任务打卡”模板，方便 Task Horizon 等插件安全读取。
- **性能守门**：新增十万级回顾、批量追加、批量删除和自动归档性能基线。

## 安装

下载本 Release 的 `package.zip`，在思源中通过“设置 → 集市 → 下载安装包”安装。升级前建议在插件设置页导出 JSON 备份。
