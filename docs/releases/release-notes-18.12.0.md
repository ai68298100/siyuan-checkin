# 小驴打卡 v18.12.0

「设置页体验」批次（用户反馈驱动的 4 项实施落地）：统一文档选择器覆盖全部绑定入口、设置页目标卡在所有宽度恢复单列卡面（逐字竖排/挤压消除）、设置页字体层级三档令牌归一、SurfaceContext 读侧扩参与多 root DOM id 唯一化。主存储与公开 API 不变，最低思源 3.8.4 不变，可直接从 18.11.0 升级。

## 更新内容

### 统一文档选择器

- **全绑定入口覆盖**：日记/摘要/健康/问卷/叶归笔记本五张目标卡换用单搜索框+候选行列表——支持名称/路径/ID 搜索、笔记本浏览、↑/↓ 环选、Enter 选中、Esc 收起、IME 组合态安全；旧「按钮+下拉」双框全部退役。
- **候选行元数据**：每行显示文档名称与完整路径双行预览，读屏可及。
- **叶归笔记本**：首次聚焦自动拉取笔记本列表（会话缓存），搜索框客户端过滤；已存笔记本不在列表时保留自动停用+提示行为。

### 设置页目标卡修复

- **全宽单列卡面**：目标卡在 ≥720px 容器不再被「标签|控件」两列行栅格压入 240px 窄列——摘要逐字竖排与字段挤压彻底消除（此前用户截图中的「乱码」实为 CJK 字符在 0~14px 列宽内逐字竖排的伪乱码）。
- **类名退役**：五张目标卡不再复用 `settings-row` 行类，行栅格规则不再与卡竞争；CSS 死类清理。

### 设置页字体层级归一

- 三档类型令牌（标题 720 / 次级强调 650 / 帮助 11px）统一设置面 12 处散布字重（620/640/660/700→两档）与帮助字号（10/10.5/11→11px）。
- 探针双档计算样式验证一致（420/1180）；分组折叠头字重归一。

### SurfaceContext 读侧扩参

- 合同 1 全形状聚合：日期（review day 钻取）、范围、工作区、查询、筛选（scope/source/order/page/reminder，默认值不进上下文）；返回路径分派不受影响。

### 安全与多表面

- 提醒中心标题与事项预设 datalist id 按渲染次序唯一化（多窗口同屏读屏不串台）。
- 目标摘要附 title 全值（悬停可读完整名称/路径/ID）。

## 边界与说明

- 主存储结构、公开 API 写入面、`externalRef` 幂等注册表不变；升级无需迁移。
- 统一选择器的真实搜索与多窗口并发建议按 [集成冒烟清单](integration-smoke-checklist.md) 抽查。
