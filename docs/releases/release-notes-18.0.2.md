# 小驴打卡 v18.0.2

本次小版本修复回顾布局、图表自适应和中文输入，并完善头像编辑、日记文档选择/新建及回顾助手入口。

## 更新内容

- 回顾统计周期、记录数值与操作区对齐；图表随面板宽度展开，修正窄屏字号和移动端滚动。
- 今日搜索保留中文输入法组合过程，避免旧计时器中断拼音输入。
- 支持预设、文字和照片头像，照片可拖动取景、缩放、重置和取消。
- 日记设置支持搜索文档、选择笔记本新建文档，并明确区分搜索、创建和保存失败。
- 复制回顾提问后尝试打开思源智能体；面板不可用时提示手动打开，不自动发送。
- 补充间隔复习、文档绑定、每日日记、同类产品和闪卡联动的后续调研计划；这些研究功能尚未开发。

## 升级与验证边界

最低思源版本为 3.8.4，可直接从 18.0.1 升级；主存储 v3、公开 API v5 与契约 storeVersion 2 不变。日记写入仍默认关闭、手动触发并仅追加到绑定文档。

本地自动化验证结果见 [发布验收记录](../release-validation-18.0.2.md)。真实思源桌面端与 Android、软键盘/安全区、只读/发布服务、智能体面板和双插件联调仍有待验收项，不将浏览器模拟视为真机验收。
