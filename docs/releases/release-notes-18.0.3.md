# 小驴打卡 v18.0.3

本次补丁版本完成间隔复习、文档绑定、每日日记、同类产品和闪卡联动的研究收口，并明确后续小版本边界。插件功能、数据结构与公开 API 保持不变。

## 更新内容

- 普通习惯保留现有固定间隔；知识复习仅在独立模式中继续评估 FSRS。
- 文档绑定复用 `noteAnchor`，后续先完善打开、挂起和移动端降级。
- 日记先采用只读摘要和用户确认写入，暂不自动创建或修改每日笔记。
- 闪卡调度归思源宿主，暂不轮询到期队列、自动记账、制卡或同步调度。
- 增量复核 Loop、Table Habit、Obsidian Tracker、思源插件与 SiYuan v3.8.4 API，形成采用、延后和不做矩阵。

## 升级与验证边界

最低思源版本仍为 3.8.4，可直接从 18.0.2 升级；主存储 v3、公开 API v5 与契约 storeVersion 2 不变。研究结论不代表候选功能已经实现。
