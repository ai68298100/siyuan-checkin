# 小驴打卡 v12.0.2

这是 12.0 系列的性能与可靠性维护版本，重点优化大数据读取、移动质量门禁和底栏番茄钟兼容准备。

## 更新内容

- 新增事件 ID、项目日期、日期和日期范围只读索引，减少回顾、历史操作和统计中的重复扫描。
- 新增项目 ID/启用状态索引，优化打卡、专注、回顾和联动流程中的项目查找。
- 日期范围使用按需排序和二分边界，保留原事件顺序，不改变已有统计口径。
- 完全退役生产 legacy 样式入口，统一设备能力、移动端和模板规则的样式归属。
- 76 个测试文件全部接入质量链，孤立或退役测试为 0。
- 完善底栏番茄钟消费端的诊断、幂等、重试和安全边界；上游兼容 API 尚未发布，因此本版本仍建议使用自带番茄钟。

## 安装

下载本 Release 的 `package.zip`，在思源中通过“设置 → 集市 → 下载安装包”安装。升级前建议在插件设置页导出 JSON 备份。

## 验证说明

自动化测试覆盖类型、构建、主功能、UI、移动端、生态、性能和发布资源。真实思源桌面、移动端、dock、安全区、软键盘和底栏番茄钟双窗口仍建议现场复核。
