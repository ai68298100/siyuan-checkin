# 小驴打卡 v18.17.5

现代桌面质感重塑与 UI 原型 v3 对齐版本，引入 Hero「下一步」行动卡、Bento 统计网格与健康总览矩阵，可从 v18.17.4 直接升级。

## 更新内容

新增：

- Today 首屏落地 Hero「下一步行动卡」，清晰突出当前唯一建议做的事，支持一键记录与快速专注。
- Settings 设置页落实 2×2 Bento 健康总览卡片网格，状态胶囊带有彩色呼吸指示灯并支持一键去配置。

优化：

- 引入物理微材质：卡片顶部 1px 物理微高光（明暗双主题自适应）与双层环境漫反射阴影。
- 排版与数字防抖动：全局启用等宽数字（tabular-nums），消除计数、计时器与百分比宽度跳动。
- 交互手感提升：引入仿 iOS/macOS 物理弹簧微缓动曲线，按钮悬停浮雕与按压物理微回弹。
- 纯化残留的 Unicode 纯文本符号为标准规范 SVG 矢量图标，杜绝跨系统字体差异变形。
- 全面清理 7px~11px 极端微小字号，收敛提升至 ≥12px，确保在窄屏与 Dock 侧边栏下清晰可读。

## 兼容性与验收范围

- 主存储、事件身份、公开 API v5 和最低思源版本 v3.8.4 保持兼容，无数据迁移。
- 本地质量链覆盖类型、主/UI/移动/生态/扩展/性能测试、生产构建、视觉与宽度走查、发布资产和回滚演练。
- 真实思源桌面客户端、Android/TalkBack、第三方账号、缩放与保存面板仍需现场验证；本次发布到 GitHub Releases，不推送思源集市。
