# 小驴打卡 v18.6.0

问卷式日记打卡上线：打卡项目可绑定问卷模板（感恩三问、九宫格晨间日记等 5 个预设或自建），填写后完整内容写入当日日记或指定文档。同时交付数值快捷增量、年度分享图导出、里程碑分级庆祝与低压力呈现基线。主存储 v3、最低思源版本 3.8.4 不变，可直接从 18.5.0 升级。

## 更新内容

- **问卷式日记**：项目绑定模板（5 个双语预设或自建问题集），打卡时弹出问卷，完整内容写入当日日记或指定文档；同日重填幂等更新、不重复记账；文档写入失败不影响打卡（审计 + 提示）。
- **快捷记录**：数值项目可配预设增量按钮一键记录；今日行动台完成度环；回顾统计区近 30 日趋势迷你线。
- **相关性洞察**：报告新增项目间关联（重叠 ≥4 天且 |r|≥0.4 才收录，固定附「相关不等于因果」说明，纯本地统计）。
- **渲染块**：month 块超额日正向描边；today 块分时段（早/午/晚）记录计数。
- **分享图**：年度格子 + 统计本地生成 PNG（跟随主题，零网络零遥测）。
- **里程碑庆祝**：连击 7/30/100/365 天等阶梯时反馈升级（减弱动态偏好下降级为静态金标）。
- **低压力基线**：失速卡「双日规则」文案、calm 文案禁则守门、色盲安全色阶冗余编码、移动端 44px 触控目标、66 天习惯成熟度参考刻度、诊断导出结构化预览。
- **迁移健壮性**：Loop CSV 未识别列导出前点名不静默丢弃；跨午夜归账边界证据；导出向前兼容承诺。
- **清理**：零消费的 loading/success/saving 呈现词汇退役并有防回流断言。
