# 小驴打卡 v18.27.0

「报告导出全来源筛选支持与趋势比对算法性能优化」小版本发布：深度重构并补齐 Review 回顾报告导出（Report Markdown）对外部联动来源（思阅、思播、微信读书、叶归 LifeLog）的完整声明展示支持，收敛来源类型转换与断言契约；项目趋势比对（Item Trend Compare）重构为哈希桶预索引算法，消除 31 日循环内部全量过滤 `store.events` 的高频计算损耗，大幅降低长周期历史数据下的 CPU 占用。主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 报告与复盘：Markdown 导出全生态来源筛选支持（T-1919，D-570）
- **全生态来源回显无遗漏**：重构 `buildWeeklyReportMarkdown`，将 `REPORT_SOURCES` 白名单完整扩充至全部 8 种来源（`manual`, `tomato`, `api`, `import`, `sireader`, `siplayer`, `weread`, `yeguif`）；无论用户在回顾页如何筛选单一来源导出，周报与周期报告均精准回显来源声明行。

### 2. 算法与性能：项目趋势比对多日序列预索引优化（T-1920，D-571）
- **O(N) 预归类消除百万次内循环**：在 `buildItemTrendSeries` 中使用 `Map<string, CheckinEvent[]>` 对目标项目事件做一次性哈希分桶，彻底废弃原有多日循环体内对 `store.events` 的重复全量遍历，时间复杂度由 O(31 * N) 骤降为 O(N)，大数据集下比对丝滑秒开。
