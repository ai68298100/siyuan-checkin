# 小驴打卡 v18.17.0

「双机合并后的事项工作台、微信读书推荐与跨表面可靠性收口」版本。主存储、公开 API v5、最低思源版本和既有导入格式保持兼容，可直接从 18.16.0 升级。

## 更新内容

- 微信读书推荐引擎与设置页推荐草案预览。
- 事项重复确认、规则预览、排序、改期冲突、逐次完成、提醒状态和关联项目跳转。
- 多 root 状态隔离、草稿恢复、失败回执、导入失败回滚和提醒写入生命周期保护。
- 键盘日期导航、IME 搜索、移动端表单定位、焦点恢复和读屏状态改进。

## 兼容性与升级

- 插件清单最低兼容版本仍为思源 v3.8.4。
- 升级前建议从设置页导出 JSON，并核对[备份范围](../export-formats.md)。
- 外部来源仍默认关闭；Key、目标 ID 和映射只保存在本地偏好。
