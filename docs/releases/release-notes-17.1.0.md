# 小飞驴打卡 v17.1.0

宿主契合度版本：对照思源 3.8.4 源码逐条核对插件的卸载收尾、多窗口合并、智能体接入与移动端交互，修掉四类用户可见问题，并补上「真内核 + 真插件实例」的端到端验证。存储结构不变（仍为 v3），可直接升级。

## 你会感觉到什么

- **关闭或禁用插件不再丢最后一条打卡**：卸载收尾改为在宿主的 5 秒拆除预算内有界完成，队列里攒下的变更合并成一次落盘；万一仍排不进去，会明确提示「请重新打开面板确认最新打卡」，而不是静默丢失。
- **专注计时不再泄漏**：禁用插件时正在进行的专注会先入账已投入的分钟数，再停掉秒级心跳与庆祝提示的延时器；插件注销后不再有任何后台写入。
- **手机端回顾页修好三处**：复制报告 / 导出报告 / 报告设置 / 更多 四个控件同一基线（此前按钮被下沉 15px、还套了两层胶囊，「更多」被推到最右留出空洞）；「报告设置」「更多」「自定义范围」点开后的浮层不再被裁成一条（此前 220px 的菜单只剩约 8px 可见，还被统计卡片压住）。
- **手机端点导出不再导致思源重启**：思源 Android/iOS/鸿蒙客户端的 WebView 没有网页下载能力，原来的 `blob:` 下载会被当成一次导航打到宿主自身。现在导出先写入工作区 `assets/`，再交给系统保存面板——因此**手机端导出会在「资源文件」里留下一个文件**，与思源自身导出行为一致。桌面端与浏览器不变。
- **智能体接入状态不再误报**：设置页原来把「数据读取失败」也显示成「未检测到可用的思源智能体入口」。现在分四种状态说明（宿主不支持 / 正在初始化 / 注册中断并附原因 / 已注册 11 项能力），并给出在 设置 - 人工智能 - 能力 里的核对位置。
- **打卡日志不再一次铺满**：最近日志改成「月份 → 周 → 日期」三级折叠，默认只展开最近一层；每周、每日项目和同项目逐条明细都按有界批次继续展开，同时保留准确的天数与记录数。

## 稳定性与兼容

- 多窗口合并的写放大消除：接收方不再把建议工作流原样重写回磁盘，审计诊断在同一变更窗口内合并为一次写入（实测一次跨窗口变更的辅助存储写入由 2 次降为 0 次）。
- 文档内 ```checkin 渲染块的代码块读取增加四级回退，思源小版本改动 DOM 结构时不再静默不渲染。
- `docs/siyuan-compatibility.md` 重写为如实登记：三处依赖思源内部 DOM 的位置与降级边界、11 项智能体能力（7 只读 / 4 写入）、拆除预算、连远端内核（`?remote=1`）时插件整体不加载、只读与发布模式下保存被拒的行为差异。
- 移动顶栏入口的无障碍名称改为随插件语言切换（中/英）。

## 验证

- 新增 7 个测试文件（拆除预算、渲染块与文档一致性、辅助写入卫生、智能体状态、路径可移植、导出通道、日志层级），测试清单 126 个文件、0 退役。
- 新增真实例端到端：独立测试工作区 + 真内核 + 真插件实例，覆盖打卡落盘与重载恢复、`externalRef` 幂等、双窗口 `onDataChanged`、宿主禁用/启用、移动 bundle、宿主侧智能体登记、只读实例。
- 完整质量链（类型、构建、功能、UI、移动、生态、扩展、对比、性能、发布资源）与端到端全部通过（思源 3.8.4）。
- 仍需真机复核：系统保存面板、软键盘与真实 WebView 下载行为要在目标 Android/iOS 设备上现场确认，自动化不替代这一步。

## 安装

下载本 Release 的 `package.zip`，在思源中通过“设置 → 集市 → 下载安装包”安装。升级前建议照例导出 JSON 备份；回滚不会删除插件数据，见 `docs/release-rollback.md`。
