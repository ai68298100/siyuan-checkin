# 小驴打卡 v18.17.1

全插件功能与 UI 复核后的可靠性和体验补丁，可从 v18.17.0 直接升级。

## 更新内容

- 设置、页面偏好、恢复点和记录回执在保存失败时保留草稿、恢复状态并支持重试。
- 来源待处理箱与 Dock Tomato 清理失败不再误报完成，重试不会重复累计事实。
- 周复盘保存、导出、复制 AI、清除统一防重复点击并显示忙碌状态；导出失败反馈可见。
- 今日、事项、回顾和弹窗的导航、排序、焦点及异步反馈按发起页面隔离，避免多窗口串页。
- 修复无效日期、CSV 半行导入、公开 API 重复回执与生命周期返回值；完善键盘、双语和减少动效体验。
- 异常提示清理凭据、路径和控制字符，动态图标与附件保留安全输入边界。

## 兼容性与验证范围

- 主存储、事件身份与公开 API v5 保持兼容；最低思源版本仍为 v3.8.4。
- 升级前可从设置页导出 JSON，并核对[备份范围](../export-formats.md)。
- 本地验证覆盖质量链、Chromium 明暗主题、宽度矩阵、发布资产完整性与回滚演练。
- 真实思源、Android/TalkBack、第三方账号、缩放与保存面板现场证据仍待补齐；本次没有发布到思源集市。

完整变化见 [18.17.1 变更记录](../v18.17.1-change-log.md)。
