# 8.0 变更记录

## 概览

8.0 主题为「打磨与平台」：主题色板系统、性能基准守门、细节走查清单、发布流水线脚本与 i18n 基础设施。存储与 API 保持向后兼容。

## 新增

- **主题色板系统（设置 → 外观 → 强调色）**：薰衣草紫（默认）/ 海洋蓝 / 森林绿 / 落日橙 四套强调色，明亮 + 暗黑双模式各自调校，切换即时生效并持久化。
- **性能基准守门（`pnpm run test:perf`）**：10,000 事件 fixture 下全量渲染基线断言（实测 158ms，门槛 3s）+ 无横向溢出 + 零页面错误；无浏览器环境自动跳过。
- **百项细节走查清单（`docs/detail-checklist.md`）**：8 界面 × 6 维度（空态/错误态/极端数据/微交互/无障碍/主题）共 48 个走查单元，已核验项与待真实客户端项分列，随版本持续更新。
- **一键发布流水线（`scripts/release.cjs`）**：版本号 → 构建 → 全部测试链 → 提交推送 → tag → GitHub Release（自动写入 SHA-256）。
- **i18n 基础设施（`src/i18n.ts`）**：zh-CN / en-US 字典 + `t()` 查询，导航文案已迁移；全量文案抽取列入 8.1 持续迁移。

## 变更

- 打卡日志按天渲染上限保护，配合已有的 14 天窗口与 999+ 徽章封顶，构成大数据量下的渲染防线。

## 兼容性

- 需要思源 v3.4.2+；存储结构与 `window.siyuanCheckin` API（v4）保持兼容。

## 验证

- 全部测试链（含新增 `test:perf` 性能基准）通过；双主题 harness 与 12 组"宿主宽度 × 页面"走查通过。
