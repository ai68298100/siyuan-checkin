# 小驴打卡后续大版本路线（2026-09-17）

> **2026-09-18 增补**：基于竞品调研（`docs/benchmark-habit-apps-2026-09.md`）的融合路线已定稿于 `docs/roadmap-habit-evolution-2026-09.md`，覆盖 v16.1 → v19 的合并节奏（v16.1~v16.3 复盘呈现与习惯内核、v17.0~v17.2 生态联动与笔记回写、v18 开放生态、v19 习惯内核二期）。本文档 v14~v18 主题与门槛继续有效；版本顺序与任务分解以融合路线为准。

## 当前基线与原则

- 最新发布版为 `v13.0.0`（2026-09-17）；官方集市已收录（Bazaar PR #2248 已合并）。
- 12.x 已具备打卡、事项、提醒、回顾、模板、备份恢复、跨窗口事件、只读生态 API 和跨端 UI。
- B-001/B-007、T-023/T-129 仍需真实思源桌面、手机、页签、dock、软键盘和双窗口证据，自动化不能代替真机。
- 13.0 专注生态的消费端能力已随 12.0.x/13.0.0 发布；上游 Dock Tomato 兼容 PR 与真机联调仍归 B-007。14.0 数据内核的可自动化范围（写前收敛、写后校验、墓碑并发、十万级索引化）已随 13.0.0 发布（版本决策见 D-156）。
- 发布工程、性能、无障碍、数据恢复和跨端回归成为每个版本的持续门槛。
- 主线下一步：`15.0 UI 系统`；其后为 `16.0 复盘计划 → 17.0 受控自动化 → 18.0 开放生态`。

## 12.x：现场稳定与集市反馈

目标：把已发布能力在真实思源环境中验证扎实。

- 验证桌面、移动、页签、dock、窄侧栏、安全区、软键盘和多窗口。
- 复核局部刷新、完成/撤销、提醒延期/跳过、设置导航和长页面浮动导航。
- 跟踪官方集市审核、安装、升级、卸载重装和数据保留。
- 只处理高影响缺陷、兼容回退和数据安全问题，不增加大型功能。

完成门槛：T-023/T-129 有真实记录，无已知数据损坏问题。

## 13.0：专注计时与任务生态

目标：形成“打卡项目 → 外部专注 → 完成回写”的稳定闭环。

- 用户确认后推进 Dock Tomato 上游 PR，并按维护者意见收敛公共契约。
- 提供 provider 检测、能力协商、未就绪/忙碌/版本不兼容诊断及自带计时降级。
- 固化 session 身份、幂等回写、次数/分钟/小时映射和暂停/恢复/放弃语义。
- 双方先确定权限、时间游标和保留范围，再设计错过实时事件的有界补偿接口；不读取私有文件。
- 预留第二 provider 的注册规范，但没有真实目标和契约前不显示空壳选项。
- 覆盖双加载顺序、热重载、双窗口、多端同步和任一插件中途停用。

完成门槛：上游兼容版本可安装；真机跑通开始、暂停、恢复、完成、放弃、冲突和重载；重复回调不重复记账。

## 14.0：数据内核与长期可靠性

目标：在数据增长、跨版本迁移和多窗口并发下保持可恢复、可验证。

- 统一事件、事项实例、提醒动作、番茄来源和审计记录的版本化身份。
- 固化跨日、时区、DST、修改计划、归档和恢复后的统计口径。
- 完善迁移预检、变更摘要、校验报告、失败回滚和恢复点生命周期。
- 优化万级/十万级历史的索引、范围查询、增量派生和渲染输入。
- 加固多窗口冲突、幂等 tombstone、旧版本回放和损坏数据隔离。
- 分离公共数据 schema 与内部存储 schema，第三方不得依赖私有持久化结构。

完成门槛：迁移/回滚演练、大数据性能、冲突和中断恢复均有自动化证据。

## 15.0：统一 UI 系统与跨端体验

目标：偿还 CSS 覆盖债，形成紧凑、稳定、可预测的跨端界面系统。

- 完成 T-105，退役 legacy `index.scss`，明确组件、布局、响应式和宿主变体职责。
- 合并 dock 多档重复规则；颜色、间距、圆角、阴影、字号、按钮高度和动效归一到 token。
- Today、事项、回顾、设置、编辑和弹层复用统一顶栏、工具栏、卡片、筛选、空态和反馈组件。
- 手机端坚持单列、拇指操作区、安全区、软键盘视口和单滚动所有权；dock 保持 320px 可用下限。
- 统一加载、保存、成功、冲突、错误、撤销和无感保存，消除布局跳动与整页闪烁。
- 补齐键盘顺序、ARIA 动态区域、减少动效、大字号、双主题和高对比度验证。
- 在功能不退化前提下清理重复 CSS，完成后依据实测下修预算。

完成门槛：全页面宽度、双主题、无障碍与真机截图留档；无横向溢出、双根滚动和关键操作遮挡。

## 16.0：复盘、目标与计划闭环

目标：从“记录发生了什么”升级为“知道变化、原因和下一步”。

- 统一日/周/月/年和自定义范围，增加目标线、完成质量和计划偏差。
- 重构热力图、趋势图、日志、提醒逾期、成就和事项回顾的信息层级。
- 支持周报/月报模板、可配置摘要、对比基线、异常说明和安全导出。
- 增加周期目标、里程碑、暂停、调整历史和可追溯的达成判定。
- 本地生成“最值得关注的一项”和行动建议，数据不足时明确说明。
- 多次打卡按项目/日期聚合，同时保留展开明细与准确时间。

完成门槛：所有指标可追溯到原始事件和版本口径；空数据、小数据、跨时区和修改目标均有清晰表达。

## 17.0：受控自动化与智能体协作

目标：自动化重复维护工作，同时始终保留用户控制权。

- 将建议工作流扩展为结构化草案：新建/调整项目、提醒整理、事项延期和复盘计划。
- 所有写入经过差异预览、影响范围、确认、审计、撤销和冲突检查。
- 增加本地规则建议，例如达标后调整目标、逾期后建议延期，默认只建议。
- 建立稳定错误码、恢复动作、超时、重试和幂等引用。
- 读取、草拟、执行使用不同 capability 和最小权限，不提供万能写入口。
- 批量操作只在单项路径长期稳定、可撤销且真实验证后开放。

完成门槛：未配置模型时基础能力完整；所有自动化写入可解释、可审计、可撤销，无静默执行路径。

## 18.0：开放生态与规模化发布

目标：向其它思源插件开放成熟能力，同时控制兼容和维护成本。

- 稳定 `window.siyuanCheckin` 的版本、能力发现、事件 schema、错误码和弃用周期。
- 发布类型定义、最小示例、集成指南、契约测试包和兼容矩阵。
- 建立适配器准入清单：身份、幂等、卸载清理、权限和失败隔离必须通过测试。
- 自动化集市发布、预发布、升级/降级、回滚包、资产摘要和变更日志。
- 建立低端设备、大数据和多插件组合的长期性能基线；诊断导出必须由用户主动触发。
- 评估共享模板和跨设备协作，隐私、冲突和撤销模型明确后才实现。

完成门槛：公共契约有至少两个真实消费方或明确维护价值；破坏性变更有迁移期；发布与回滚可重复。

## 持续门槛与近期顺序

每轮运行 `pnpm run test:quality`；发布前补 Chrome 视觉、宽度和无障碍检查。每次发布记录版本、提交、CI、资产大小和 SHA-256。CSS 超过 420000 bytes 必须说明，超过 450000 bytes 阻断，15.0 后重新制定更紧预算。

近期顺序：

1. 冻结 Dock Tomato 本地 PR，等待用户通知，不 push、不创建 PR。
2. 收集 12.0.1 真机和官方集市反馈，完成 T-023/T-129。
3. 以 13.0 专注生态为下一主线；上游未确认前只完善小驴打卡侧诊断、降级和测试。
4. 并行准备 14.0 数据规模基准与 15.0 legacy CSS 清单，不提前大改用户可见结构。

未经用户确认，不 push、不创建第三方 PR、不修改远程 Release，也不自动同步本地集市目录。
