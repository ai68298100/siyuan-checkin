# 17.2.1 变更记录

## 全页 UI 与记录流程修订

- 今日卡片按当天排期数量和容器宽度自适应：超过 12 项进入紧凑布局，宽屏紧凑布局支持三列，长名称和长单位自然换行。
- 时长项目与非二值番茄来源项目同时提供专注计时和手动记录入口；底栏番茄钟完成按分钟/会话正确回写并幂等处理。
- 回顾页统一趋势单位、日活跃说明、年度热图、日志、历史操作、建议和报告的内容层级；长备注、长项目名和图片图标完整显示。
- 新建、复盘、归档、事项和设置页面完成窄屏、长内容、触控尺寸和自定义图标适配。
- 修复番茄钟收件箱小时换算、月度/每周事项隐藏字段覆盖、月度和年度第 N 个星期序数选择等问题。
- 公开 API 保持 v5，兼容 v4 能力；不改变主存储结构，可直接从 17.2.0 升级。
