# 9.0 变更记录

## 主题：性能优化

### WeakMap 事件索引

- **核心优化**：新增 `getStoreIndex()` 使用 WeakMap 按店对象自动缓存事件索引
- `getEventsForDay` 从 O(E) 全量扫描变为 O(1) 查表
- 所有依赖它的函数（`getProgress` / `isComplete` / `evaluateRule`）自动受益
- 索引随 store 对象生命周期自动创建和销毁（WeakMap），无内存泄漏
- **实测：10k 事件全量渲染 158ms → 92ms，提升 42%**

### 渲染合并

- 新增 `scheduleRender()` 使用 `requestAnimationFrame` 合并同一帧内的多次渲染请求
- 减少不必要的重复 DOM 替换和事件重绑定

### 兼容性

- 需要思源 v3.4.2+；存储与 API 完全兼容；无数据结构变更
