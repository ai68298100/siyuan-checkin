# v18.17.1 变更记录

批次：全插件功能与 UI 复核后的可靠性和体验修复（2026-10-09），可从 v18.17.0 直接升级。

## 反馈与持久化

- 页面偏好、设置草稿、导入和恢复点写入失败时回滚内存，保留输入和重试反馈。
- 来源待处理箱与 Dock Tomato 的事实写入、箱清理共同决定成功；清理失败恢复条目，后续重试保持幂等。
- Review 周复盘保存、导出、复制 AI 和清除共享忙碌状态，导出透传保存通道结果并提供双语失败提示。
- 记录回执、诊断清理和外部候选状态在失败与重试后保持一致，不提前显示完成。

## 页面与交互

- 今日、事项、回顾、编辑器和快速弹窗的导航、排序、焦点及迟到反馈按发起 root 隔离。
- 修复重复绑定、草稿离开守卫、来源配置切换及卸载后的异步写入和反馈。
- 增加日期格键盘激活、选择器无结果提示与唯一可访问关联；热力图和相关入口补齐双语文案。
- 减少动效设置匹配真实页面根节点，窄屏首卡、动作颜色和长内容布局经过回归。

## 输入、安全与 API

- 日历、排期和统计拒绝无效日期；配额边界按民历日处理跨 DST。
- CSV 拒绝未闭合引号和截断半行，错误反馈包含行号与原因。
- 公开 API 返回独立快照，批量重复记录回填事件身份；`completeOccasion` 在未就绪、非法参数或队列未执行时稳定返回 `false`。
- 异常反馈清理凭据、路径和控制字符；动态图标、附件和导出数据保留明确输入边界。

## 兼容性与验收

- 主存储、事件身份、公开 API v5 和最低思源 v3.8.4 兼容；升级无需迁移。
- 发布检查以完整质量链、Chromium 明暗主题与宽度走查、ZIP 摘要和回滚演练为证据。
- 真实思源客户端、Android/TalkBack、第三方账号、缩放与保存面板仍需现场验证；本地浏览器夹具不替代这些证据。
