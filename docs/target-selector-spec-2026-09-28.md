# 思源目标选择器统一规范（T-1556，2026-09-28）

## 定位

- 为**文档 / 块 / 笔记本 / 当日日记**四种目标建立共享选择器规范；实施归 T-1557（组件化）/T-1558（体检与换绑确认）/T-1559（失效恢复闭环）。
- 依据：[联动研究稿·绑定专项]（入口不统一/目标信息不足/保存反馈弱/失效修复割裂/范围语义不直观五问题）、[设置字段注册表](settings-field-registry-2026-09-28.md) A 类文档目标保存现状、[联动专项视图](integration-capability-registry-2026-09-28.md) 六使用点归属。
- 现状锚点：`validateBindingTarget`（存在性/类型/文档根/笔记本打开，SQL 元数据）、日记文档搜索防抖（index.ts:4235-4254，`/api/query/sql`）+ 新建文档（4291）、问卷共享 picker `bindDocumentTargetPickerFor`（journal-dialog.ts:28，防抖 180ms）、叶归笔记本加载（4183，`lsNotebooks`）、集中绑定体检（3814-3868，`collectNoteBindings`）、编辑器锚点选择器（editor.ts:279-291）。**不臆造可写权限预检 API**（D-307 边界）。

## 契约 1：四种目标类型

| 类型 | 机器身份（已存，不变） | 查询/检查面（现状可证实） | 特有语义 |
| --- | --- | --- | --- |
| 文档 doc | 文档 ID（20260101120000-xxxx） | SQL 元数据：存在、类型=文档、文档根、所属笔记本、路径标题 | 可选「新建文档」（createDocWithMd，现仅日记入口有） |
| 块 block | 块 ID | 同上 + 类型必须为块；锚点另查块存在性与所在文档 | 只更新插件自写块（锚点所有权边界） |
| 笔记本 notebook | 笔记本 ID | `lsNotebooks`（列表、关闭状态） | 只读范围=笔记本内当日新建段落（叶归） |
| 当日日记 daily | 笔记本 ID（按日记路径规则解析） | 笔记本存在 + 日记路径规则解析；可创建当日文档 | 目标随日期变化，保存的是笔记本+规则 |

## 契约 2：统一交互流（五步）

1. **选目标类型**：使用点已固定类型的可省略此步（健康=文档、锚点=块、叶归=笔记本、日记报告=当日日记），但选择器上仍显示类型徽标。
2. **笔记本过滤**：文档/当日日记先选（或确认）笔记本；列表加载失败、无打开笔记本分别给出修复动作（重试加载/先去思源打开笔记本），**「列表为空」不当作「没有笔记本」**。
3. **搜索 / 最近使用**：搜索防抖（沿用 180ms 模式）；最近使用=本会话内该使用点已确认过的目标（会话态，不持久）；无结果空态带「清除筛选」与「新建文档」（仅文档类型）。
4. **结果预览**：结果行显示——可查询到的**名称、层级路径、所在笔记本、类型徽标、检查状态**；搜索文本含 ID/路径/标题（现有 data-anchor-search-text 模式推广）。
5. **保存**：仍以既有 ID 为机器身份写入原存储字段；保存前经 `validateBindingTarget` 同源校验，失败保留旧绑定与草稿（bindVerifiedDocumentSave 既有回滚语义推广到全部使用点）。

## 契约 3：已选目标卡（五动作）

每个使用点的已选目标统一呈现为一卡：`当前目标摘要（名称/路径/笔记本/类型，会话缓存）+ 更换 + 清除 + 打开（openTab）+ 重新检查`。
- 摘要信息为**会话查询缓存**，查询失败退回显示已存 ID + 「重新检查」修复动作；**不新增持久化名称/路径快照**——如需持久先另立数据模型迁移任务（D-307 决策，不改 Store v3 承诺）。
- 「重新检查」= 只读跑一次 validateBindingTarget 同源检查并显示结果时间。

## 契约 4：六使用点差异表（选择器不掩盖来源差异）

| 使用点 | 类型 | 读/写 | 是否创建文档 | 触发 | 失败行为 |
| --- | --- | --- | --- | --- | --- |
| 日记报告 diary | 当日日记 | 写（追加报告） | 是（当日缺失时） | 手动「写入本期报告」 | 写失败不影响事实，报告入口禁用态 |
| 摘要驻留 summary | 文档 | 写（更新驻留块） | 否 | 打卡后自动 | 停写+问题态；事实保留 |
| 健康收件箱 health | 文档 | 读（收件箱行） | 否 | 轮询 | 读失败+问题态；停用保留事件 |
| 叶归 yeguif | 笔记本 | 读（当日新段落） | 否 | 轮询（≤200 块） | 笔记本关闭自动停用+原因 |
| 笔记推导 notequery | 文档或笔记本 | 读（字段/标签行） | 否 | 轮询 | 非法配置 fail-closed 关摄取 |
| 问卷 journal | 当日日记或文档 | 写（答案块） | 否（目标缺失即失败） | 打卡动作 | 事实先落盘、文档失败不回滚；补写幂等 |

每点在选择器下方显示一行范围说明（读/写、读取哪些块、触发、失败暂停）——文案模板复用 [T-1554 状态矩阵](integration-status-matrix-2026-09-28.md)。

## 契约 5：换绑确认（T-1558 实施基准）

换绑/清除前显示四段：旧目标（含失效原因）/ 新目标（预览检查结果）/ 读写范围变化 / 历史与风险（旧事件与文档保留；有限窗口来源提示可能重复摄取——叶归/健康适用）。确认后落库；失败保留原绑定与草稿。**不做可写权限试写预检**——写入能力以真实操作结果与审计呈现。

## 验收门（T-1557/1558/1559 对账）

1. 六使用点全部替换为共享组件，原 ID 输入/各自搜索入口退役后旧配置原样恢复（存储键不变）。
2. 结果行五字段 + 已选卡五动作逐点走查（双语/键盘上下选择/IME/320px/焦点返回）。
3. 笔记本列表失败、全关闭、查询失败、目标失效四类异常各有文案与动作；「重新检查」显示检查时间。
4. 换绑确认四段齐备；集中体检（T-1559）就地修复复用同一换绑确认。
5. 会话缓存命中/回退两路径都有测试夹具；无持久快照写入（存储 diff 为空）。
