# 小驴打卡：愿景、产品边界与本地开发计划

日期：2026-09-27｜决策 D-291｜计划任务 T-1509～T-1523（15 项，全部待开发）

## 1. 结论与证据范围

愿景：**让每一次真实行动成为可信、可解释、可复盘的长期记录，帮助用户以低压力方式持续调整自己的生活节奏。**

产品定位：思源笔记里的本地优先习惯、打卡与复盘工作台。核心闭环为「设定可行规则 → 低成本记录 → 核对事实 → 看懂变化 → 主动调整」，笔记和外部来源围绕这条闭环服务。

下一阶段确定为“深化现有工作台”，不新增一级导航，不做通用任务管理器、云账号、社交排名、RPG 奖惩、万能 AI 写入口。先让数据可靠、规则透明，再增强复盘与配置复用。

本次是当前仓库代码与台账审查，不是重新运行软件、截图走查或新一轮竞品调研。manifest 版本为 18.8.0；发布台账记录已发版，但工作区有大量后续未提交实现，不能把工作区能力全部称为已发布。本文件所称“已有”指代码/台账已有，不代表本轮重新验收或第三方真实联通。

## 2. 用户目标与产品目标

| 用户要完成的事 | 产品目标 | 后续验收指标（目标，非已有测量结果） |
| --- | --- | --- |
| 今天做完就记，不想配置一堆东西 | 今日保持短路径；复杂操作按需展开 | 普通快捷记录保留一次动作；新增面板关闭后回到原焦点 |
| 补记和纠错时不担心账乱 | 每次批量/改动先展示范围与结果 | 预览零写入；失败无部分成功假象；重复点击不重复记账 |
| 知道自动记录为什么出现 | 显示来源、计量方式、归属与处理结果 | 已知来源可追溯；未知来源明确未知；失败可以处理 |
| 知道目标是否过重、规则怎么生效 | 编辑时能看到未来安排与变更影响 | 固定输入可重现；配额、休息、SKIP、限额不混算 |
| 一周后能决定下一步 | 从指标走到原始事实与行动草案 | 分母可展开核对；缺数据不编造原因；建议不自动改目标 |
| 换项目/复用模板不用从头配 | 安全复用、导入前解决冲突 | 不带凭据和绑定 ID；不静默覆盖；重复导入行为明确 |

这些指标由夹具、交互脚本和人工浏览器走查验证；不引入遥测，也不以点击数假装证明用户留存提升。

### 外部联动必须守住的口径

1. 思阅/思播监听型时长按真实片段记录：同日先 20 分钟再 15 分钟是两条记录，和番茄记录的事件思路一致；不以达标阈值代替实际时长。
2. 微信读书只有官方日汇总时保留日汇总语义，不能编造为两次会话；不同计量方式在 UI 明示。
3. 叶归按具体项目类型归属，例如拉伸→拉伸；显式映射表存在时，未匹配类型跳过；无表只允许唯一同名合格目标，不回退到一个通用项目。
4. 相同身份重放幂等，用户撤销形成墓碑；未知身份不做模糊合并。
5. T-1508 仍开放。已观察到且成功进入持久待处理箱的失败片段可由 T-1509 本地恢复；监听未收到的事件、缓存前崩溃、存储完全不可用期间的片段不能承诺补回。跨窗口共享会话身份是另一问题，不阻塞本计划。

## 4. UI 方向与信息架构

保留「今日—回顾—事项—管理/设置」现有分工，不为新功能增加一级页签。桌面 tab、dock、快捷对话框和移动入口共享业务语义，允许不同信息密度。

| 位置 | 首屏职责 | 深层功能放置 | 本批避免的拥挤 |
| --- | --- | --- | --- |
| 今日 | 当前要做的事、进度、记录 | 已有展开区/项目编辑 | 不常驻展示整套统计与待处理技术明细 |
| 回顾·记录 | 找到、核对、补充事实 | 筛选折叠区、单条详情、批量补记预览 | 不给每行堆满来源身份和规则字段 |
| 回顾·分析 | 看懂变化 | 指标解释面板、项目比较、周复盘流程 | 图表必须带文字/表格替代，不只增加图数 |
| 编辑器 | 设置项目与规则 | 未来排期、修改前后对照 | 复用现有卡片预览；高级排期按需展开 |
| 设置·外部来源 | 是否配置、是否运行、发生了什么、问题是什么 | 待处理箱、粘贴样例试算 | 不用一个“已同步”徽标掩盖多种状态 |
| 管理/模板/导入 | 安全复用与迁移 | 分享预览、冲突选择、修改清单 | 不重复建立独立模板商城或数据中心 |

视觉延续淡紫蓝画布、白卡、紫罗兰主色及独立双主题色板；深色不简单反色。普通信息用中性色；“未做/无数据/跳过/错误”须有文字或符号区别，不仅靠红绿。保持低压力文案，不用欠账、惩罚或羞辱性提醒。

交互统一为预览→明确操作→处理中→成功/失败→可恢复；无变更时不制造保存动作，失败保留输入。弹层可用 Escape 关闭并恢复焦点，破坏性行为和未保存离开使用既有保护模式。窄屏面板单列，长名称不遮挡动作。

这是基于实现结构的 UI 判断，不是本轮截图测量结果。历史质量记录显示 CSS 已超过 620KB 软预算，后续优先复用组件与样式；新增 UI 必须重新测量，不把历史尺寸/对比度结果外推到新页面。

## 5. 正式立项：15 项无需真实宿主验收的开发任务

以下均为未来任务，本轮只立项。每项交付包含用户入口、真实逻辑和本地验收，不能以只写纯函数或模拟截图代替功能接线。涉及存储使用现有持久化接口的可注入替身；文档输出复用既有渠道，本批不新增宿主 API。

### 批次 A：可靠事实与可处理问题（P0）

**T-1509 外部失败记录待处理箱**
- 增量：从“失败片段可能丢失”升级为可见的待处理、重试和丢弃；入口为设置外部来源的问题区。
- 实现：外部入口区分成功/重复/墓碑/配置拒绝/可重试存储失败；有界持久箱保存最少字段，容量和保留期显式配置常量并在实现决策中记录；满箱不能静默覆盖。启动恢复及用户重试均重查项目、修订、单位、映射、启用状态与墓碑；禁止自动转投新目标。
- 验收：注入“保存失败→重载→成功”；重复重试只入账一次；撤销/改绑/停用后不错误复活；满箱和缓存保存本身失败可见。不宣称恢复从未收到的会话。
- 依赖：拆分承接 T-1508 本地恢复部分；不等待上游共享会话 ID。

**T-1510 单条记录事实详情**
- 增量：已有徽标/原因升级为可展开详情，显示记录日期/时间、实际数值单位、来源计量方式、可取得的生效修订与归属信息。
- UI：回顾记录行一个“详情”，敏感外部身份默认不展开；缺少旧修订或来源证据如实标未知，不以当前配置反推历史。
- 验收：20/15 分钟两条、官方日汇总、手动/导入/未知来源、历史规则缺失、跨日事件夹具；预览零写入，键盘打开/返回不丢位置。
- 依赖：既有 record-trust/事件模型；详情独立可做。

**T-1511 批量补记实际数量与提交预览**
- 增量：在 T-1497 批量补卡上逐项填实际值/单位，列出可提交、已存在、排期不适用和不支持原因，确认前显示总条数。
- 边界：二值保持 1；数值不默认为已经实际完成目标值；限额/戒除不批量制造成功事实；问卷项目明确排除或跳转既有单条流程；配额按既有内核处理。
- 验收：混合类型、零/负/非法值、已有事件、预览后项目改动、重复点击、保存失败全量回滚、单条撤销。先预览后提交仍重新校验。
- 依赖：既有批量事务，不新增宿主查询。

**T-1512 来源渠道细筛与计量方式筛选**
- 增量：在现有 source 枚举筛选基础上，区分同属 api 的健康/笔记推导等登记渠道，并支持会话/日汇总/其他计量方式。
- UI：回顾记录筛选，显示命中数；未知身份归“其他/未知”，不用自由字符串猜插件名。
- 验收：同 source 不同登记前缀、旧身份、未知身份、组合筛选、清空、分页与导出范围一致；查询不修改事件。
- 依赖：复用来源登记与 T-1510 计量描述，不变更公开 source 枚举。

### 批次 B：规划透明与复盘可解释（P1）

**T-1513 单项目未来 30 天排期预演**
- 增量：编辑器现有卡片预览增加逐日安排和应做原因；只读使用当前草稿。
- 边界：配额展示周期窗口及剩余次数，不编造固定执行日；休息日与未完成分开，非法草稿显示错误而非回落默认排期。
- 验收：工作日/指定星期/间隔/配额、闰日/月末、起始日期、固定时区夹具；改草稿即时重算且不落库。
- 依赖：现有日期及排期内核。

**T-1514 规则修改前后影响对照**
- 增量：保存既有项目的规则修改前，展示目标、单位、频率变化及未来 30 天安排差异，说明历史事实保留规则。
- 边界：本期使用已有修订生效机制，不新加任意回溯/未来生效日期，也不把旧值自动换算到新单位。
- 验收：只改名称不触发规则警告；目标/单位/频率变更正确；历史快照不变；取消零写入、保存失败保留草稿。
- 依赖：T-1513。

**T-1515 全项目未来一周负荷预览**
- 增量：今日的按需入口展示未来七天每天计划项目与数量，并允许跳回项目编辑。
- 边界：次数、分钟、数量分开；只把明确配置为时长的目标计入分钟；配额列作灵活周期任务，不重复摊派到每天。
- 验收：跨周、停用/归档、休息、配额、混合单位；固定数据与日期确定性输出；零事件写入，窄屏无横向动作遮挡。
- 依赖：T-1513 共用投影，非智能自动排程。

**T-1516 统计分母与状态贡献明细**
- 增量：现有指标旁增加“如何计算”，展开参与日期、完成/应做/跳过/休息/配额口径，跳转对应记录。
- 边界：复用原指标计算，不复制第二套公式；分母为零显示无适用数据，限额/配额独立解释。
- 验收：明细汇总必须与指标一致；日期范围、历史修订、暂停/SKIP、配额夹具；钻取前后保持筛选与返回位置。
- 依赖：T-1510 可用于详情，不阻塞纯投影开发。

**T-1517 选定项目横向趋势比较**
- 增量：已有当前期/上一期比较之外，允许选择 2～4 个项目看同一期间的趋势。
- 边界：兼容单位才比较原始数值；不同单位分图，完成率仅在适用口径下比较；数据不足明确提示，不排名施压。
- 验收：分钟/次数/数量混选、单位修订、空数据、稀疏日期、归档项目；表格与图一致，键盘选择与移除可用。
- 依赖：既有比较与图表组件、T-1516 的口径说明。

**T-1518 周复盘向导与可恢复草稿**
- 增量：基于已有回顾助手/报告，增加“核对本周事实→记录阻力→选择下周一项调整”的可继续流程。
- 边界：无模型也可完整使用；建议只是草案；确认调整跳到既有编辑器，不自动写目标；导出 Markdown 可独立完成，不依赖写入宿主文档。
- 验收：空周、跨年周、重载恢复、切换周不串草稿、取消/导出、保留用户文本；引用统计可定位、事实与用户解释分开。
- 依赖：T-1516，复用问卷草稿与报告基础。

### 批次 C：配置复用与安全迁移（P1）

**T-1519 个人模板脱敏分享**
- 增量：现有模板管理增加选中模板→分享内容预览→导出纯配置包。
- 边界：仅白名单项目类型、目标、单位、排期及展示配置；排除事件、项目/文档/外部绑定 ID、凭据、附件和用户备注，名称等用户文本明确预览；不建模板云市场。
- 验收：敏感字段夹具确认不出包；导出确定性、版本声明、空选择/超量拦截；不修改原模板。
- 依赖：现有个人模板模型。

**T-1520 模板包导入逐项差异与冲突处理**
- 增量：承接分享包，在既有组合包预览之外支持外来个人模板的字段对照、重名跳过/另存/明确替换。
- 边界：替换只影响模板，不影响已创建项目；未知版本/字段按契约提示或拒绝，不执行脚本、不自动接联动。
- 验收：非法/超大包、重名、部分选择、重复导入、旧版本；取消零写入，失败回滚，替换可恢复。
- 依赖：T-1519 格式。

**T-1521 设置保存前变更清单与分节恢复**
- 增量：在已有搜索/草稿基础上，集中列出本次改了哪些设置，允许撤回单项或恢复一个分节。
- 边界：显示脱敏前后值；停用/重绑影响明确；恢复设置不删除记录、不清空文档内容；继续走现有保存通道。
- 验收：无改动、多个分节、敏感值遮罩、恢复取消、保存失败、重载、键盘操作；不得把“草稿已改”当“已生效”。
- 依赖：现有偏好归一化与设置草稿。
