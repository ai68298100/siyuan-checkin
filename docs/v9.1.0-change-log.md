# 9.1.0 变更记录

日期：2026-09-11

本次为"打磨批次"：完成 P1 全部体验项 + 无障碍审计守门 + 两处交互修复。

## 新功能

- **回顾页区块折叠（T-011）**：趋势 / 打卡日志 / 近期事项 / 成就 四个区块可独立折叠展开，默认全部折叠，突出日历、明细与项目汇总；展开状态存入视图偏好，跨会话记忆。
- **快捷键帮助卡片（T-013）**：设置页新增"快捷键"分组，列出 Alt+Shift+C（呼出）、Alt+1-9（快速打卡）、Alt+↑/↓（手动排序），键帽样式排版。
- **首次使用引导（T-014）**：今日页空状态升级为三步引导（选模板 → 命名 → 打卡），并提供"新建第一个打卡项"入口。

## 体验与无障碍

- **图标弹层焦点返回（T-012）**：关闭图标弹层后焦点回到"更换图标"按钮；选择图标时弹层摘要中的当前图标实时刷新。
- **无障碍审计守门（T-021）**：新增 `tests/accessibility-audit.test.cjs`，双主题走查全部页面，断言 ① 交互元素均有可访问名称 ② 无正向 tabindex ③ 文本对比度 ≥4.5:1。
- **对比度达标（WCAG AA）**：引入文本专用 token 体系（`-text` / `-fill` / `-contrast`），次要文字加深（#85869A → #63657A），实心按钮/导航盘改用更深的填充色；深色模式实心填充改配深色文字。四套强调色板同步补齐文本变体。共修复 233 处对比度实例。
- **补齐 aria-label**：历法 / 每月星期 / 频率 三个未包裹在 label 内的下拉框。

## 修复

- **打卡日志行挤压**：照片缩略图引入的四列网格误用于全部日志行，导致无照片行项目名被挤成竖排；现已仅对带缩略图的行启用四列。
- **中宽容器导航重叠**：720–999px 容器下左侧粘性导航与滚动内容重叠；现从中宽起启用双列栅格（导航列 + 内容列），桌面大屏保持原间距。
