# 9.2.0 变更记录

日期：2026-09-12

主题：i18n 基础设施全量落地——七大界面用户可见文案迁移至字典。

## i18n（T-020 主体完成）

- 迁移范围：今日页（工具栏/四种空态/三步引导/日期提醒横幅）、标签体系（类型/重要性/时间段/排序/频率/来源）、回顾页与习惯复盘、事项页（表单/21 个模板/重复描述引擎/星期名）、打卡项编辑器（模板区/图标弹层/类型选项/预览/高级安排/操作）、设置页（七个分组全部）、归档页。
- 引擎与数据：事项模板新增 `nameKey` 渲染时翻译（套用模板时以当前语言写入名称）；`describeRecurrence` 全部输出改查字典；星期名、月历表头、月/年标签改字典键。
- 日期 locale 化：新增 `getPluginLocale()`；日历、历史日期、时间戳、七日概览等 Intl 格式化全部随插件语言。
- 中文字典新增约 330 键，英文全部补齐；默认 zh-CN 界面逐字不变。
- 新增键值模式：常量表存键 + `t()` 运行时取词；`getPluginLocale()` 供 Intl 使用。

## 修复

- 修复时段标签双重 `t()` 包裹（英文模式下会漏译）。

## 遗留（T-020 收尾项）

- 运行时消息串（showMessage/confirm，约 74 处）尚未迁移。
- catalog.ts 打卡模板名称/备注、图标组显示名与关键词仍为中文数据（关键词兼作搜索数据）。

## 验证

- 全部测试链（check/test/test:ui/test:mobile/test:ecosystem）+ 宽度走查 + 双主题视觉走查 + 无障碍审计 + 性能基准通过。
