# v18.19.0 变更记录

批次：多桶备份版本化、写入幂等事实对账与全表面视觉系统收口（2026-10-20 交付）。

## 数据可靠性与多桶备份版本化（T-1787 / T-1862，D-515 / D-517）
- **统一预检与格式识别**：落地 `preflightUnifiedBackup`，自动识别旧版单主档 JSON 与新版版本化多桶 BackupEnvelope（v1）。
- **旧版单主档兼容消歧**：旧版单主档如实披露丢失的独立配置桶，提示不覆盖现有独立配置，消除“主档恢复等于全量迁移”认知误区。
- **逐桶规划与敏感桶遮罩**：依 D-514 规则自动生成覆盖/合并/跳过规划预览，敏感桶默认遮罩并跳过。
- **多桶原子全量回滚**：多桶恢复在锁内执行，预先快照所有桶，主档严格走 `enqueueMutation`；任何辅助桶写入异常立即触发全量原子回滚。
- **多桶完整备份导出**：在设置页落地 `downloadBackupEnvelopeFor` 与 `createBackupEnvelopeFromBuckets`，支持导出包含全部辅助桶与脱敏审计日志的完整版本化备份。

## 存储基建与辅助存储桶治理（T-1860 / T-1861，D-514）
- **辅助存储桶三分类架构**：追加型（AI历史/审计）、覆盖型（偏好/草稿）、增删改型（模板/图标/问卷），杜绝删除复活缺陷。
- **单桶写入事务回滚**：`persistUserTemplates`、`persistCustomIconLibrary` 与 `saveJournalData` 在磁盘写入失败时严格回滚内存快照，全仓 TypeScript `any` 保持零残留。

## 事实层一致性与写入幂等对账（T-1786，D-518）
- **二值完成与戒除破戒口径收敛**：`recordExternalEvent` 与内部记录器同口径，二值普通项完成阻断，二值戒除项（`atMost`）首破可写、多次破戒拦截。
- **跨入口写入幂等**：无论通过 API 单条 `recordEvent`、Agent `checkin-record-item` 携带 `requestId`（映射为 `agent:<requestId>`）还是 UI 入口，重复提交同一 `externalRef` 时严格返回既有事实，杜绝重复增账。
- **回执对账与撤销对象统一**：幂等回显既有事件以及外部 API 写入成功时，统一调用 `setRecentRecord` 刷新当前回执，撤销对象跟实际入账事件 100% 对齐。

## 稳定性与顶栏重绘防御（D-522）
- **根除纵向滚动外溢**：`bindNavOverflowHintFor` 废除 `scrollIntoView`，改用纯内部 `scroller.scrollLeft` 自包含横向计算，杜绝顶栏被推到视口上方视野外。
- **后台重绘活动态挂起**：`renderBackgroundUpdateFor` 检测活动输入控件，用户正在输入时挂起至 `focusout` 再刷新，杜绝重绘打断与突发重刷。
- **中窄屏顶栏紧凑保留**：放宽 `< 720px` 规则，440px~719px 保持紧凑模式显示品牌头像与导航图标，避免分屏 Tab 或小弹窗导航全灭。
- **全表面事件闭环与尺寸固化**：`renderInto` 统一收尾调用 `bindDialogClose`、`bindMobileNav` 与 `normalizeUiIcons`；固化顶栏 SVG 固有尺寸为 18px。

## UI/UX 视觉系统收口（T-1817~T-1824，D-516 / D-519 / D-520 / D-521）
- **五级动作按钮语义体系（T-1817）**：Primary / Secondary / Quiet / Destructive / Icon 五级语义类名，统一定制 `:focus-visible` 焦点环，高对比度模式自动注入实体轮廓。
- **表单输入与文本域 Token 收敛（T-1818）**：新增 `field-height-sm`、`field-textarea-min-height`、`field-textarea-min-height-lg` token，统一表单校验与禁用状态。
- **长表单分节与折叠系统（T-1821）**：`[data-editor-section]` 虚线视觉分隔与加粗标题，收敛高级设置抽屉微动效。
- **导航溢出指引与防折行（T-1819）**：新增横向溢出渐变蒙层，启用 `scroll-snap-type: x proximity` 与 `flex: 0 0 auto` 防折行，选中项自动居中可见。
- **宿主容器三档密度（T-1824）**：dock 紧凑档（0.9 / 30px）、tab/quick 标准档（1.0 / 34px）与移动端触控优先档（1.1 / 44px）；移动端输入框聚焦自动注入 96px `scroll-margin-bottom` 虚拟键盘保护。
