# 17.0.0 变更记录

17.0.0 是习惯体系融合版本：引入跳过态（存储 v2→3）、习惯强度分数、负向目标、笔记回写、声明式渲染块与对外契约文档，整合竞品调研产出的六大批次二十三项任务（T-1216~T-1241）。

## 跳过态（D-216/T-1220~T-1223）

- 事件新增可选 `kind: "checkin" | "skip"`；缺省不物化，历史数据无损升级（存储版本 2→3，读入时自动迁移）。
- 统计口径在计算层落地：进度与规则计算排除跳过事件；连击中跳过日桥接（不算完成也不断链）；完成率分母剔除跳过日；配额跳过不吃量；年度热力图与回顾月历的仅跳过日渲染中性格。
- 交互：Today 卡上下文菜单「跳过今日 / 取消跳过」（可填原因、可撤销）；批量模式支持跳过（单事务）。
- 宽容提醒：已完成项退出待办提醒视图；跳过日不再提醒；超期 snooze 物理清理；连续跳过触发「下调频率」教练建议；洞察页显示「重新开始」说明。

## 习惯强度（T-1224~T-1227）

- 新增 `src/features/habit-score.ts`：半衰期模型（m = 0.5^(√freq/13)）逐日滚动 0~100 分；跳过日与非计划日冻结；数值型按当日目标归一。
- 弹性配额自动补全（D-217 AUTO）：当期达成后的剩余日推导为自动完成日，只存在于计算层；连击遍历合并真实完成与 AUTO。
- 回顾页新增「习惯强度」折叠卡（近 30 天逐项目折线）；洞察页新增强度分数、两周变化与成熟度百分比（sigmoid，66 天参考线）。
- 智能体 API 新增 `getStrengthSummary`（只读，窗口 7~366 天，最多 200 个活跃项目）。

## 负向目标（D-219/T-1239）

- `direction: "atMost"` 戒除类目标（仅每日排期）：不记录即成功，记录即破戒；连击 = 连续无破戒日（跳过桥接、破戒断链、止于创建日）。
- Today 卡按钮「记破戒 / 撤销破戒」语义切换，无破戒日显示「今日已避开」；新增戒烟、戒奶茶、限制咖啡、不熬夜刷手机、戒糖饮料五个戒除模板。

## 笔记回写（D-218/T-1231~T-1233）

- 项目级 opt-in 笔记锚点：打卡状态回写为绑定块的自定义属性 `custom-lv-checkin`；备注与跳过原因可追加为锚点文档子块（带日期戳）。
- 回写为尽力而为旁路：失败不阻断打卡主路径；块不可达直接挂起并审计；写失败有界重试（2 次/1.5s）；解绑与卸载逐块清除本插件属性键。
- 仅使用已验证内核端点（setBlockAttrs / getBlockInfo / appendBlock），白名单由测试锁定。

## 声明式渲染块（T-1234~T-1236）

- 文档内 ` ```checkin` 代码块写 JSON 配置即可渲染月历 / 热力 / 汇总视图；支持项目、分组、全部三种作用域与色阶配置。
- 只读预览紧邻源码块；点击日期跳回顾页当日详情；配置错误显示固定可读文案，不回显用户原文；打卡事件驱动自动刷新。
- ~9k 事件三视图渲染 73ms（门禁 2000ms）。

## 复盘与报告（T-1216~T-1219）

- 回顾页「较上一周期」：当前/上期/带符号差值与逐项目差值条（共享 asOf 推导基线）。
- 周报/月报五区块可配置（记录/完成概览/项目明细/基线对比/亮点说明），导出 Markdown；数据不足时输出明确说明。
- Loop Habit Tracker CSV 迁入迁出（迁移降级边界明确）；宽容提醒一期（已完成项退出待办视图、超期 snooze 清理）。

## 契约与文档（T-1237~T-1238）

- 新增 `docs/identity-and-merge.md`（事件四层身份、externalRef 幂等约定、合并规则）与 `docs/export-formats.md`（四导出三导入总览），文档引用与实现由测试交叉核对。

## 生态与质量

- 新增测试：review-compare-view、report-sections、loop-csv、reminder-tolerance、skip-model、skip-semantics、skip-interaction、skip-tolerance、habit-score、auto-days、auto-streak、strength-view、note-anchor、checkin-block、export-identity-docs、at-most、habit-quality，全部纳入统一质量门禁。
- auto-archive 与 checkin-block 计时门禁按 T-1172 哲学对齐（本机实测波动 301-1320ms，保留灾难性退化捕获）；CSS 预算维持 420KB 告警 / 450KB 硬线。
