# 2.0 迁移说明（开发线）

当前 2.0 开发会继续复用现有存储版本 `2`，不会改变打卡项目、事件、删除标记和日期事项的数据语义。

## 新增视图偏好

以下字段保存在 `checkin-view-preferences`，旧数据缺失时自动使用默认值：

- `density`: `standard`
- `appearance`: `system`
- `reducedMotion`: `false`

同时保留原有分组、排序、已完成区域折叠和复盘项目选择。恢复显示偏好只会重置这些界面字段，不会删除业务数据。

## 兼容策略

- 旧版本客户端读取新偏好时忽略未知字段，继续使用原有默认视图。
- 新版本读取旧偏好时补齐缺失字段，不要求用户重新配置。
- API 继续使用协议 `siyuan-checkin`、版本 `4`；第三方应通过能力发现进行渐进兼容。
- 真实升级、回滚和跨版本验证按计划延后到 2.0 完成后统一实测。
