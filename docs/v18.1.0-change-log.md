# 18.1.0 变更记录

本次小版本把外部数据来源正式接入打卡体系（来源统筹框架 + 思阅适配器 + 健康收件箱），新增 Task Horizon 日历可见性与每日摘要驻留，增强连续统计（容错连续）与热力图色阶，并完成锚点体验收口。主存储 v3、契约 storeVersion 2、最低思源版本 3.8.4 不变；公开 API v5 新增 `calendar.read` 能力（共 20 项）。

## 新增功能

- **每日摘要驻留（T-1353，opt-in 默认关）**：把当天汇总以单行纯文本追加到用户绑定的思源文档，外部工具经内核公开读接口即可读取；字段白名单（日期/完成比/记录数/来源计数）、只追加、标记行幂等、审计通道独立。外部工具真机读取验证随 T-1344。
- **来源统筹框架（T-1383，D-258）**：统一「登记→接入→结算→身份→治理」五段管道与四类接入渠道；来源描述符、治理配置、结算层均为纯函数冻结契约（`src/features/source-framework.ts`），新增来源不改动结算与身份层。
- **思阅阅读联动（T-1384，opt-in 默认关，D-260）**：消费思阅公开生命周期事件（reader:open/focus/blur/close），有焦点区间墙上时间计时、跨日预切分、分钟向下取整；当日累计达阈值后每日一次幂等写入（`sireader:<itemId>:<localDate>`）；重载丢弃在飞区间；设置页开关/项目/阈值三行。
- **健康数据收件箱（T-1403，opt-in 默认关，D-262）**：iOS 快捷指令经内核 `appendBlock` 向绑定文档追加 `health:<指标>:<日期> 数值` 行，插件每 5 分钟轮询摄取、幂等入库；指标→项目映射（步数/体重）；模板与接入指南见 docs/health-shortcuts-integration.md。
- **Task Horizon 日历可见性（T-1390/T-1391/T-1393，D-259）**：项目级「在任务管理器日历中显示」开关（缺省显示，仅物化 false）；公开 API 新增 `calendar.read` 与 `getCalendarProjection`——有界项目×日期只读投影，服务端过滤隐藏/归档项目，状态口径（排期/quota/SKIP/at-most/localDate）由小驴统一计算；隐藏不复用归档、不影响任务完成回写。
- **容错连续（maxGap，T-1409）**：项目级「漏打容错（天）」（1~30）——排期日漏打不超过 N 天不断签、缺口不计入连续；与 SKIP 正交；at-most/quota 不叠加；洞察、渲染块、API getStreaks、今日徽章同口径。
- **热力图色阶自适应（T-1410）**：年度热力图四级色阶按个人「有记录日」条数分布的百分位（25/50/75）自适应，低频用户同样呈现完整层次；阈值随 YearHeatmap 暴露。

## 改进

- 锚点跳转打开前重新解析归属文档——锚点块被移动后自动跟随新根文档；不可达时给出可读提示并回落项目详情（v18.1.x，T-1404/T-1405）。
- 摘要驻留来源计数覆盖思阅来源；历史与洞察来源标签新增「思阅阅读」。

## 公开 API（v5）

- 新增能力 `calendar.read`（since 5）与 `getCalendarProjection(range)`：≤366 天 / ≤200 项目、truncated 显式、无备注/附件/externalRef；契约 manifest 与文档同步。外部 API 输入不可伪造内部保留来源 `sireader`（强制回落 api）。
- externalRef 前缀注册表新增 `sireader:<itemId>:<localDate>` 与 `health:<metric>:<localDate>`。

## 工程与质量

- 发布资产清单（dist 逐文件 + package.zip 的 SHA-256）与回滚演练（预发布→坏版本→漂移检测→回滚→完整性复核）脚本化，并入 `check:release` 证据链（T-1398）。
- 仓库清理：43 个历史本地分支收敛为 main，27 个未合并分支打 `archive/codex-*` 归档 tag（内容可恢复），遗留 worktree 移除（T-1396）。
- 生态调研循环（T-1400/D-256）启动：第一轮 13 候选 → 采纳 3（maxGap/色阶/动效待收尾）、延后 4、不做 3、佐证 3，记录于 benchmark 文档 §十。
- 动效克制原则确立（D-263）：动效仅在收尾阶段少量引入，性能与可用性硬前提，尊重 reducedMotion。

- 主存储 v3、公开 API v5 契约 storeVersion 2、minAppVersion 3.8.4；本版本不包含数据迁移脚本，从 18.0.x 可直接升级。
- 动效（完成庆祝反馈）按 D-263 留待收尾批次 T-1411；Task Horizon 消费端图层与真实宿主联调（T-1392/T-1394/T-1388）继续开放。
