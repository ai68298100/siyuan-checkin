# v0.7 大项目路线

## 项目一：核心规则与周期目标（已完成）

- 设计并迁移周期配额 schema
- 区分按次数、按数值、按天数的配额统计
- 明确暂停、归档、创建前和周期边界语义
- 在不改变旧频率行为的前提下接入今日页
- 为迁移失败、跨时区和历史数据补充回归测试

## 项目二：复盘与分析（已完成）

- 支持日、周、月和自定义日期范围
- 增加目标、完成率、连续记录和趋势对比
- 展示单条记录明细与备注
- 统一 JSON/CSV 导出上下文
- 预留 AI 总结适配器和权限边界

## 项目三：快速交互与移动端（已完成）

- 快速弹窗中的连续记录和最近项目
- 键盘快捷记录、撤销和焦点管理
- 移动端软键盘、旋转、安全区和触控目标回归
- 侧边栏、弹窗、页签共享响应式规则
- 低网络或多窗口状态下的操作反馈

## 项目四：集成与发布质量（已完成）

- 稳定插件 API、事件和第三方适配器接口
- 建立思源 3.8.3+ 前端兼容矩阵
- 构建、安装包、版本号和 Release 资产一致性检查
- 市场元数据和图标/预览资源校验
- 发布候选分支和回滚说明（见 `docs/release-rollback.md`）

每个大项目先在独立分支拆分子任务，完成纯逻辑、迁移、UI 和回归验证后再合并。未完成验证的子任务不进入 Release。
