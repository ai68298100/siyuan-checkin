# 6.0 变更记录

## 概览

6.0 主题为「效率与生态」：让每日打卡更快（拖拽排序、批量操作、内置专注计时），把日期事项与打卡清单打通，并提供完整的第三方接入手册与示例。数据模型仅新增可选字段 `linkedOccasionId`（完全向后兼容）。

## 新增

- **今日清单拖拽排序**：排序方式为"自定义顺序"时，行尾出现排序把手——桌面悬停浮现、移动端常显；指针拖拽实时换位，松手按新顺序持久化；支持 `Alt+↑/↓` 键盘重排；已完成项不可拖动。
- **批量操作**：今日页"多选"模式——勾选待办项后可一键 全部完成（数值项自动补足剩余）/ 批量归档 / 全选待办。
- **内置专注计时器**：按时长项目的"专注"按钮不再依赖外部插件——打开深色倒计时面板（15/25/45/60 分钟预设、暂停/继续、进度条），自然结束或手动"完成"都会自动落账一条带"专注 N 分钟"备注的记录；外部番茄钟插件注册的适配器始终优先于内置面板。
- **日期事项 → 打卡项联动**：日期事项行新增"转打卡"——生成一个仅在事项发生日出现在今日页的一次性打卡项，完成后自动把事项标记为已处理。
- **生态接入手册与示例**：`docs/ecosystem-integration.md` 新增"10 分钟接入"快速开始；新增 `examples/tomato-bridge` 可运行示例（等待就绪 → 能力协商 → 去重写入 → 事件订阅）。

## 变更

- `CheckinItem` 新增可选字段 `linkedOccasionId`（≤64 字符，自动规范化）；读取旧数据自动兼容。
- 专注按钮显示条件从"存在外部适配器"放宽为"按时长项目"。
