# v18.17.2 变更记录

批次：全插件 UI 复核后的提醒布局、入口一致性与短屏体验修复（2026-10-10），可从 v18.17.1 直接升级。

## 页面与交互

- “未来七天负荷”调整到 Today 主任务区域下方，避免在宽屏右侧形成空洞并分散打卡操作注意力。
- 提醒通知在可见 Dock、Tab 和 Dialog 中进入页面文流，首次挂载与重绘保持相同位置，不再遮挡 Today、编辑器预览或事项内容。
- More 入口、设置健康卡、快速弹窗记录入口和返回上下文保持统一；事项长文本、短屏编辑器和移动底栏经过重新走查。

## 响应式与反馈

- 短高 surface 的提醒通知限制为 64px，保留可操作按钮高度并隐藏非必要提示，避免挤压编辑器保存区。
- 删除重复短高样式，补充页面滚动区的 flex 约束，减少通知挂载时的布局跳动和内容覆盖。
- 宽度走查补充 More、短高编辑器、事项长文本和提醒定位断言，README 结构与内测说明加入自动契约检查。
