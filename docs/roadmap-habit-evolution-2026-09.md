# 习惯体系融合路线（v16.1 → v19，2026-09-18 定稿）

> 输入：`docs/benchmark-habit-apps-2026-09.md` 竞品调研（uhabits / mhabit / Habitica 源码 + 11 款商业应用 + Obsidian/Logseq/Notion 生态）。
> 本文档在 `docs/development-roadmap-2026.md` 的 v16 复盘 → v17 生态联动 → v18 开放生态主线上，叠加「习惯内核」与「笔记联动」两条吸收轨道，形成合并节奏。与原路线冲突处，以本文档为准；现场验收类事项（T-023/T-033/T-129/T-1173、B-007、T-1165）继续独立跟踪，不阻塞本地开发。

## 一、总原则

1. **不推翻，只叠加**：现有五记录类型（binary/count/duration/quantity/custom）、六种排期（daily/weekly/workdays/custom/interval/quota）、事件模型（source/note/attachment/externalRef）、复盘管道（SummaryContext → review-comparison）全部保留；吸收的能力以**新增派生层 + 少量数据模型扩展**落地。
2. **事件=原始记录，推导=计算层**（对齐 uhabits 原始/计算 Entry 分离）：跳过、自动补全、强度分数都不改写历史事件；统计口径变化只发生在计算层，保证指标可追溯（延续 D-215 原则）。
3. **计分单一代码路径**（Habitica common/script 模式）：新的分数/streak/补全函数放独立纯函数模块，UI、智能体 API、批量操作共用同一入口，禁止多处实现。
4. **每个吸收项都过既有门槛**：`pnpm run test:quality` 全绿、CSS 预算 480KB 告警 / 520KB 硬线（2026-09-20 D-239 放宽，护栏仅防灾难性膨胀）、双主题无障碍 4.5:1、1k/10k/100k 性能基线不回退。
5. **不臆造思源 API**：笔记联动只用已验证的内核接口（getBlockByID/setBlockAttrs/appendBlock/updateBlock 等），真机证据不足的能力先做诊断与降级。

## 三、版本详细计划

### v16.1 复盘呈现与数据入口（消费 v16.0 基线）

目标：把 T-1215 的 `buildReviewComparison()` 变成用户可见价值，并补齐迁移入口。纯增量，不动数据模型，可作为小版本先行发布。

- **T-1216 回顾页范围对比区块**
  - 验收：回顾页新增「较上一周期」区块，消费 `buildReviewComparison()` 渲染总事件/完成项目/计划项目的当前值-基线值-delta，逐项目标差值条按并集展示；空数据、单日范围、跨时区修改目标均有清晰表达；双主题对比度达标；1k/10k/100k 回顾性能基线不回退（tests/review-performance-baseline）。
  - 依赖：T-1215（已完成）。
- **T-1217 周报/月报模板与导出**
  - 验收：回顾页可选周/月报视图，摘要内容可配置（指标选择、对比基线开关、异常说明自动生成），可导出/复制为 Markdown；导出走既有安全导出路径；「最值得关注的一项」本地生成，数据不足时明确说明而非编造（延续原 v16 规划第 5 条）。
- **T-1218 Loop Habit Tracker CSV 导入与 CSV 导出**
  - 验收：导入器兼容 Loop `HabitsCSVExporter` 格式（习惯元数据 + 逐日值），映射到现有五类型/六排期（不可映射项有明确降级说明）；导入记录 `source:"import"`、幂等可重放、导入前自动恢复点；导出生成同构 CSV 供迁出。续作参考 mhabit `loop_import.dart` 的映射表。
- **T-1219 宽容提醒一期**
  - 验收：当日已录入（手动/番茄/API）后取消该日剩余提醒，不弹「已打卡仍提醒」；snooze 状态持久化、过期 snooze 丢弃；任何数据写命令完成后重排提醒计划，打卡/改色类命令除外（对齐 uhabits ReminderScheduler 的命令监听模式）。
  - 依赖：reminders.ts 现有调度。

### v16.2 跳过态（数据模型唯一一次扩展）

目标：引入 SKIP 一等记录态。这是吸收清单里价值最高、也是唯一动 store 结构的项，独立成版本以便迁移和回滚演练。

- **T-1220 跳过事件模型与存储迁移**（需先记 DECISIONS）
  - 推荐方案：`CheckinEvent` 新增可选 `kind?: "checkin" | "skip"`（缺省 `"checkin"`，历史数据零迁移语义不变）；不采用「value=0 的完成」或复用 `source`。`CheckinStore.version` 2→3，迁移器做规范化校验（非法 kind 裁剪入审计），旧版本读到 v3 的降级策略与恢复点流程沿用 14.0 数据内核。
  - 验收：迁移幂等、损坏输入隔离、tombstone 兼容 skip 事件、API 合同（api-contract）与契约测试同步、恢复点可回滚到 v2 表达。
- **T-1221 跳过统计口径**
  - 验收：streak 计算中跳过日中性（不算成功也不断链）；完成率分母剔除跳过日；热力图/月历跳过日用中性色且双主题对比度 ≥4.5:1（uhabits #1736 透明渲染思路）；回顾日志显示跳过行及原因；quota 排期跳过不吃配额。
- **T-1222 跳过交互**
  - 验收：Today 卡片上下文菜单（右键/长按，复用 T-1170 通道）新增「跳过」；跳过时可写一句原因（落 `note`）；跳过可撤销（撤销不过墓碑语义）；批量模式支持跳过可见项。
- **T-1223 宽容提醒二期与反内疚建议**
  - 验收：跳过日不再提醒；连续 N 次跳过或强度连续下滑时，建议引擎输出「下调排期/改为弹性频率」建议（只建议，不自动改，走 agent-suggestions 现有工作流）；断链表述统一为「重新开始」而非「归零」（文案 + i18n 中英）。

### v16.3 习惯内核一期（强度与弹性）

目标：把 uhabits/mhabit 的算法精华落成纯函数内核，反哺回顾与建议。

- **T-1224 强度分数模块 `src/features/habit-score.ts`**
  - 验收：实现 `score = prev × 0.5^(√freq/13) + 当日表现 × (1 − 0.5^(√freq/13))` 的逐日滚动，输出 0~100；跳过日冻结衰减（既不加也不减）；数值型按 target 归一（至少型 `min(1, 累计/target)`）；非每日频率先做 uhabits 式倍增平滑；纯函数、不扫 store（消费预聚合，沿 D-215）；属性化测试覆盖闰年/跨时区/修订回放。
- **T-1225 弹性频率自动补全（AUTO 推导）**
  - 验收：quota 型（每周/月 x 次）在周期内达标后，剩余日推导为 AUTO 态（滑动窗口法）；AUTO 只存在于计算层（streak/分数/热力图），不落事件、不产生通知；与 SKIP 的优先级：跳过日保持跳过、不吃 AUTO 配额；决策与测试样例记 DECISIONS。
- **T-1226 streak 计算重构**
  - 验收：连续天数基于「manual + AUTO − skip」合并序列统一计算，替换各处口径不一致的局部实现（计分单一代码路径）；当前/最长连续与既有成就判定对齐；性能与现有 100k 基线持平。
- **T-1227 回顾页强度曲线与建议接入**
  - 验收：回顾页新增每项目强度趋势卡（0~100，可折叠/隐藏，进 reviewFold 偏好）；卡片说明文案解释衰减语义；建议引擎消费强度（连续下滑→降排期建议，与 T-1223 共用入口）；智能体摘要 API 输出强度字段（有界、只读）。

### v17.0 Task Horizon 联调收口（原 v17 P1，维持不变）

T-1228 日历「打卡」图层、T-1229 任务完成回写联调（含 T-1165）、T-1230 双方契约测试互置。bridge 侧 T-1167~T-1215 已就绪，只待对方排期；期间不新增 bridge 能力，避免契约漂移。本版本可与其他版本并行推进。

### v17.1 打卡回写笔记块（嵌入笔记差异化）

目标：把「打卡状态」变成思源可搜索、可反链的数据。独立 App 做不到，这是我们相对 Habitify/Streaks 的结构性优势。

- **T-1231 项目级笔记锚点与状态回写**
  - 验收：项目编辑器可绑定目标文档或块（opt-in，默认关）；打卡成功后把最新状态（日期/值/连续）回写为绑定块的 custom 属性，可选追加 memo 行；回写失败不阻断打卡主路径，进入有界重试与诊断（复用 Task Horizon bridge 的重试分类经验）；卸载插件不残留孤儿写入的清理路径明确。
- **T-1232 打卡即笔记（备注锚定）**
  - 验收：打卡备注/跳过原因可选择「同时追加到锚点日记」，追加内容带日期戳可检索；只写用户明确绑定的位置（隐私边界写入 README）；撤销打卡时同步移除或标记追加行（策略记 DECISIONS）。
- **T-1233 回写一致性守门**
  - 验收：绑定块被删除/移动后的悬挂检测与用户提示；重载后锚点恢复；多窗口同时打卡的回写合并策略（存储锁内复核，复用删除并发安全模式）；内核 API 全部走已验证接口，新增接口先在真实宿主小范围验证。

### v17.2 声明式渲染块

目标：打卡数据以声明式块进入笔记正文（Obsidian Tracker/Heatmap Calendar 已验证的模式，思源集市尚无同类）。

- **T-1234 `checkin` 渲染块**
  - 验收：支持作用域（笔记本/文档/标签/项目 id）、视图（month 网格/heatmap/summary）、阈值与色阶配置；月网格 intensity 线性映射到主题色阶、today 环、`data-date` 属性、跳过中性色；配置解析失败显示可读错误而非空白。
- **T-1235 点击跳转定位**
  - 验收：点击格子打开对应日期视图/日记并滚动定位高亮（借鉴 syh19/task-list 的打开+滚动+闪烁交互）；无对应文档时跳回顾页当日详情。
- **T-1236 渲染安全与性能**
  - 验收：渲染块只读、不渲染任意 HTML（Obsidian duoani 默认关富文本的教训）；1k/10k 事件渲染性能门禁；块随数据变化经刷新事件更新（复用生态刷新通道）。

### v18.0 开放生态（原 v18 + 吸收项扩展）

维持原计划：API v5 演进、externalRef 前缀注册、每日摘要写驻留文档（先过隐私评估）。吸收项并入：

- **T-1237 记录确定性身份文档化**：事件 id 与 externalRef 的派生/合并规则形成公开文档（mhabit 确定性 UUID 思路），为未来多端合并铺路；不迁移历史 id。
- **T-1238 导出格式 v2**：CSV/JSON/Markdown 表格三件套 + 第三方导入兼容说明（数据所有权作为本地优先卖点写进 README）。

### v19.0 习惯内核二期（进阶模型，视 v16.3 反馈启动）

- **T-1239 负向习惯（戒除类）**：item 增加方向标记（at-most 语义），完成判定反转（做了断链、忍住记成功），强度插值用 mhabit 底线-目标线性；模板库补戒烟/戒糖/不刷手机类负向模板。
- **T-1240 完成度分级与超额封顶**：完成度 ok/goodjob 分级，超额奖励封顶 1.5；数值型部分完成衰减减半；成就系统新增「超额日」「连续超量」徽章。
- **T-1241 里程碑与成长视觉（可选）**：7/30/100 天徽章 + sigmoid 成熟曲线（targetDays 饱和感）；轻量自平衡积分（收益递减 0.9747^v + 难度乘数 + streakBonus）作为默认关闭的可选开关——只取 Habitica 的数学，不做 RPG。

## 四、开发节奏与门槛

- **批次节奏**：沿用现行协议——每批 3~5 个相关任务、每批过 `pnpm run test:quality`、每阶段本地 commit 一次、不 push。
- **串行主线**：v16.1 → v16.2 → v16.3（同一主题域且存在数据/计算层依赖，跳过态必须先于强度分数落地）。
- **并行支线**：v17.0 依赖对方排期，可随时插入；v17.1/17.2 在 v16.3 合入后启动（回写的「连续天数」字段消费新 streak）；v18/v19 视用户反馈决定先后。
- **发布节奏**：v16.1/v16.2/v16.3 各自可独立发小版本（patch/minor 按 API 变化定）；发布前补 Chrome 双主题视觉、宽度走查、无障碍检查与 SHA-256 记录。
- **持续现场项**（不阻塞编码，保持跟踪）：T-023/T-033/T-129/T-1173 真机验收、B-007 Dock Tomato 联调、T-1165 回写联调准备、T-1166 外部摘要通道（P3 远期）。
- **调研续作**：`docs/benchmark-habit-apps-2026-09.md` 为活文档——思源集市其他打卡/习惯类插件第二梯队梳理、Obsidian 插件（Tracker 表达式引擎、Habit Tracker 21 的 gapStyle 细节）补充精读，在 v17.1/17.2 启动前各补一轮即可，不必提前。
