# 习惯打卡同类产品与开源生态深度调研报告（2026-10）

> 更新日期：2026-10-19
> 调研对象：开源标杆（Loop Habit Tracker、Table Habit、Habitica）、主流商业应用（TickTick 滴答清单习惯、Everyday、Streaks）、知识库生态插件（Obsidian Tracker、Obsidian Contribution Graph、Notion Habit Template）。
> 目标：对标前沿功能、算法与交互设计，为小驴打卡后续阶段（M1 串联闭环、M2 差异化复盘、M3 生态连接、M4 受控智能）提供高信度待办输入。

## 一、 开源与商业产品核心机制对比

| 产品 | 核心定位 | 算法/状态模型 | 独特优势 | 启发与小驴打卡差异化映射 |
| :--- | :--- | :--- | :--- | :--- |
| **Loop Habit Tracker**<br>*(Android/开源)* | 科学严谨的个人习惯追踪 | **五态模型**（YES_MANUAL / YES_AUTO / NO / SKIP / UNKNOWN）<br>**指数半衰期滑动平均**（0~100 强度分） | 算法透明、无广告、离线优先、标准 Loop CSV 交换格式 | 小驴已吸收其强度分半衰期公式；后续可强化“弹性周配额在日历上的自动补全展示”。坚持**不引入社交竞争**与惩罚。 |
| **Table Habit (mhabit)**<br>*(Flutter/开源)* | 习惯养成与成长曲线 | **Sigmoid 逻辑斯蒂饱和曲线**（y=1/(1+e^-0.4x)）<br>等级化完成分（zero/ok/goodjob，超额 1.5x 封顶） | 成长可视化强、确定性 UUID `f(habit, date)` 幂等去重 | 小驴打卡已建立 66 天成熟度参考线；后续可在 Review 洞察中提供“习惯稳固度饱和度图”，直观展现从不稳定到扎根的过程。 |
| **Habitica**<br>*(Web/Mobile/开源)* | RPG 游戏化习惯养成 | 任务价值双曲正切阻尼，红/黄/绿/蓝状态演变，掉血与金币奖惩 | 趣味性高、社交公会激励 | **明确不引入掉血/惩罚经济**（小驴坚持低压力与反内疚哲学）。但其任务价值阻尼（连续超额收益递减、避免过度疲劳）值得借鉴至教练建议中。 |
| **TickTick (滴答清单)**<br>*(商业产品)* | 任务管理 + 习惯工作台 | 打卡 + 心情表情（1~5分）/ 日志 / 照片，未达成原因（Unachieved）登记 | 习惯与日程强联动、打卡即日记、多端桌面小组件 | 小驴打卡作为思源原生插件，在**文档联动与复盘日记**上具备天然优势；可借鉴其“打卡附带 1~5 档心情/精力轻量标签”与“复盘时按心情交叉分析”。 |
| **Obsidian Tracker / Contribution Graph**<br>*(PKM 生态插件)* | 本地 Markdown 笔记习惯分析 | 基于 Dataview / Frontmatter YAML 解析，多色阶热力图与折线图 | 笔记双链结合紧密、自定义色彩配置丰富、渲染块嵌入 | 小驴打卡已有渲染块体系；后续可提供**热力图多种主题色板预设**（如翡翠绿、紫罗兰、秋日橙、赛博蓝）与自适应思源主题，增强文档嵌入美感。 |
| **Everyday / Streaks**<br>*(iOS/Mac/极简美学)* | 极简专注型习惯工具 | 纯视觉流流动色彩、弹性触感振动反馈、全键盘快捷操作 | 摩擦力极低、视觉与动效质感顶级 | 小驴打卡已具备全键盘流（j/k/e/空格）与振动反馈；后续可在 Today 视图加强**轻量弹性动效与卡片微交互层级**。 |

## 二、 核心待办建议与规划落地（待编入 TODO）

基于本次调研，提炼出 5 项高度契合小驴打卡“低压力行动记录与事实层”定位的候选任务：

1. **T-1830：打卡附带心情与精力轻量自评（对标 TickTick 习惯日志）**：
   - 在精确录入面板（Exact Entry）中提供可选的 1~5 档心情/状态图标（如 😴 🥱 😐 😊 🚀）；
   - 不增加打卡摩擦（完全可选、主按钮一键打卡不受影响）；
   - 数据保存在事件 metadata 中，供回顾页进行“完成度 × 心情精力分布”对账。

2. **T-1831：习惯稳固度 Sigmoid 饱和成长曲线（对标 Table Habit）**：
   - 现有的 66 天习惯成熟度刻度升级为阶段化稳固度状态（探索期 1~21天 → 爬坡期 22~45天 → 扎根期 46~66天+）；
   - 在洞察页提供平滑饱和曲线对比，直观展示习惯自发性与稳定节奏。

3. **T-1832：年度热力图多风格色板与自适应渲染（对标 Obsidian Contribution Graph）**：
   - 渲染块与回顾热力图支持可选调色板预设（Classic Green / Violet Glow / Warm Sunset / Monochrome）；
   - 支持夜间模式对比度自动校准与色弱模式纹理增强。

4. **T-1833：移动端与桌面端卡片交互质感升级（对标 Everyday / Streaks）**：
   - 优化今日卡片在移动端的触觉反馈与打卡微动效节奏；
   - 保证在 `prefers-reduced-motion` 开启时彻底清零，符合无障碍标准。

5. **T-1834：结构化周复盘行动卡证据深度回链（对标 M2 证据工作台）**：
   - 回顾页行动建议卡（Coaching Suggestions）增加“直接查看关联原始事件明细”的一键钻取通道；
   - 样本量不足时诚实给出提示，杜绝误导。
