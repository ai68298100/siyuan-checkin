# 习惯打卡同类产品与开源生态深度调研报告（2026-10）

> 更新日期：2026-10-19
> 调研对象：开源标杆（Loop Habit Tracker、Table Habit、Habitica）、主流商业应用（TickTick 滴答清单习惯、Everyday、Streaks）、知识库生态插件（Obsidian Tracker、Obsidian Contribution Graph、Notion Habit Template）。
> 目标：对标前沿功能、算法与交互设计，为小驴打卡后续阶段（M1 串联闭环、M2 差异化复盘、M3 生态连接、M4 受控智能）提供高信度待办输入。

## 一、 开源与商业产品核心机制对比

| 产品 | 核心定位 | 算法/状态模型 | 独特优势 | 启发与小驴打卡差异化映射 |
| :--- | :--- | :--- | :--- | :--- |
| **Loop Habit Tracker**<br>*(Android/开源)* | 科学严谨的个人习惯追踪 | **五态模型**（YES_MANUAL / YES_AUTO / NO / SKIP / UNKNOWN）<br>**指数半衰期滑动平均**（0~100 强度分） | 算法透明、无广告、离线优先、标准 Loop CSV 交换格式 | 小驴已吸收其强度分半衰期公式；后续可强化“弹性周配额在日历上的自动补全展示”。坚持**不引入社交竞争**与惩罚。 |
| **Table Habit (mhabit)**<br>*(Flutter/开源)* | 习惯养成与成长曲线 | **Sigmoid 逻辑斯蒂饱和曲线**（y=1/(1+e^-0.4x)）<br>等级化完成分（zero/ok/goodjob，超额 1.5x 封顶） | 成长可视化强、确定性 UUID `f(habit, date)` 幂等去重 | 小驴打卡已建立 66 天成熟度参考线；后续可在 Review 洞察中提供“习惯稳固度饱和度图”，直观展现从不稳定到扎根的过程。 |
| **Habitica**<br>*(Web/Mobile/开源)* | RPG 游戏化习惯养成 | 任务价值双曲正切阻尼，红/黄/绿/蓝状态演变，掉血与金币奖惩 | 趣味性高、社交公会激励 | **明确不引入掉血/惩罚经济**（小驴坚持低压力与反内疚哲学）。但其任务价值阻尼（连续超额收益递减、避免过度疲劳）值得借鉴至教练建议中。 |
| **TickTick (滴答清单)**<br>*(商业产品)* | 任务管理 + 习惯工作台 | 打卡 + 心情表情（1~5分）/ 日志 / 照片，未达成原因（Unachieved）登记 | 习惯与日程强联动、打卡即日记、多端桌面小组件 | 小驴打卡作为思源原生插件，在**文档联动与复盘日记**上具备天然优势；可借鉴其“打卡附带 1~5 档心情/精力轻量标签”与“复盘时按心情交叉分析”。 |
| **Obsidian Tracker / Contribution Graph**<br>*(PKM 生态插件)* | 本地 Markdown 笔记习惯分析 | 基于 Dataview / Frontmatter YAML 解析，多色阶热力图与折线图 | 笔记双链结合紧密、自定义色彩配置丰富、渲染块嵌入 | 小驴打卡已有渲染块体系；后续可提供**热力图多种主题色板预设**（如翡翠绿、紫罗兰、秋日橙、赛博蓝）与自适应思源主题，增强文档嵌入美感。 |
| **Everyday / Streaks**<br>*(iOS/Mac/极简美学)* | 极简专注型习惯工具 | 纯视觉流流动色彩、弹性触感振动反馈、全键盘快捷操作 | 摩擦力极低、视觉与动效质感顶级 | 小驴打卡已具备全键盘流（j/k/e/空格）与振动反馈；后续可在 Today 视图加强**轻量弹性动效与卡片微交互层级**。 |

## 二、 核心待办建议与规划落地（待编入 TODO）

基于本次调研与 2026-10 发版后的最新状态，提炼出 7 项高度契合小驴打卡“低压力行动记录与事实层”定位的演进任务（编排为 T-1872～T-1878）：

1. **T-1872：打卡主观心流与精力轻量自评及交叉分析（对标 TickTick / Atoms）**：
   - 精确录入面板中提供可选的 1~5 档心流/精力自评（⚡ 1:枯竭/2:疲劳/3:平和/4:充沛/5:心流，完全可选，主按钮一键打卡不受干扰）；
   - 事件结构与存储向前兼容（可选字段 `energy?: 1 | 2 | 3 | 4 | 5`），CSV/JSON 导出包含该事实；
   - 回顾页提供“完成度 × 精力分布”交叉对账，直观呈现精力高低与打卡达成率的真实相关性。

2. **T-1873：习惯稳固度 Sigmoid 饱和成长曲线与阶段化成熟模型（对标 Table Habit / 掌控习惯）**：
   - 升级 66 天习惯成熟度刻度为阶段化自发性模型（萌芽期 1~21 天 → 爬坡期 22~45 天 → 扎根期 46~66 天+）；
   - 在洞察页引入 Table Habit 风格的 Sigmoid 逻辑斯蒂饱和曲线 `y = 1 / (1 + exp(-0.4 * x))`，超量完成给予平滑封顶奖励（防刷）；
   - 直观量化并展示习惯从“依赖极高意志力启动”到“自动化扎根”的心理学质变过程。

3. **T-1874：多主题色阶年度热力图与日格快速钻取（对标 Obsidian Contribution Graph）**：
   - 热力图色板解耦：提供 Classic Green（经典翡翠绿）、Violet Glow（紫罗兰之光）、Autumn Warm（秋日暖阳）、Monochrome（极简水墨）4 档主题色阶预设；
   - 交互增强：热力图每个方格支持键盘聚焦、Enter 点击直接同 root 钻取到当天的历史事实面板或唤起补卡（对齐 Today 七日条交互契约）。

4. **T-1875：历史排期日历轻量点选补卡与矩阵批量回填（对标 Loop Habit Tracker 矩阵模式）**：
   - 解决用户连续漏记多天时逐项打开表单繁琐的痛点；
   - 在项目详情/回顾中提供“点选快速补卡模式”：按月日历矩阵，点击日期直接在未完成/完成/跳过三态循环切换，批量保存时一次原子 mutation 入账；
   - 严格继承该项目生效规则的单位与方向，杜绝错期与单位漂移。

5. **T-1876：智能体习惯进化建议一键采纳与规则修订直通（对标 M4 智能进化）**：
   - 行动建议卡（Coaching Suggestions）与项目规则修订时间线（Revision Timeline）直接打通；
   - 建议卡附带“采纳并调整排期”（例如：连续超负荷时采纳“由每日 1 次转为每周 4 次弹性配额”）；
   - 点击后直接向项目写入一条自明日生效的有效修订（CheckinItemRevision），无需用户重新手动编辑长表单。

6. **T-1877：周复盘卡片证据链一键钻取与样本量守门（对标 M2 证据工作台）**：
   - 建议卡与复盘指标点击可展开具体的支持证据（支撑该建议的历史事件、时间区间与对比差值）；
   - 当历史数据 < 7 天时，明确展示“样本积累中”，不给出可能误导的强断言。

7. **T-1878：移动端/桌面端卡片微动效与触觉反馈深度调优（对标 Streaks / Everyday）**：
   - 打卡完成时呈现微妙的紫罗兰微收缩微回弹（Micro-bounce），移动端触发轻柔振动；
   - 在 `@media (prefers-reduced-motion)` 和插件设置中开启减少动效时彻底 0ms 纯平切，保障无障碍合规。
