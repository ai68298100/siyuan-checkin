# 18.0.3 变更记录

本次补丁版本完成 T-1374～T-1379 的研究收口。只更新研究结论、开发范围和发布文档，不改变插件运行行为、主存储 v3、公开 API v5、契约 storeVersion 2 或最低思源版本 3.8.4。

## 研究结论

- 普通习惯继续使用现有固定间隔、配额和强度分数；知识复习若立项，使用与普通习惯分离的 review 模式，再评估锁定版本的 FSRS。
- 项目文档绑定继续复用 `noteAnchor`，后续优先完善根文档打开、失效挂起、移动/删除降级和 Android 触控验收。
- 日记联动先采用只读摘要和用户确认的周期报告；自动每日摘要等待隐私复核、多窗口幂等和真实宿主证据。
- 闪卡调度与评分归思源原生 Riff；后续优先研究人工打开入口。到期查询存在缓存副作用风险，不用于后台轮询。
- 竞品增量复核只采纳可由源码、官方文档或公开格式验证的能力，不以星数、价格或营销描述立项。

## 后续小版本候选

- v18.1.x：文档锚点打开、挂起和移动端体验收口。
- v18.2.x：日记只读摘要与用户确认写入收口。
- v18.3.x：具备稳定宿主入口后的闪卡人工入口。
- v19.x：仅在明确知识复习需求和迁移证据成立时评估独立 review 模式。

研究完成不代表上述功能已实现。真实思源桌面、Android、只读/发布服务及多窗口验收继续保留。
