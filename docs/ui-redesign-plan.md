# UI 重构计划

这次重构以极简、现代、清爽和高可读性为方向，服务于侧栏、弹窗、页签和移动端四种入口。业务逻辑、数据结构和无 AI 基础流程保持稳定。

## 设计基线

- 使用思源主题变量作为底色和文字色，只保留小驴红作为操作强调色。
- 建立统一控件高度、圆角、边框、阴影和间距，避免每个页面单独调尺寸。
- 以容器查询处理真实可用宽度，侧栏缩窄时按容器变化，不能只依赖浏览器窗口断点。
- 桌面宽页签增加内容宽度和设置双列布局，移动端保持单列、底部安全区和触控尺寸。
- 信息结构遵循“标题与状态、主要操作、数据依据、次要操作”的顺序。
- 复杂配置采用分组和渐进展开，保持新建项目的第一步简单。

## 已完成的首轮基础层

- 统一背景、卡片、控件、按钮和统计块的视觉令牌。
- 今日页卡片增加清晰层级、状态边界和稳定操作区。
- 历史、总结、复盘页面统一标题、筛选、列表和统计行。
- 编辑器在宽页签使用双列表单，在窄窗口自动回到单列。
- 侧栏窄宽度下项目名称允许安全换行，操作区不会挤压正文。
- 移动底部导航增加半透明背景和安全区兼容。

## 第二轮页面工作

1. 今日页：将最近记录、筛选和分组控制压缩成清晰的工具栏，继续优化极窄侧栏。
2. 新建与编辑：把基础信息、目标、安排与分类做成稳定的分区，检查长名称、长分组和大字号。
3. 总结与复盘：强化“结论、数据、建议”层级，AI 入口只在能力可用时显示。
4. 历史页：优化月历密度、日期选中反馈和记录操作的移动端布局。
5. 空态、加载、保存失败和同步提示：统一反馈组件和文案层级。
6. 主题与可访问性：验证深色主题、键盘焦点、触控目标和较大字体下的布局。

## 本轮验收

- 今日页日期提醒区支持生日、纪念日、每月事项和一次性事项。
- 窄侧栏项目名称最多显示两行，极窄窗口头部操作自动重排。
- 日期事项管理页在窄容器中自动单列，长备注和长名称可换行。
- `pnpm test`、生产构建和安装包校验已通过。

## 验收尺寸

- 桌面页签：`1280px`、`1024px`
- 普通窗口：`760px`、`600px`
- 移动弹窗：`390px`、`360px`
- 窄侧栏：`320px`、`280px`

每轮 UI 变更都必须通过响应式结构测试、生产构建和安装包校验；没有 AI 配置时页面仍应完整可用。
