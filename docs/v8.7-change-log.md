# 8.7 变更记录

## 手机端空间极致压缩

- **卡片行高压缩**：最小高度 64→52px，图标 44→36px，内距收紧
- **名称/元信息字号微调**：13px/10px（保持可读性）
- **进度条**：3px→2px
- **打卡按钮**：36→32px（仍保持足够触控面积）
- **筛选/多选**：搜索+筛选+多选单行排列，搜索自动缩小适配
- **分组头**：28px→18px（细点 + 微字）
- **底部导航**：5 项→4 项（归档移入回顾页），高度 58→44px

- 桌面端左侧导航仍保留归档直达入口
