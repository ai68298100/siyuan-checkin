# 7.0 变更记录

## 概览

7.0 主题为「洞察与记录」：让积累的打卡数据产生更多反馈与价值。新增趋势图表、成就徽章、打卡日志时间线、CSV 导入向导，并把思源智能体能力从 6 项扩展到 10 项。存储与 API 保持向后兼容。

## 新增

- **趋势图表（回顾页）**：近 12 周完成率折线 + 近 6 个月记录数柱状，纯 SVG 零依赖渲染，颜色随主题。
- **成就徽章**：9 枚徽章（首次打卡、50/200 条记录、坚持 7/30 天、完美一天、十次全清、连续七天全清、晨间早起鸟），全部从事件数据推导可重放；回顾页成就墙展示达成状态与进度。
- **打卡日志**：回顾页按天回看最近 14 天的记录时间线（图标 + 名称 + 数值 + 时间 + 备注）。
- **CSV 导入向导（设置 → 数据与导出）**：表头含 名称/日期（可选 数值/单位）即可批量迁入；自动按名称建项目（数值全为 1 时建成二值项）、相同记录自动去重、无效行计数提示、导入前确认。
- **思源智能体能力 v2（+4 项，共 10 项）**：
  - `checkin-list-upcoming`：查询未来 N 天的日期事项
  - `checkin-weekly-report`：生成一周纯文本周报
  - `checkin-create-item`：代建打卡项（名称必填）
  - `checkin-create-occasion`：代建日期事项（名称 + 日期必填）
  - 写入类能力沿用思源智能体自身的确认流程，并复用插件的并发锁与持久化队列。

## 变更

- 回顾页区块顺序：统计条 → 日历/明细 → 趋势 → 项目汇总 → 成就 → 打卡日志 → 近期事项 → 智能总结。

## 兼容性

- 需要思源 v3.4.2+；存储结构与 `window.siyuanCheckin` API（v4）保持兼容；既有 6 项智能体能力不变。
