# 17.2.0 变更记录

17.2.0 是联动与生态版本：完成底栏番茄钟 PR #5 评审的全部消费端修复（五轮核查）、公开 API 升级到 v5、新增 Obsidian Habit Tracker 21 迁入通道，并把最低思源版本校准到实测基线 3.8.4。**主存储结构不变（仍为 v3），可直接升级，无需迁移。**

## 底栏番茄钟联动修复（D-235~D-237/T-1266~T-1270）

- 专注启动不再「成功即暂停」：启动后只校验业务前提（专注专用指纹 = 日期修订 + direction + tomatoMode），不再复检 `canStart`。
- 跨插件会话归属：`focus.start()` 必须返回非空 sessionId 才接管（否则 `DOCK_TOMATO_START_UNCONFIRMED`，不猜测不暂停）；停止经 provider/失效/active/sessionId/阶段五重守门，`pause-session` 能力存在时原子按会话暂停；休息阶段共享父 ID 不误暂停。
- 生命周期解绑：`available:false` 即时解绑并失效该 facade；注销/替换/卸载均为纯解绑（`{stopActive:false}`），卸载不再暂停外部计时器；完成清理立即释放「正在专注」，移除 5 秒全局空闲轮询。
- 完成回写持久收件箱 `checkin-docktomato-inbox`：先缓冲再处理（未就绪/刷新失败不丢通知），判定顺序 duplicate → user-removed → blocked → 写入；`completedAt` 为记账时刻（缺失/无效拒绝，不回退当前时间）；1s/5s/30s 幂等重试；容量 200 满员拒绝。
- 收件箱手动管理（设置页）：立即重试、丢弃、以及 skipped-day 条目的「撤销跳过并计入」——同受保护单元内 skip 墓碑与完成记录一起落库、一起回滚。
- 戒除类（`atMost`）目标禁用专注入口并说明原因；番茄来源备注随插件语言本地化。

## 公开 API v5（D-240/T-1275~T-1278/T-1280）

- 协议版本 4→5，能力清单 14→18：新增 `items.query`（统一项目投影,归档语义二选一）、`events.range.read`（有界半开区间事件读,`truncated` 截断标注）、`events.record.batch`（幂等批量写,单次持久化,结果 1:1: recorded/duplicate/discarded/blocked/rejected,单批 200）、`metrics.read`（`getStreaks` 返回 current+longest）。
- `describe()` 新增 `capabilitiesSince`：每项能力首次出现的协议版本,v4 消费方在 v5 宿主上可逐能力探测。
- v4 面冻结兼容：单条 `recordEvent` 行为不变；Task Horizon 契约 `minApiVersion` 钉 4 不受影响。

## Obsidian 迁入通道（T-1279）

- 设置页「从 Obsidian 导入」：解析 Habit Tracker 21 的习惯 .md frontmatter（title/color/maxGap/entries,引号、块列表与内联列表变体,非法日期消毒）；一习惯一文件映射为每日二值项目 + `source:"import"` 打卡；幂等身份 `obsidian21:<文件名>:<日期>`（前缀已登记）。颜色与 maxGap 容忍不迁移,确认文案如实说明。
