# 小驴打卡移动端专项

这条分支负责思源 mobile 与 browser-mobile 的界面和交互打磨。移动端不以“缩小桌面布局”为目标，而是围绕单手操作、软键盘和窄屏滚动重新组织信息密度。

## 交付边界

- 移动端壳层：安全区、滚动容器、返回行为、页面高度和软键盘避让。
- 今日页：核心记录动作保持单手可达，触控目标不小于 44px；数量和时长项目提供快捷增量、进度和撤销反馈。
- 新建/编辑页：模板优先，字段渐进展开；保存操作在底部固定并避开软键盘；图标和类型选择在窄屏不制造过长页面。
- 导航：今日、历史、总结、归档之间的移动端返回与切换保持明确，页签入口在移动端隐藏。
- 验收：320、360、390、430px；浅色和深色；软键盘打开/关闭；刘海和底部安全区；触控与横向滚动检查。

## 设计参考

吸收优秀习惯应用的 Today 一屏完成、模板快速开始、分组折叠、清晰进度和低压力撤销机制。核心数据仍遵循本地优先、事实优先和可逆原则，不引入社交、积分或强制连续惩罚。

## 合并约束

洞察统计与桌面编辑器核心由其他分支负责。本分支优先以移动端媒体查询、移动端专用渲染辅助和小范围交互修正交付；必须修改共享入口时，按单一行为切小提交，并在合并说明中列出冲突点和移动端截图验收结果。
