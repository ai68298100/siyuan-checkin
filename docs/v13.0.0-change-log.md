# 13.0.0 变更记录

13.0.0 是数据内核与多窗口可靠性版本：并发写入获得写前收敛与写后校验，已删除记录不再被旧数据复活，十万级历史的查询与统计全面索引化；同时包含 12.0.2 现场反馈修复。打卡、统计与提醒的用户可见口径保持不变，存储新增的内部一致性字段（事件墓碑、版本化增量）由插件自动维护，旧备份数据可直接导入。

## 数据写入可靠性（多窗口）

- 写前三方收敛：基线、本地与远端快照在同一排他锁内做确定性对账，输出冲突、合并、本地刷新与远端回写决策；每次成功写入都推进冲突基线。
- 写后回读校验：主存储每次写入后重新读取确认目标快照已持久化；发现并发覆盖时合并期望值并最多重试一次，持续失败明确抛错。
- 单进程并发重放竞态修复；插件生命周期内的已规范化数据不再在同一事务内重复清洗，远端 loadData 等不可信输入仍走严格规范化边界。

## 事件一致性

- 删除墓碑并发闭环：撤销队列仅持事件 ID 且事件暂不可见时仍写入墓碑；同 ID 手动事件与同外部身份的外部事件都不能越过墓碑复活，无关并发事件继续保留。
- 墓碑双键索引：事件 ID 与外部身份查询集各只构建一次，五万事件与两万五千墓碑的规范化不随墓碑数量线性变慢。
- 版本化记录增量：编辑、模板与导入共用统一规范化边界（正数、两位精度、十亿硬上限）；Today、智能体与专注上下文只读取目标日期修订的增量，旧日期不借用任务当前值。

## 统计与回顾口径修复

- 历史自定义汇总区间严格使用所选起止日的半开边界，不再错误复用 asOf 当天事件；区间事件一次遍历按项目分桶。
- 回顾页日历今天态、摘要、成就、提醒、逾期与热力图共享同一 AnalyticsSnapshot 截止日，跨午夜不再出现"两个今天"；成就引擎接受显式 asOf，历史回放不读取系统时钟。

## 移动端与记录体验

- 手机端已完成项点击标题后当前表面即时折叠/展开，箭头与 aria-expanded 同步，不依赖整页重渲染。
- 非二元任务可配置"每次打卡"快捷增量；任务编辑、日期修订、自定义模板、预览、Today 与智能体路径统一使用该值，旧数据沿用类型默认值。

## 十万级数据性能

- 事件多路只读索引（项目日期、日期、事件 ID、序号、外部身份、按项目分桶、自然日集合）一次遍历构建，替换 store 后由 WeakMap 自动失效。
- 范围查询半开二分、追加幂等索引、备注定位索引、配额项目分桶、规则按项目评估、汇总单次分桶、成就指标单次遍历、完美日流式聚合、连续记录日期投影、日期修订缓存与上界二分全部落地；Today 卡片、批量完成与习惯洞察统一改走 store 级规则入口。
- 质量链环境实测：十万事件追加约 1ms（门槛 250ms）、尾部备注编辑约 0.2ms、25 次配额查询约 35ms（门槛 500ms）、十万次修订查询约 37ms（门槛 1.5 秒）、50 次规则评估约 68ms（门槛 2 秒）、十万事件回顾快照约 427ms（门槛 5 秒）。
- 全部新增性能路径携带 25 组矩阵与 100+ 条逐项断言及秒级超时门禁；测试资产增至 92 项，零退役。
