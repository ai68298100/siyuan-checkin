# 14.0.0 变更记录

14.0.0 是生命周期管理与体验优化版本：新增打卡项删除、自动归档、卡片右键菜单与批量删除；事项模板 31→66 并新增推荐分组；回顾页趋势图扩为四维度、二级导航钉住；多页 UI 布局修复。

## 生命周期管理

- **打卡项删除**：编辑器与归档页提供删除入口；两步确认展示影响；删除前自动写入恢复点；事件墓碑防多窗口旧数据重放复活。
- **自动归档**：项目可配置"完成 N 天后自动归档"（编辑器高级区），打卡提交后自动检查触发；撤销不自动恢复；normalize 白名单放行字段。
- **卡片右键菜单**：Today 卡片右键弹出编辑/归档/删除菜单，零常驻空间。
- **批量删除**：批量模式新增删除按钮，一次确认批量清除并自动创建恢复点。

## 事项模板库

- 模板 31→66，新增推荐分组（精选 11 个）默认首档，取消「全部模板」分组。
- 新增：恋人生日、同学生日、宠物生日、长辈生日、戒烟/宠物到家/退伍/毕业纪念日、水/电/燃气/垃圾/车位/宽带/供暖/车船税、电视/新闻/健身房/游泳卡/网盘/电商/游戏/知识付费续费、驾照换证、车辆保养/保险续保/充电卡、血糖/视力/心理/复诊/滤芯/空调/灭虫、劳动节/国庆节/感恩节/冬至/白色情人节/腊八节/儿童节/教师节/圣诞节。

## 回顾页

- 趋势图从 2 卡扩为 4 卡（近12周/近6月/近30天活跃/年度记录数）。
- 二级导航条下滑钉在滚动区顶部。
- 跳转按钮按 fold id 精确定位（修复整体错位一位）。
- 打卡日志宽容器按天分组双列排布。
- 头部工具区与范围页签并为一行，按钮风格统一。
- 「展开其余 N 天」修复。
- 事项操作帮助富文本化（含详细描述与自动提醒说明）。
