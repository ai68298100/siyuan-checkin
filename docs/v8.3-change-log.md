# 8.3 变更记录

## 新增

- **今日页数字快捷键**：`Alt + 1~9` 在今日页（侧栏 / 弹窗 / 页签）直接完成对应待办项——二值项记完成，数值项按推荐步长记录；输入框聚焦时自动让位，不误触。
- **复制 Markdown 周报（回顾页）**："复制周报"按钮按当前所选范围生成 Markdown 报告（标题、记录数、完成率、项目明细表），一键进剪贴板，可粘贴到思源文档或聊天工具。
- **i18n 第四波**：日期事项、编辑器标题迁入字典。

## 变更

- 新增 `tests/v8-platform.test.cjs`：数字快捷键、剪贴板周报、字典键位唯一性、发布流水线与走查清单存在性。
- 新增 `pnpm run test:perf` 性能基准（10k 事件渲染基线）。
