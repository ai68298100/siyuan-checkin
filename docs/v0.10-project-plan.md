# v0.10 新建打卡项 2.0

## 项目目标

把新建和编辑打卡项从一组通用输入升级为可理解、可预览、可校验的配置流程。基础功能继续完全本地可用，模板和 AI 只提供可选增强。

## 已完成

- 类型切换时同步目标步进、默认单位和帮助说明。
- 按时长单位切换时自动换算目标值。
- 周期配额根据“完成天数/记录数值”切换对应说明和步进。
- 新增卡片预览，实时反映图标、名称、目标、单位和频率。
- 侧边栏、弹窗、页签和移动端预览使用同一响应式结构。

## 后续子项目

- 模板配置摘要和保存前校验。
- 用户自定义模板保存、编辑和删除。
- 更清晰的基础设置、目标设置、安排分类分区。
- 大字号、超长名称、空单位和异常目标的表单回归。

每项子项目完成类型检查、完整测试、生产构建和安装包校验后再进入发布候选。
