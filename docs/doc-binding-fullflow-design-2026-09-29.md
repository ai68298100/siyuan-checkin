# 全部文档目标选择与绑定流程重构设计（T-1616，2026-09-29 评审件）

定位：T-1616 的设计产出，**只设计不开发**（D-312 边界）。基线 = T-1556 [target-selector-spec-2026-09-28.md](target-selector-spec-2026-09-28.md)（四类型/五步流/已选目标卡/差异表/换绑确认五契约）与 T-1557/1558/1559/1560 已交付的文档型切片；本稿补齐其剩余边界——「从**全部可查询文档**中选择」的统一数据面、七个绑定入口的收敛清单、失败态矩阵与集中体检增量边界。实施时与 T-1615 治理方向合并收口（卡片样式提档 + 退役 settings-row 复用类，见 [settings-garbled-display-triage-2026-09-29.md](settings-garbled-display-triage-2026-09-29.md)）。

## 1. 统一数据面：候选来自「全部可查询文档」，不再只列已绑定/少量候选

- **文档型目标（diary/summary/health/journal-doc）**：唯一候选源 = 既有 `/api/filetree/searchDocs`（`src/index.ts:787`，T-1557 防抖搜索已在用）。选择器打开即给**空查询默认面**：最近绑定（会话缓存）+ 按笔记本浏览（`/api/filetree/loadNotebooks` 既有）→ 点笔记本再列其文档；搜索框支持 标题关键词 / 路径片段 / 完整 ID 精确匹配（19 位-8 位模式直接回显该 ID 候选）。**不新增内核 API、不缓存全库列表**（有界：搜索走内核、浏览按笔记本懒加载，单次有界行数）。
- **块目标（编辑器锚点）**：保持锚点选择器既有专用面（note-anchor-picker），只统一「已选目标卡」呈现与四动作，不并入文档下拉。
- **笔记本目标（叶归）**：`loadNotebooks` 全量列表（既有 load-notebooks 通道），支持名称/ID 过滤；不混入文档。
- **当日日记（问卷 daily 模式）**：保留「按日记路径解析 + 可创建」语义（create-doc/load-notebooks 既有），选择器只负责路径模板与笔记本，不预解析具体文档。

## 2. 统一交互流（对齐 T-1556 契约 2，补数据面细节）

类型 → 笔记本过滤 → 搜索/最近/浏览 → **结果预览行**（名称 · 完整路径 · 所属笔记本 · 类型徽标 · **检查状态**：会话查询缓存命中态/未检/失效）→ 选中回填 → 保存（`bindVerifiedDocumentSave` 同源校验 + 换绑确认）→ 已选目标卡刷新。

- 结果预览行是新增共享件 `document-choice-row`：四行元数据 + 检查状态徽标，桌面行式/窄屏卡式双形态；选中态键盘可达（↑/↓ 环选 + Enter，沿用 settings-navigation 的搜索键位语义与 IME 冻结模式，T-1563 既有实现复用）。
- 每入口的搜索框/下拉退役清单：`data-diary-search`+`data-diary-choice` 双框、summary/health 同构双框、journal 的「选择搜索结果」空态框（T-1615 截图中的占位异常件）——全部替换为同一选择器组件，**不再保留互相矛盾的旧选择框**。

## 4. 失败态矩阵（逐态给修复动作，禁静默回退）

| 态 | 呈现 | 修复动作 |
| --- | --- | --- |
| 搜索/查询失败 | 结果区「检测失败」+ 重试按钮 | 重试；不把失败当无结果 |

| 保存失败 | 表单草稿保留 + 失败原因（bindVerified 既有回滚） | 重试 |

## 5. 集中体检增量边界

1. 插件就绪时有界首检（现有 readBindingBlocks/validateBindingTarget 通道，一次串行、有上限），不新增轮询。
2. **同步后复检：先核实思源公开同步完成事件契约**（暂无公开事件则保留手动「检测全部联动」，不臆造内核事件）。
3. 查询失败保持「未知/检测失败」，**不误判为目标删除**；过期响应按请求代际丢弃，不覆盖新结果（与 surface 契约同纪律）。
4. 多 root/跨窗口：体检结果按 root 会话缓存（WeakMap 模式，T-1563 先例），请求单飞去重（同 docId 并发检查合并），同步连发不爆量。

## 6. 验收门（并入 T-1608 台账）

1. 任一入口可从全部可查询文档找到目标：标题/路径/ID 三种查法 + 按笔记本浏览，各至少一条走查。
2. 候选行与已选卡摘要一致（同一 label 构建函数）；换绑/清除/重载/失败重试可回滚、取消零写入。
3. 多 root 同开两个设置面板互不覆盖；跨窗口连发检查不重复爆量（单飞断言）。
4. 键盘/IME（选择器搜索中文组合词）、320px、双语、双主题走查；读屏关联（label/aria-controls 按 root 唯一化，T-1621 联动项）。
5. 复用三件套（`validateBindingTarget`/`bindVerifiedDocumentSave`/集中体检）断言保持；退役旧选择框的存在性反向断言。
6. 与 T-1615 合并验收：720~1180 档设置目标卡特写无竖排、无挤压；`editor.clear` 等 5 键补齐后代码引用完整性守门入链。
