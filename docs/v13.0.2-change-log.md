# 13.0.2 变更记录

13.0.2 是回顾页体验版本：二级导航条滚动跟随、跳转精确定位、宽容器日志双列排布，并修复"展开其余 N 天"失效。不改变打卡、统计与提醒的用户可见口径。

## 回顾页

- 二级导航条（提醒/趋势/项目/记录/分类/成就/计划）在页面下滑时钉在滚动区顶部，方便随时跳转；宿主界面缩放（zoom 子树内 sticky 失效的 Chromium 缺陷）下同样跟随，由滚动同步主动定位。
- 跳转按钮按区块 id 精确定位：此前按下标取区块，年度热力图插入列表后所有跳转整体错位一位（"趋势"会跳到"提醒"）。
- 打卡日志在宽容器按天分组双列排布，日期标题跨两列，行密度翻倍；修复"展开其余 N 天"点击无效（额外天数的隐藏门控与展开逻辑脱节）。
- 480-959px 容器（含界面缩放后的桌面弹窗/页签）范围页签与工具区并为一行，工具区不再独占第二行。

## 验证边界

- 完整质量链（类型、构建、主功能、UI、移动端、生态契约、扩展性能门禁、发布资源）与浏览器视觉走查全部通过。
- 真实思源桌面/移动端、多窗口并发、dock、安全区与软键盘行为仍需现场复核。
