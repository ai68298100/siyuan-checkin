# v18.6.0 变更记录

发布日期：2026-09-26。主存储 v3 不变、最低思源版本 3.8.4 不变、契约 storeVersion 2 不变，可直接从 18.5.0 升级。全部功能为本地实现，零网络依赖、零遥测。

## 问卷式日记打卡（T-1465，D-273）

- 项目编辑器可将二值打卡项目绑定到问卷模板；绑定后打卡动作变为填写问卷，完成即打卡，完整内容写入当日日记或指定文档。
- 内置 5 个双语只读预设：感恩三问、五分钟日记、九宫格晨间日记、KPT 每日复盘、深度复盘周记；支持在设置页自建模板（空行分块、`# 名称 | 图标`、每行一题可标注 text/slider）。
- 写入目标可选：指定文档 ID，或「今日日记」（笔记本 dailyNoteSavePath 经 sprig 渲染定位，文档不存在时幂等创建）；不硬编码日记路径。
- 幂等与边界：插件自写条目带结构化标记，同日同模板重复填写会更新原条目（绝不改写用户已有内容）；打卡事件先落盘，文档写入失败不阻断打卡（审计 + 提示重试）；重填当日已完成的项目不重复记账。
- 真实思源内核 E2E：建笔记本 → 绑定点按 → 填写 → 落盘 → 重填更新同块不重复记账，22 场景全绿。

## 快捷记录增强（T-1462）

- 数值/时长项目可配置预设增量步长（最多 4 个，如 +250/+500），今日页与 today 渲染块渲染为一键增量按钮；一次点击 = 一条追加式增量事件，走既有记录、审计与撤销通道；未配置时行为不变。

## 今日行动台与回顾呈现（T-1466）

- 今日行动台摘要条升级完成度环（SVG wrap-around 圆环），与数字文案互为冗余编码；完成 100% 切换成功色；静态呈现、无动效、不改变摘要条高度。
- 回顾页范围统计区新增近 30 日记录趋势迷你线（sparkline），复用内存中的分析序列，零新增聚合。

## 相关性洞察（R-17.1）

- 报告新增「相关性洞察」节：项目对完成率的 Pearson 相关投影，仅在重叠排期日 ≥4 天且 |r|≥0.4 时收录；支持领先一天的滞后相关（严格更强才呈现）；确定性排序取前 3。
- 纯统计实现，无 AI 依赖；报告固定附带「相关不等于因果，仅供观察」的免责说明。

## 渲染块增强（R-17.2 / R-17.3）

- month 块超额日正向表达：数值项目当日总量超过目标时，格子显示强调色描边与「超额」角标；强度色阶口径不变。
- today 块时段分组：当日 ≥2 条有效记录的项目按早/午/晚分组计数（跳过不计），与快捷增量按钮组合覆盖高频记录场景。

## 分享图片导出（R-18.1）

- 回顾页工具新增「分享图」：年度格子 + 统计（记录总数、活跃天数、最长连击）本地渲染为 PNG，经既有保存通道落地（原生容器自动适配）。
- 图片仅在本地生成，零网络、零遥测；调色板跟随当前主题。

## 里程碑分级庆祝（R-18.5）

- 连击命中 7/14/30/60/100/180/365/500/1000 天阶梯时，完成反馈升级为里程碑级（金标 + 加重弹跳 + 里程碑文案）；其余完成保持日常轻反馈。
- 全部动效为纯 transform、零布局位移；系统减弱动态或插件关闭时降级为静态金标文字（信息不丢失）。

## 低压力呈现基线（T-1461）

- 失速卡新增「双日规则」收尾文案：断一天是数据，连断两天才是信号。
- 全局 calm 文案禁则入守门：用户可见文案禁止愧疚/惩罚式措辞。
- 热力图色阶守门：仅允许主色单色亮度阶梯，格子保留日期与悬停文字冗余编码（色盲安全）。
- 移动宿主主要打卡目标 ≥44px（Apple HIG / Material / WCAG 2.2 参考）；dock 密度布局为例外并登记。
- 低风险操作撤销优先于确认弹窗；17 处高危确认清单全量审计并登记。

## 迁移与数据健壮性（T-1463）

- Loop CSV 导入预览：未识别列在确认弹窗中点名（计入损耗词表），不静默丢弃；源文件永不改写。
- 跨午夜归账边界守门：时长来源跨午夜切段、双日归账与身份隔离有确定性证据。
- 导出格式文档新增向前兼容承诺：只增不改、宽容读取、版本可辨、源文件不动。

## 诊断与成熟度（R-18.2 / R-18.3a）

- 诊断导出升级为结构化预览对话框：按原因码计数、时间范围与内容边界披露，确认后走版本化导出通道。
- 洞察页新增 66 天习惯成熟度刻度条（自动性研究中位数参考，注明「是参考不是标准」）。
