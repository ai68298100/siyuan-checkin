# 联动与局部刷新 Smoke 清单

用于 T-129（手机、页签、dock）和番茄钟双窗口联动验收。该清单是人工验收记录模板，不替代自动化测试。

## 表面矩阵

依次在手机全屏、桌面页签、dock 侧栏执行：

1. Today 页面记录一个数值项目，确认只更新目标卡片，焦点仍在主操作按钮，滚动位置不跳变。
2. 切换筛选后记录，确认不可见项目不会被错误更新，筛选条件保持。
3. 完成态切换（首次完成、再次打开/撤销），确认卡片状态、连续徽章和 toast 各出现一次。
4. 点击撤销，确认事件删除、卡片派生值回退，toast 消失且焦点可继续用 `j/k` 移动。
5. 在窄屏键盘弹出和横屏两种状态重复 1–4，确认顶栏/底栏不遮挡内容且不随滚动漂移。

## 番茄钟双窗口

1. 窗口 A、B 同时打开联动设置并选择同一目标项目。
2. 分别完成不同 session，确认小驴打卡事件各写入一次，`externalRef` 不重复。
3. 人为制造一次不可用 API 后恢复，确认记录进入 pending，恢复后可重试成功。
4. 在 A 重试、B 删除同一 pending，确认最终队列不复活已删除项，其他项不丢失。
5. 在设置页主动复制诊断，确认快照仅包含能力、数量和状态分类，不含项目名称或事件正文。

## 提醒中心（11.0-C 真机验收）

在手机全屏与桌面页签各执行一轮：

1. 回顾页提醒中心出现待办提醒，行内显示来源、标题、时限与「延期 / 跳过」按钮。
2. 点「延期」：行变为「已延期 · 原日期」，按钮收敛为「恢复」，低干扰 toast 出现一次。
3. 点「跳过」：行变「已跳过 · 原日期」；切换提醒筛选到「已完成」等档位后行不消失、状态标签正确。
4. 点「恢复」：行回到计算状态（今天/逾期/倒计时），再确认存储键 `checkin-reminder-actions` 中该条动作被清除。
5. 把系统日期跨日（或次日复查）：昨日的「已延期」回退为计算状态，动作不复活。
6. 对已完成提醒确认无任何动作按钮；窄容器（320px dock）行内无横向滚动、按钮不换行错位。

## 习惯体系融合批次（v17.0.0 真机验收）

在手机全屏、桌面页签、dock 各执行一轮：

### 跳过态（T-1239/T-1222）

1. Today 卡右键（桌面）/长按（触屏）：菜单出现「跳过今日」，点开可填原因（可留空），确认后卡片出现「已跳过」标签。
2. 再开菜单确认出现「取消跳过」，点击后标签消失、连击与完成状态恢复。
3. 跳过当日后回顾页提醒中心与 Today 优先横幅均不再出现该项目的「今日」提醒。
4. 批量模式勾选多项点「跳过」，确认一次 toast、卡片全部进入已跳过状态。
5. 次日复查：昨日跳过日不断连击；回顾页完成率分母未把跳过日计入。

### 渲染块（T-1234~1236）

1. 在任意文档新建代码块，语言选 `checkin`，内容 `{"view":"month"}`（或先粘贴 `{"view":"summary"}`），确认源码块下方出现月历/汇总预览。
2. 修改代码内容（如 `{"view":"heatmap","year":2026}`），确认预览随编辑刷新。
3. 点击月历有记录的日期，确认跳转回顾页并定位该日。
4. 配置写错（如 `{"view":"nonsense"}`），确认显示固定错误提示而非空白或报错堆栈。
5. 若渲染块未出现或选择器不命中（思源前端版本差异），记录思源版本号与代码块 DOM 结构截图。

> **2026-09-19 真机实测（思源 v3.8.4）DOM 已核对**：语言名位于 `.protyle-action__language` 文本（代码块容器无 data-subtype、无 language-checkin 类），代码内容在 `.hljs` 下 contenteditable div——渲染器已按此实现并真机验证块识别与错误提示。另注意：**reloadUI 不会刷新插件 JS 缓存**（页面继续跑旧代码），验证新版本需整树重启思源或在窗口内 Ctrl+Shift+R 强刷。

### 笔记锚点（T-1231~1233）

1. 编辑器「笔记锚点」粘贴一个块 ID，保存后在该项目打卡，确认绑定块出现 `custom-lv-checkin` 属性且值含当日日期。
2. 打卡时填写备注（勾选「同时把备注追加为笔记块」），确认锚点文档出现 `- 日期 已完成 **项目**：备注` 子块。
3. 撤销打卡后再次打卡，确认属性更新为最新状态；删除绑定块后再打卡，确认不报错且设置审计出现「笔记回写」条目。
4. 解绑（清空锚点 ID 保存），确认原绑定块属性被清除。

### 负向习惯（T-1239）

1. 用「戒烟」模板新建项目，确认卡片默认出现在已完成区并带「今日已避开」标签。
2. 点主按钮「记破戒」，确认卡片移出完成区、连击清零；再点「撤销破戒」确认恢复。
3. 次日无操作，确认连击从昨日继续累计（跳过日/无记录日桥接）。

### 宽容提醒与报告（T-1217/T-1219/T-1223）

1. 完成全部今日项目后，回顾页提醒中心「全部」视图为空态或仅剩事项提醒。
2. 切换「已完成」过滤，确认已完成打卡提醒仍可查。
3. 「导出报告」下载 Markdown，内容与所勾选区块一致；勾选「上一周期对比」后报告含对比行。
4. 连续跳过 2 天以上的项目在洞察页教练建议出现「连续跳过了 N 天」下调建议。

## 可信记录批次（v18.9.0 真机验收）

在手机全屏、桌面页签、dock 各执行一轮；每轮前整树重启思源（reloadUI 不刷新插件 JS 缓存，见渲染块一节的注意事项）。

### 外部失败待处理箱（T-1509）

1. 设置 → 连接与能力：健康/笔记推导来源卡确认无「待处理箱」区块时展示为空态（或整块不渲染），无残留占位。
2. 若存在历史失败条目（构造：录入手动墓碑后让外部写入命中同身份），确认重试按钮给出拒绝原因且条目保留；「丢弃」带确认弹窗，误触可取消。
3. 重启思源：启动恢复摘要 toast 至多出现一次；已成功条目不出现在箱中（不复活、不重复入账）。

### 记录事实详情（T-1510）

1. 回顾 → 记录：任一外部来源行点「详情」，确认六行（日期/时刻/数值单位/计量方式/生效修订/归属项目）与实际记录一致；触屏展开/收起不引起页面滚动跳变。
2. 对已删除项目的记录展开详情，确认对应行显示「未知」而非以现名顶替。
3. 跨日事件（如昨日记今天的思阅片段）确认「记录日期」与「时刻」分列正确，不从 UTC 反推。

### 批量补记两步流（T-1511）

1. 历史页勾选 3+ 项目点「补记」：预览面板逐项分类原因可见；数值项留空提交，确认按钮计数不含该项且无默认目标值写入。
2. 填入合法值提交：确认一次 toast、一条持久化；随后逐条撤销，确认每次撤销独立且滚动位置不跳。
3. 预览打开时切换日期/翻页，确认预览收起且无残留草稿值。

### 渠道与计量筛选（T-1512）

1. 有真实思阅/健康事件的账号：来源下拉各细分渠道命中数与实际行数一致；计量方式三档互斥且合计=总数。
2. 选「api」伞选项，确认健康/笔记/任务回写/其他全部保留（伞语义）。

### 排期预演与规则对照（T-1513/T-1514）

1. 编辑既有项目改排期（如每天→每周三次）：确认对照面板字段差异行与新增/不再应做天数与实际排期直觉一致；「取消」后重开编辑器，确认草稿未落库。
2. 320px 宽度下对照面板无横向滚动、按钮可点。

### 周负荷与分母明细（T-1515/T-1516）

1. 今日页「未来七天负荷」展开：7 日格与应做项目对应；点项目名跳编辑器且返回不丢今日页状态。
2. 概览「如何计算」展开：任一项目的完成/未完成/跳过日数与记录页手工核对一致；点逐日芯片跳转记录页后筛选与排序保持。

### 横向比较（T-1517）

1. 分析 → 横向比较：触屏勾选 4 个项目后第 5 个禁用；单位不同的项目分图呈现、无跨单位换算数值。
2. 窄屏（≤360px）折线图容器可横向滚动或等比缩放，无页面级横向溢出。

### 周复盘向导（T-1518）

1. 回顾页切「本周」：向导事实块数字与概览一致；填阻力/调整后**整树重启思源**，确认草稿恢复（真机重载是最易丢状态的场景）。
2. 「导出 Markdown」经系统分享/保存面板落地成功（Android WebView 下载通道是历史高风险点）。
3. 「清除」只清当前周；上周草稿不受影响。

### 模板分享与导入（T-1519/T-1520）

1. 设备 A 勾选 2 个模板导出 JSON，经文件/剪贴板传到设备 B 导入：决策表逐行可见；重名项三选（跳过/替换/另存为）行为与标签一致。
2. 移动端文件选择器选择 .json 成功解析；超大文件（>200KB）给出拦截提示而非卡死。
3. 导入失败场景（篡改 JSON 的 shareVersion）：确认提示「导入失败，已恢复原模板」且模板列表未变。

### 设置变更清单（T-1521）

1. 修改 3 项设置（含 1 项敏感字段如微信读书 Key）：清单中敏感字段两侧均为遮罩「••••••」；撤回单字段后输入框回落已保存值。
2. 撤回整节后清单分节消失；「没有待保存的修改」空态出现。

### 迁移冲突三选（T-1522）

1. 准备含同名项目的 Loop CSV 导入：冲突面板逐行显示双方单位/类型；不兼容行 merge 禁用且默认 skip。
2. 选「另存为」确认新项目名带「· 导入」后缀且原项目未被修改；提交失败（可拔存储场景难造则跳过）记录体感。

### 样例试算台（T-1523）

1. 三张来源卡分别粘贴样例：触屏长按粘贴可用；逐行判定与摘要出现；刷新/重进设置页后样例清空（仅会话内存，属预期）。

### 模板与概览回归（T-1525/T-1524/T-1526）

1. 新建项目模板区确认 5 个新模板（读一页书/按时服药/定时起身/联系亲友/分散复习）中英文名随界面语言切换。
2. 回顾概览统计区确认无迷你趋势线残留、第 4 网格位无空洞；两主题下统计卡排版正常。
3. 打开既往依赖骨架屏/弹窗关闭钮的界面（设置首次加载、各弹窗），确认无布局空洞、关闭动作可用（宿主 b3 关闭钮）。

### v18.12.0~v18.16.0 真机验收补充（T-1616/T-1617/T-1621/T-1628 等）

#### 统一文档选择器（T-1616，全部绑定入口）

1. 日记/摘要/健康/问卷(doc 模式)四张卡：搜索框输入关键词 → 候选行出现（名称+路径双行）→ ↑/↓ 环选 → Enter 或点击选中 → ID 回填输入框。
2. 叶归笔记本卡：搜索框聚焦 → 笔记本列表自动出现（无需点击加载按钮）→ 输入过滤 → 行点击选中。
3. IME 组合态：中文输入法打字过程中候选列表不闪烁；组合结束后才触发搜索。
4. 多窗口：同时打开 dock + 页签两个设置表面，两个表面的候选列表 id 不冲突、互不覆盖。
5. 桌面端：点击「+」后无纵向位移（表单常驻可见）；移动端：点击「+」后定位到表单无 smooth 动画感知。

#### 设置页目标卡全宽单列（T-1615/T-1616）

1. ≥720px 容器：日记/摘要/健康/问卷/叶归五张目标卡均为单列卡面——无逐字竖排、无 240px 窄列挤压。
2. ≤719px 容器：五张卡在窄容器下仍为单列卡面，无布局回归。

#### 设置页字体层级（T-1617）

1. 桌面与移动端：卡片标题、字段标签、帮助文字、状态值、链接的字号/字重一致（标题 720/次级 650/帮助 11px），无双档跳变。

#### CSV 导入（T-1628）

1. 导入含无效行的 CSV：确认弹窗前 settingsFeedback 显示错误行摘要（行号+原因，前 5 条）；确认消息中的 skipped 计数正确。
2. 导入超 20000 行的 CSV：确认前显示截断警告。

#### 跨窗口（T-1622/T-1630）

1. 两个窗口同时操作提醒动作/事项完成/失败箱：操作互不覆盖。
2. 微信读书三指标独立出结果；升级提示阻断全链路。
3. CSV 导入超行数上限时确认前显示截断警告。

#### 偏好回滚（T-1620）

1. 断网/存储不可用时修改设置（主题/语言/来源开关等）：界面值自动回滚到保存前状态，显示失败提示。
