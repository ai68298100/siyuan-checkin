# 12.0.0 变更记录

日期：2026-09-16
主题：分析与生态稳定、跨端界面收口、提醒与数据可靠性。

## 发布摘要

12.0.0 将 11.x 已落地的记录、提醒和受控建议能力整理成可复用的分析与生态边界。重点不是引入新的云端服务，而是让回顾页、第三方插件和跨窗口场景都读取同一份经过校验的本地事实。

## 用户可见变化

### 回顾与分析

- 回顾页统一日、周、月和自定义范围的总结入口。
- 趋势区分完成率、记录数量、活跃天数和年度记录，避免把不同量纲混在同一张图里。
- 年度热力图按“每天的记录条数”分级；悬停/辅助文字会给出日期和数量。
- 项目汇总、连续记录、配额、成就、提醒/逾期和打卡日志采用分组与折叠布局；同一项目的多次记录可以展开查看具体时间和值。
- 支持 JSON 快照和 CSV 明细导出，导出仍然只读取插件本地数据。

### 日期事项与提醒

- 事项模板覆盖生日、纪念日、节日、定期支出、会员续费、体检和车辆年检等常用场景。
- 支持一次性、每周、每月、季度、半年、自定义间隔、公历/农历以及“每月第 N 个星期”等规则。
- 今日、即将到来、逾期和已完成状态使用统一投影；延期、跳过、恢复动作写入独立动作记录，不改写原始打卡事件。
- 事项的触发日可以完成事项，但不会自动生成一条伪造的普通打卡事件；两种事实在回顾中保持可区分。

### 桌面、dock 与移动端

- 页签、dock、快速弹窗和移动端采用同一套容器响应式规则，宽屏保留侧栏/工作台，窄屏切换为单列。
- 移动端底栏使用五列等宽布局，主“新建”操作位于中间；内容区为软键盘、安全区和滚动保留空间。
- 今日卡片的图标、标题、徽章、元信息和操作区在窄宽度下分行，避免按钮与正文重叠。
- 新建/编辑模板、事项、设置和回顾的折叠区遵循相同的间距、焦点和空态约定。
- 主题支持跟随思源、浅色、深色；减少动效偏好会关闭非必要过渡和反馈动画。

### 可靠性与数据安全

- 分析快照使用版本化信封，读取时校验日期、点数、数值范围、文本长度和 512 KiB 载荷上限。
- 跨窗口分析更新采用按 `asOf` 的单调合并，旧窗口不会覆盖更新的快照。
- 事件继续使用稳定 ID；同一 `source + externalRef` 的外部事件幂等去重。
- 保留恢复点、审计记录、冲突检测、迁移预检和失败回滚；导入不会在用户确认前覆盖主数据。
- 智能体建议沿用差异预览 → 用户确认 → 审计 → 可撤销的流程，公共生态 API 只暴露建议工作流只读快照。

## 对外 API 变化

`window.siyuanCheckin` 仍使用协议 `siyuan-checkin`、API 版本 `4`，本版本补齐并稳定以下只读分析能力：

- `hasCapability("analytics.read")`：检查分析读取能力；
- `getAnalyticsSnapshot(asOf?)`：取得版本化周/月/日/年趋势快照；
- `getAnalyticsSummary(asOf?)`：取得当前周、月、年度值及活跃天数摘要；
- `checkin:analytics-updated`：本地数据刷新后通知订阅方重新读取。

原有 `getSummaryContext`、`getCustomSummaryContext`、`recordEvent`、`registerFocusAdapter`、`registerSummaryProvider`、日期事项和导出接口保持兼容。调用方应先 `whenReady()`，再检查能力；不要把插件版本号当作功能开关。

### 番茄钟适配

第三方番茄钟可以注册 `FocusAdapter`，或通过 `recordEvent` 写入 `source: "tomato"` 与稳定 `externalRef`。没有适配器、宿主不支持或调用超时时，手动记录和内置专注仍可使用。本版本不会调用未公开的思源接口，也不会替第三方插件启动后台计时器。

## 兼容性与迁移

- `plugin.json` 的最低思源版本为 **3.4.2**；未提供 `addAgentCapability` 的宿主会跳过智能体注册，核心离线功能不受影响。
- 11.x 的主存储、日期事项、提醒动作、恢复点、审计和模板数据按向后读取策略加载，不需要用户手动改写 JSON。
- 升级前仍建议在设置页导出 JSON。若出现异常，保留导出文件、恢复点和审计报告，再按 [发布与回滚说明](release-rollback.md) 操作。

## 验证记录

发布候选应通过以下自动化门禁（以发布提交上的最终运行结果为准）：

- `pnpm run test:quality`
- `pnpm run check:stability`
- `pnpm run test:cross-surface`
- `pnpm run test:backup`
- `pnpm run test:analytics-snapshot`
- `node tests/ui-sweep.cjs`
- `node tests/visual-qa.cjs`（浅色与 `CHECKIN_QA_THEME=dark` 深色）
- `node tests/width-walkthrough.cjs`
- `pnpm audit --prod`

自动化视觉走查不能模拟真实思源宿主。**真实思源桌面端、原生页签、dock、移动端、软键盘、旋转、安全区和番茄钟双窗口仍需用户在目标环境实际复核**；在取得现场证据前，不把本版本标记为集市兼容性已完全确认。

## 已知限制

1. 提醒中心是插件内界面提醒，不承诺系统级后台通知。
2. 分析快照为本地只读结果，不能作为云同步或远端报表。
3. 智能体行动写入必须明确确认；没有模型或宿主能力时不提供静默替代路径。
4. 真实客户端现场验收尚未由自动化测试替代，发布说明中必须保留该事实。

## 后续方向

12.0.0 之后优先收集真实宿主证据和第三方生态反馈，再决定 13.0 受控执行试点与 14.0 发布工程；不会以继续增加 CSS 或模型层代码代替现场验收。
