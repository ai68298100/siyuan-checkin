# 12.0.2 变更记录

12.0.2 是 12.0 系列的性能、质量和生态准备维护版本，不改变插件本地数据格式。

## 数据内核

- 同一不可变 store 快照一次构建事件索引，覆盖项目日期、日期和事件 ID 查询；替换 store 后由 WeakMap 自动失效。
- 日/周/月与自定义日期范围使用按需排序投影和二分边界，结果仍按原持久事件顺序返回。
- 项目 ID 与启用状态查询进入同一只读索引，Today、回顾、历史操作和专注流程减少重复线性扫描。
- 缺失值、重复 ID、空范围、逆序范围和范围外查询保持原有确定性语义。

## 底栏番茄钟兼容准备

- 外部计时提供方明确收口为“底栏番茄钟插件”，旧泛化偏好自动迁移。
- 增加公开 focus facade 的能力发现、九态诊断、严格 completion 校验、幂等回写、失败重试、诊断恢复和安全导出。
- session/record 身份必须无损，非法时长、项目归档/删除、单位或记录模式漂移均拒绝写入。
- completed/ended 风暴共享在途释放操作；插件卸载后迟到异步结果不再刷新界面。
- 兼容 PR 仍处于本地草案阶段，并已更新到 Dock Tomato v2.2.8 基线要求；本版本不宣称真实外部联动已经可用。

## 样式与测试治理

- 完全退役生产环境 legacy `index.scss`，样式真值归入 tokens/components。
- 设备能力、触控目标、安全区、减弱动态和打印规则统一由组件层维护。
- 移动编辑器结构测试进入标准移动质量链，覆盖 320/360/390/430px。
- 测试资产覆盖守门要求每个 `.test.cjs` 都必须实际执行；当前 76 个测试文件、0 个退役测试。
- 新增事件、日期范围和项目索引测试，包含超过 200 条逐项运行期断言及缓存/失效边界。

## 验证边界

- 自动化覆盖类型检查、生产构建、主功能、UI、移动端、生态契约、性能和发布资源。
- 真实思源桌面、移动端、dock、安全区、软键盘和底栏番茄钟双窗口仍需现场复核；自动化结果不替代宿主验收。
