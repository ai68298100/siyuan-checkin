# 8.1 变更记录

## 概览

8.1 落地 8.0 顺延的两项：**图文打卡日志（照片附件）** 与 **i18n 迁移第二波**。存储与 API 保持向后兼容。

## 新增

- **照片附件**：数值/次数类项目的精确记录面板新增 📷 附图按钮（≤500KB，JPEG/PNG/WebP/GIF），照片以 data URL 随事件保存在插件本地数据；回顾页"打卡日志"时间线直接显示照片缩略图；历史明细中有照片的记录带标识。
- **i18n 第二波**：今日页标题、筛选占位、多选等高频文案迁移至 `src/i18n.ts` 字典（zh-CN / en-US），输出对默认中文用户无任何变化。

## 兼容性

- 需要思源 v3.4.2+；`CheckinEvent` 新增可选字段 `attachment`（data URL，读取时自动校验前缀与大小，超限静默丢弃），旧数据完全兼容。
- 注意：照片会占用插件本地存储空间（单张 ≤500KB），随打卡数据一起被思源同步。
