# 类型驱动的新建流程原型（T-1569，2026-09-28）

## 定位

- 把 [编辑器字段矩阵](editor-field-registry-2026-09-28.md) 的「目标流程」列落成**分段屏幕组成**：主流程按「选起点→记录什么→做到多少→什么时候做→是否为每日戒除/上限→怎样产生记录→可选输出与组织」七段重排现有字段（不新增能力，只重排与显隐收拢）。实施归编辑器迁移批次（研究稿 8 步方案的步骤 2~4）。
- 显隐规则**唯一事实源**=bind-editor.ts `updateConditionalFields`（477-544）：本稿逐条登记并标注收拢目标（矩阵重复判断 #1 的解法）。

## 契约 2：类型×排期×方向 适用性矩阵

| 组合 | 合法性 | 行为（现状证据） |
| --- | --- | --- |
| 方向 atMost × 非 daily | **非法** | UI 隐藏（bind 490）+ 保存静默回落 at-least（save-form.ts:81-82）→ **迁移时改为显式提示**（矩阵重复判断 #3） |
| 配额 quota × 方向 atMost | 不出现 | 方向段在 quota 排期下隐藏（daily 才显示）；完成语义=周期累计（evaluateQuotaSchedule），无戒除方向 |
| 配额 countMode=dates | 目标值不参与周期计数 | quotaAmount min/step=1，标签「周期天数」，帮助文案「同一自然日多次记录只计 1 天」（bind 495-500 既有文案） |
| 配额 countMode=value | 周期目标按单位累加 | min/step=getEditorStep(kind,unit)，标签「周期{目标}」，帮助「按当前单位累加周期内记录值」（bind 495-500） |
| 二值 × 配额 | 合法 | valueFields 隐藏但配额「周期天数」可用（每周打卡 N 天）；问卷绑定可用（binary 专属） |
| 容错 streakTolerance × atMost/quota | **不叠加** | types.ts 字段注释明示；迁移时输入框在 atMost/quota 下禁用并说明 |

## 契约 3：实时解释句式（每段一句话，复用既有文案模式）

- 段 2：`kindDesc.{kind}`（既有键）解释三种类型；
- 段 3：目标标签 `getTargetLabel(kind)`（既有函数）+ 单位 chips 即选即改；
- 段 4：排期标签 `SCHEDULE_LABELS` + 配额帮助两分支（既有 bind:500 文案为范本）；
- 段 5：`editor.directionAtMost(+Hint)`（既有键：「不记录即成功，记录即破戒」）——**按类型分叉**：二值=「今天没记录就是守住」；数值=「不超过目标即守住，超出即破戒」（与 T-1609 洞察口径、今日「记破戒」按钮语义一致）；
- 段 6：预览卡动作行 `describeEditorPreviewActions`（既有）实时反映类型×排期×来源的真实按钮；
- 段 7：锚点所有权/Task Horizon 只读投影语义沿用既有 hint 键。
- 新增文案全部走 `set.state.*`（T-1554 模板）与既有 `editor.*` 键位风格，双语入 i18n-parity。

## 契约 4：三种类型的最终屏幕组成

- **二值**：起点→类型→(无段3)→排期→方向（daily 时）→记录方式（问卷/专注按需）→输出组织。今日卡动作=完成/撤销（或 记破戒/撤销破戒）。
- **次数 quantity**：全段显示；快捷步长 chips 上屏；今日卡=步长按钮+精确录入。
- **时长 duration**：同次数 + 单位默认分钟/小时切换（editorTarget 默认 0.5 小时特判，矩阵重复判断 #4 收拢点）；专注入口可用（非 atMost 时）。
