目标仓库：`5kyfkr/siyuan-plugin-docktomato`

本地准备目录：`D:\AI\Codex\siyuan-plugin-docktomato-pr`

## 建议标题

`feat: expose a versioned focus API for optional plugin integrations`

## 建议 PR 正文

### 背景

小飞驴打卡等第三方插件需要在用户明确选择后启动底栏番茄钟，并在专注真正完成且历史记录已经持久化后取得稳定会话标识与实际时长。当前公开门面提供设置、默认时长、历史和统计读取，但没有稳定的开始/暂停专注契约；依赖 DOM 点击、私有函数或内部文件会给双方后续版本带来高耦合风险。

### 本 PR 做什么

- 新增只读冻结的 `window.__dockTomato.focus` v1 门面：`getStatus()`、`start()`、`pause()`，并公开冻结的能力列表，调用方不必通过插件版本猜测功能。
- 新增 availability、started、paused、completed 四类浏览器事件，兼容任意插件加载顺序。
- `start()` 默认沿用用户在底栏番茄钟配置的时长；可选时长继续经过原有 5–180 分钟归一化。
- 如果已有运行或暂停中的计时器，明确抛出 `DOCK_TOMATO_TIMER_BUSY`，不覆盖、不重置现有会话。
- 外部 `context` 仅允许有限键名和字符串/有限数字/布尔/null，最多 24 项、4 KiB；不接受函数、嵌套对象或原型引用。
- 外部启动会同时清理主任务、分段任务、本地聚焦恢复来源、最近完成快照及同步 envelope 中的陈旧关联，避免把打卡项错误记到上一次选中的任务块或恢复旧高亮。
- `pause()` 只调用原有暂停流程，不删除历史、不冒充完成，命名与实际语义一致；用户仍可在底栏番茄钟恢复或放弃。
- 只有 `phase=focus`、`isCompleted=true` 且原有事务已成功持久化后才发出 completion；休息、暂停片段、短片段和放弃不会误报完成。
- completion 返回稳定 `sessionId` / `recordId`、完成时间、实际分钟、计划分钟和安全 context，消费方可幂等去重。
- context 与预先分配的 focus session ID 绑定；历史草稿和状态展示只有在 session 匹配时才携带 context，避免同步残留被之后的手动专注误认领。
- context 同时写入该次历史草稿，便于进程重载后的只读核对；完成或启动失败后及时清理活动上下文。
- context 进入同步语义签名，避免只有关联上下文变化时被同步去重误判为无变化。
- 初始化恢复阶段与忙碌状态分别使用稳定错误码 `DOCK_TOMATO_NOT_READY`、`DOCK_TOMATO_TIMER_BUSY`；API 初次公开与真正 ready 会分别发送能力/可用性通知。
- 卸载前广播 unavailable 并清理上下文。

### 明确不做什么

- 不导入、不调用小飞驴打卡代码，底栏番茄钟保持可独立运行。
- 不修改原有计时状态机、事务执行器、历史/记账 writer、同步租约、提醒、音频或 UI 流程。
- 不开放内部文件路径、可变 `syncState`、DOM 节点或私有函数。
- 不在番茄钟线程中等待第三方写入；第三方失败不会反向导致番茄钟记录失败。
- 不自动完成第三方任务；是否写入、写入哪一项由消费插件和用户设置决定。

### 兼容性与失败策略

- 未安装消费插件：新增门面无副作用，原有操作完全不变。
- 消费插件后加载：读取现有 `window.__dockTomato.focus`。
- 消费插件先加载：监听 availability 后绑定。
- 重复开始：返回明确 busy 错误。
- 启动持久化失败：沿用原状态机回滚，同时恢复调用前的时长、主/分段任务关联、聚焦来源、同步 envelope 和 UI，并清理外部 context，避免半修改状态。
- 完成持久化失败：不发送 completed，避免第三方产生幽灵记录。
- 第三方监听器抛错：DOM event 隔离，不影响计时事务。
- 多窗口/多端：context 随同步状态和历史草稿传播；消费方仍必须使用 sessionId 去重。completed 是实时事件而不是可靠消息队列，消费方重载或停用期间可能错过；本 PR 不宣称已提供补偿重放。
- 停用/卸载任一插件：监听与适配器可独立释放，不保留跨插件函数引用。

## 小飞驴打卡侧配套

- 设置项由泛化的“番茄钟插件”改成明确的“底栏番茄钟插件”；旧值 `plugin` 自动迁移为 `docktomato`。
- 只接受适配器 ID `siyuan-plugin-docktomato`，不会误选未来注册的其他专注插件。
- 通过 v1 门面启动，并把 `consumer=siyuan-checkin`、`itemId`、单位和分钟/次数口径放进安全 context。
- 完成后按 `docktomato:<sessionId>` 写入 `source=tomato`；重复事件天然去重。
- 次数模式写 1；分钟模式按实际分钟写入，单位为小时时除以 60。
- 项目已删除/归档、事件版本未知、时长非法或会话 ID 缺失时拒绝写入。
- completion 后主动释放小飞驴打卡的 active adapter 状态。
