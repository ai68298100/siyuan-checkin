# 18.0.2 变更记录

本次补丁版本收口 18.0.1 发布后的界面和交互修复，包含头像设置、日记文档选择与新建、回顾助手入口等既有需求的完善。最低思源版本仍为 3.8.4，主存储 v3、公开 API v5 和契约 storeVersion 2 不变，不需要新的数据迁移。

## 回顾与今日

- 修正统计周期选择器与内容区对齐、记录数值与操作区垂直居中，清理限制回顾面板可用宽度的样式。
- 趋势和强度图表按容器尺寸绘制，窗口或面板变宽时展开内容；窄宽度保留可读标签，并清理尺寸观察器的生命周期。
- 调整移动端回顾导航和滚动、今日筛选标签及按日达成信息的对齐。
- 今日搜索在中文输入法组合开始时清除旧计时器；组合中、页面替换后或查询失效后不执行旧搜索，保留正在输入的节点。

## 头像设置

- 支持预设图标、文字/表情和照片头像，补齐双语设置文案与预设字形。
- 照片支持裁剪取景、拖动、键盘微调、缩放、重置、取消和保存；取消不覆盖已有头像。
- 校验图片类型和大小，损坏或超长 data URL 不再通过截断后保存；沿用照片优先于预设/文字的显示顺序。

## 日记文档与助手入口

- 日记设置增加目标文档搜索，最多投影 50 条结果；兼容思源 v3.8.4 的数组响应，搜索失败时明确提示并保留手填 ID。
- 新建日记文档可选择打开的笔记本；空标题、没有可用笔记本、创建失败和偏好保存失败分别提示。
- 搜索与笔记本列表忽略过期或已离开设置页面的响应。
- 复制回顾提问后，通过宿主能力守卫尝试打开思源智能体面板；不可用时保留复制内容并提示手动操作，不自动发送提问。
- 快捷入口在提供方注册方法不返回清理函数时仍避免重复注册。

## 后续研究

登记 T-1374～T-1379：间隔复习算法、每项文档绑定、每日日记、同类插件/软件和闪卡联动。研究需要先留下来源、适用范围、候选权衡与验收方案，再由 T-1378 形成采用/延后/不做结论。当前只增加研究计划，没有新增复习调度、闪卡同步或自动日记写入功能。

## 验证与兼容边界

- 发布时运行完整 `test:quality`，另走查生产包的宽度布局与明暗主题；具体执行结果见 [18.0.2 本地发布验收](release-validation-18.0.2.md)。
- 日记搜索是已核对源码的宿主路由兼容增强，不是插件的稳定公开 API；见 [思源兼容矩阵](siyuan-compatibility.md)。
- 浏览器生产包、接口桩和 fake DOM 验证不替代真实思源桌面/Android、软键盘/安全区、只读/发布服务、智能体面板与双插件联调。T-023/T-1344/B-007 保持开放。
