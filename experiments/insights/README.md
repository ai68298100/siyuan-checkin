# 习惯详情与复盘：独立实验

本目录是 `codex/habit-insights` 分支的可运行成果，与主干的今日页、编辑器、插件版本及安装包分开。入口为 `dist/index.html`，生成后可以直接用浏览器打开，不需要启动服务。

## 已实现

- 28、84、180 天窗口与截止日期选择。
- 按有效计划机会计算的当前连续和窗口内最长连续。
- 完成率、达标日数、不同单位的累计值。
- 可点击的日历热力图和每周趋势，点击后显示该范围的事件。
- 每条记录的当地日期、查看者时区的时间、数值、单位、来源和备注；详情面板保留完整备注，并识别 `siyuan://blocks/<块 ID>`、Markdown 块链接和 `((块 ID "标题"))` 引用。
- 支持校验后的块链接点击、块 ID 复制和可见反馈；独立浏览器预览提示需在思源中打开。宿主跳转桥接用模拟接口验证，真实思源接入仍由主干完成。HTML 标签内的引用、普通 URL 和不合法块 ID 保持文本。
- 记录区域支持备注/数值/单位/日期/来源搜索、来源筛选、最新或最早排序，以及长列表分批加载。
- 可把当前日期或周范围内的筛选结果导出为带 BOM 的 CSV；导出包含全部匹配记录，并对文本公式前缀做表格安全处理。
- 内置示例数据，空数据状态，只读打开小驴打卡导出的 v1/v2 JSON。
- 当前复盘 JSON 导出、深色模式、桌面及窄屏布局。

本预览不调用 SiYuan 存储接口。打开文件只在当前页面内存中解析；页面关闭后不保留，不上传数据。JSON 报告是分析结果，不能作为插件原始数据备份导回。界面内的示例明确标注为「示例数据」。

## 构建与验证

在本目录安装独立依赖后执行：

```sh
npm install
npm run build
npm run test:ui
```

验证默认使用本机 Microsoft Edge。也可以设置 `CHECKIN_BROWSER` 为 Chromium 浏览器可执行文件的完整路径。Playwright 截图输出到 `screenshots/`，构建结果位于 `dist/`，两者均被本目录的 `.gitignore` 排除。

纯逻辑测试从仓库根目录执行：

```sh
node tests/insights.test.cjs
node tests/insight-records.test.cjs
node tests/record-notes.test.cjs
```

其依赖是 TypeScript，可以使用仓库已安装的依赖。预览构建可以用 `NODE_PATH` 引用已有的 webpack/esbuild-loader/lucide 安装，不需要改主项目的 package.json 或锁文件。

## 统计合同

```ts
import {buildHabitInsights} from "../../src/features/insights";

const report = buildHabitInsights(normalizedStore, itemId, {
    asOf: new Date(),
    days: 84,
});
```

- 输入是通过现有 `normalizeStore` 得到的存储快照。找不到项目时 `report.item` 为 `null`。
- 统计窗口包括截止日，`days` 限于 7 到 366 天；默认 84 天。
- 连续次数的单位是「计划日」，不是经过的自然日。非计划日和既有归档区间跳过；已过去的未达标计划日中断连续。
- 截止日尚未达标时不进入分母，也不立即断开连续；已达标时进入分子和分母。分母可从 `eligibleScheduledDays` 核对，结果称为「已结算计划日」。此处截止日始终按尚未结束的一天处理，即使用户选的是过去某天。
- 当前与最佳连续都仅在所选窗口内计算，不声称是项目自创建以来的终身记录。
- 创建前、归档期和非计划日不进入完成率。实际存在的事件仍出现在记录列表与单位累计中。
- 每天用当日生效的目标、频率和单位判断完成。分钟、小时等不同单位不自动换算，也不混加。
- 一日无记录只表示没有记录证据。零值事件仍保留在明细；现有模型只支持正向阈值，不能据此声称支持戒除型目标。
- 删除标记会排除对应事件和外部幂等引用，输入数据不会被修改。
- 记录筛选是展示层能力，不改变统计指标；CSV 接收筛选后的完整数组，不受界面分页影响。

## 合并边界

新增核心文件 `src/features/insights.ts` 只依赖现有 `src/model.ts` 与 `src/types.ts`。本次没有修改这些文件，也没有把预览导入 `src/index.ts`。继承到工作树的主干未提交改动保留在原处，不纳入本功能提交。

主干接入只需增加习惯详情入口，向模块传入一次数据快照，再渲染报告；当前页面的渲染和写入时序仍由主干负责。接入前统一核对主干的数值误差处理与完成判定，避免统计和今日页对同一小数目标出现不同结果。

记录工具可以直接复用 `selectInsightRecords` 和 `serializeInsightRecordsCsv`。接入正式详情页时，应继续先按项目和日期/周范围取记录，再交给筛选器；CSV 导出动作应传入筛选后的全部结果，不要传当前分页数组。

块引用解析位于 `src/features/record-notes.ts`。它只从 `event.note` 派生链接，不借用 `externalRef`，后者仍是外部事件去重键。`extractSiyuanBlockLinks` 返回按块 ID 去重的列表；`extractSiyuanBlockLinkSpans` 保留每次出现的位置，供正文安全渲染；标签必须转义。`parseSiyuanBlockUrl` 供跳转前再次校验。正式接入时应保留用户主动点击的行为；预览中的 `openFileByURL` 只是宿主桥接检测，尚未在真实思源宿主验证，不可用时显示提示并保留页面。

本次不实现周/月配额、正式跳过记录、负向目标、提醒、强度评分或真实跨插件适配器。这些功能的先后依赖与验收标准见 `../../docs/design-roadmap.md`。
